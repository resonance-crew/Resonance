# Brand marks the apps draw

`instagram.svg` — Instagram's glyph (the camera), verbatim from Simple Icons 16.35.0
(`icons/instagram.svg`, CC0; its data names Meta's brand resources as the mark's source and
guidelines), as the web's `atoms/BrandMark` takes LINE, Threads, Facebook and X. It is a trademark
of its owner, used only to name the share action that opens Instagram's Stories composer (both apps'
「Instagram 限時動態」: Android's share sheet can't draw another app's adaptive icon in its own row of
actions). Drawn in one colour, never recoloured or redrawn; change it only deliberately (the apps'
tests pin its path).
