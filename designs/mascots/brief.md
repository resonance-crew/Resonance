# 業主原始需求（逐字，2026-10-27）

共振 Resonance｜手繪吉祥物角色設計提案

一、專案背景
我們正在為「共振 Resonance」設計一系列具有辨識度的原創角色，作為品牌的視覺夥伴，第一階段預計將角色導入首頁（Landing Page），未來再逐步發展成具有互動性與生命感的動態角色系列。
共振是一個以真實生命故事為核心的平台，希望透過故事分享與彼此理解，讓不同的人在生命經驗中找到共鳴。
我們相信，每個人都是立體而獨特的個體，擁有自己的生命故事、情感、信念與體悟。人與人之間不必完全相同，也能透過理解與分享，產生連結。
品牌核心精神：
* 使命： 用生命影響生命。
* 品牌主張： 讓世界上每個同頻的靈魂，都能透過故事彼此共振。
* 情感方向： 溫暖、真誠、可愛、親和、具有生命力，並帶有一點療癒感。
* 設計理念： 每個角色都應該具有獨特的外型與個性，就像每個人都有自己的生命故事，而不是同一個模板換上不同顏色。

二、設計目標
請設計一系列適合「共振」品牌的原創手繪風格角色。
角色不必侷限於人類、動物、植物或任何既有生物，也可以是抽象的生命體、奇妙的小生物，或介於不同物種之間的存在。
我們希望角色具有類似 LINE 貼圖中那些令人印象深刻的原創角色的特質：即使無法明確判斷它究竟是什麼，也能透過眼睛、表情、姿態與動作，感受到它的情緒與個性。
最重要的不是角色屬於哪個物種，而是它看起來像一個有情感、有個性、能與人建立連結的生命。
角色應具備以下特質：
1. 可愛且有親和力： 讓人自然產生好感，不刻意賣萌，也不要過度幼稚。
2. 具有情感表現力： 能透過眼神、姿勢與肢體動作表達好奇、開心、害羞、感動、陪伴等情緒。
3. 具有獨特辨識度： 即使縮小顯示，也能從輪廓、比例或標誌性特徵辨認角色。
4. 能承載品牌理念： 角色的存在與互動應自然呼應故事、共鳴、理解、連結與生命的多樣性，不必直接或刻意地象徵這些抽象概念。
5. 適合持續發展： 未來能擴展成不同角色、表情、姿勢、互動情境與動態效果。

三、視覺風格
希望整體呈現具有手繪感、溫暖且帶有些微不完美的插畫風格。
優先探索以下視覺特徵：
* 色鉛筆、蠟筆或其他手繪媒材般的筆觸與紙感。
* 柔和、低飽和度的色彩，能與共振目前溫暖、自然、療癒的品牌視覺融合。
* 柔軟或具有趣味性的輪廓，不必過度規則或幾何化。
* 簡潔但有表情的五官，尤其是具有情緒表現力的眼睛。
* 適度保留手繪的不規則感，避免看起來像制式的 3D 公仔、通用 AI 吉祥物或過度光滑的向量圖示。
上述媒材僅是探索方向，不是硬性限制。如果某個概念更適合其他插畫風格，也可以提出不同的視覺解法。
請避免直接模仿現有 IP、LINE 貼圖角色或其他品牌的既有角色設計。我們希望建立能長期發展、具有原創辨識度的品牌角色。

四、第一階段：角色方向探索與提案
這是目前唯一需要執行的階段。請先不要直接製作完整角色系列。
請先運用少量的探索成本，提出 3 個風格與概念具有明顯差異的角色設計方向。
如果有 Subagent 可用，請讓不同的 Subagent 各自探索一個方向，再由主 Agent 統整與評估。每個 Subagent 只需完成單一角色概念，不必延伸整個系列，也不需要製作大量表情或動態素材。
三個方向可以自由發揮，例如：
* 具有生物感、容易讓人產生情感投射的奇妙小生物。
* 具有柔軟、流動或變形特徵的抽象生命體。
* 具有特殊輪廓、材質或肢體語言的原創角色。
這些僅供參考，不必拘泥於此，也不必刻意讓三個方向分別對應這三種類型。
每個提案需要包含
1. 角色概念： 角色的核心想法、靈感來源，以及它與「共振」品牌理念的關係。
2. 外型設計： 身體輪廓、比例、五官、材質、主要色彩與最具辨識度的特徵。
3. 個性與情感： 角色給人的第一印象，以及它可以如何表達情緒。
4. 手繪風格： 如何透過筆觸、線條、色彩與材質，營造我們期待的插畫感。
5. Landing Page 的應用想像： 角色如何出現在首頁、如何移動，以及如何與其他角色互動。
6. 未來系列化的潛力： 這個概念如何自然延伸成具有不同外型與個性的其他角色，而不只是換色或更換配件。
每個提案請搭配一張足以看出角色設計的概念圖。如果工具支援，請以實際的角色插畫作為主要呈現，而不只是文字描述、情緒板或參考圖片拼貼。
請優先確保角色本身的辨識度與情感表現力，不需要為第一階段製作完整的品牌指南、角色設定集或動畫成品。

五、Landing Page 的動態應用情境
角色未來預計會出現在共振首頁的 Landing 區域，成為品牌與訪客建立第一印象的視覺元素。
我們期待它們像真正生活在這個空間裡的角色，而不是固定擺放在頁面上的裝飾插圖。
未來可能的動態情境包括：
* 角色從畫面側邊探頭、走進來，或以其他自然的方式出場。
* 角色在畫面中停留、觀察、好奇地看向訪客，或做出簡單的情緒反應。
* 當另一個角色出現時，兩者可以互相注意、靠近、打招呼、陪伴，或產生有趣的互動。
* 角色可能短暫離開畫面，之後再以自然的方式出現。
不需要在第一階段實作動畫，但請在設計角色時考量這些未來情境。
角色的身體結構、輪廓與肢體特徵，應盡可能適合拆分、變形或製作簡單動態。避免設計成只能以單一靜態姿勢呈現的插畫。

六、成本與工作流程限制
請採取分階段、低成本的設計流程，避免在方向尚未確認前投入過多資源。
第一階段只需要 3 個角色方向提案，不需要完整系列。
* 若使用 Subagent，每個 Subagent 僅負責一個角色概念。
* 不需要為每個提案製作多張變體、完整設定集或動畫。
* 不需要提前設計所有未來角色，也不需要過度研究與本次決策無直接關係的資料。
* 可以收集少量有助於釐清視覺方向的參考素材，但應以原創設計為主。
* 若有使用現有角色或插畫作為參考，請說明參考的是什麼設計特徵，以及如何避免直接仿作。
* 主 Agent 負責整合三個提案，指出各自的優勢、限制、系列化潛力與實作成本。

七、提案評估方式（品牌契合度／情感感染力／視覺辨識度／角色差異化潛力／動態表現潛力／實作成本）
請提出具體觀察與取捨，不需要為每個項目打大量分數。

八、完成第一階段後先停止，呈現三個提案、差異比較、主 Agent 點評與推薦、混合建議。在業主確認前不要開始完整系列或動畫。

最後的設計原則：我們不是單純想要一個可愛的吉祥物，而是希望創造一群能夠陪伴使用者、承載不同生命故事，並讓人感受到「每個人都不一樣，但仍然能夠彼此理解與共鳴」的角色。
