共振 Resonance　第一階段　第二輪

留下你喜歡的，把形體修好

你喜歡 B 的色鉛筆筆觸和第一版的漸層，也喜歡 C 第二版的撕紙貼紙；不喜歡 A、B 的形體和膚色，覺得 C 的手太短、舉起來看不出、末端也沒有東西。這一輪照這些話做了三個方向：B 換一副新形體，C 只修手，再加一個把 B 的畫法和 C 的材質合在一起的新角色。

為什麼 ChatGPT 的圖都有點像史迪奇或皮卡丘

你問關鍵是不是大頭。我們的判斷和這一輪所有方向共用的形體守則如下。

大頭不是原因

大頭小身會觸發「可愛」的反應，幾乎所有討喜的角色都這樣，我們也保留。讓它們彼此相像、又像名角色的，是三件事同時出現：

  1. 剪影全靠哺乳類的耳朵。尖長耳被拉向皮卡丘，招風大耳加藍紫色被拉向史迪奇，長垂耳被拉向大耳狗。
  2. 同一張臉。分得很開、位置偏低的黑橢圓眼，小小的 ω 嘴，兩團圓紅腮紅。
  3. 同一種身體。絨毛、奶油色肚子、肉球圓掌，正面站好、雙手垂下。

結構照用，詞彙自己發明

結構（讓角色不怪）

頭身分明但沒有脖子，手腳有清楚的末端，正面看得出方向，剪影上有一個突出的標誌。第一輪 A、B 會怪，就是缺了這些。

詞彙（讓角色原創）

標誌、臉、材質從紙、筆、故事卡的世界來：折角、撕邊、銅釘、鉛筆木屑、打孔、故事卡。摺摺原創又不怪，就是因為它的形體全來自紙。

兩個測試：遮住臉，要能用一句不含動物名稱的話說出它是什麼（答「兔子、貓」太通用，答「一團東西」太怪）；和皮卡丘、史迪奇、大耳狗的剪影擺在一起，不會被認錯。三個方向都通過了第二個測試。

這一輪的八條形體守則

  1. 剪影就讀得出頭、身體、手、腳；頭身之間收窄，但不能有脖子。
  2. 不要長脖子、柄、莖，不要「長條加圓球」，不要底部成對的圓球或光滑沒有特徵的鼓起。
  3. 身體不用膚色、桃色、粉米色、粉紅；腮紅可以，但要小、和身體不同色系。
  4. 每一案都轉成純黑剪影，看 48px 與 200px，再上下顛倒、左右翻轉，任何角度聯想到人體部位就改。
  5. 手臂舉起要到頭頂，末端是顏色或材質不同的手，肩膀有明確的關節。
  6. 一個標誌性特徵，不能是任何形狀的動物耳朵，最好就是「會被故事打開的部位」。
  7. 正面看得出方向。
  8. 避開三麗鷗、Sonny Angel、Kirby 式的球形身、Molang 的胖兔身，以及第一輪列過的角色。

方向 C′　撕紙紙偶　只修手

摺摺 Tuck

一張被撕下來的色紙，一直折著一個角，因為折角底下藏著幾行字。這一輪它多了兩條用銅釘釘在撕邊上的寬紙條手臂，末端是撕出拇指的奶油色連指手套，舉起手來就到頭頂。

1角色概念

人在書頁上折一個角，是在標記「這裡我還想再回來看」。摺摺把最在意的字折起來保護著，信任你才掀開。新的手也有來歷：手臂是撕下身體時剩下的兩條綠色邊角料，用小銅釘釘在撕邊上；手套是從折角背面那種奶油色紙撕下來的，撕的時候順手撕出一個拇指。所以它的手和藏著字的折角是同一種紙。

2外型設計

身體、折角、臉、風琴腿的結構、撕邊和配色都和第一輪第二版相同，身體也沒有縮小。手臂寬 50、往手腕收窄，肩上的銅釘到手套中心約是身體高的一半。主姿勢舉左手，因為右肩正上方就是折角，右手舉高會蓋住它。左上紙舌從圓頭改成窄短的斜切撕口（圓頭在剪影裡像一隻耳朵）。風琴腿從玫瑰色改成麥黃，全身不再有粉色。

3個性與情感

有點害羞、很認真。臉很安靜，情緒交給紙的物理；有了手以後能做的事多了：

  • 打招呼：左手繞銅釘舉高，手套在手腕上搖
  • 好奇：折角掀開一半，伸手邀你一起看底下的字
  • 害羞：用手套按住折角，腿縮短
  • 感動：瞇眼、眉毛才出現，雙手在肚子前抱住自己
  • 陪伴：坐下、折角整個掀開，和對方的手套碰一下

4手繪風格

和第一輪相同：撕邊的白纖維、膠水貼上去的一點陰影、鉛筆直接畫在紙上的五官。新增的銅釘是全身唯一的金屬，霧面、帶顆粒，看起來也是手作材料。所有紙色都是可替換的變數，例如想把腿換回玫瑰色，只要改兩個變數，不必重畫。

5Landing Page 的應用想像

示意：修訂版放在首頁截圖上，約 215px 高。

出場仍是「紙活過來」：頁面上平躺的一片紙先掀起折角，風琴腿一節一節把它撐起來，最後左手繞著銅釘甩上來揮兩下。停留時呼吸、眨眼，手臂像鐘擺一樣慢半拍跟著身體晃。游標停在附近時它會揮手。兩隻相遇時舉手，手套在半空碰一下。離場時揮手再見，或腿收起、躺平，變回一片普通的紙。

6未來系列化的潛力

每個角色都是一張不一樣的紙，被不一樣地撕下、折過、保存下來。這一輪多了第三條軸：接合方式決定動作的個性。摺摺用銅釘，手臂能整圈甩，所以很愛揮手；用紙膠帶黏手的角色動作有點僵，每動一下膠帶就皺一下，很容易害羞；用縫線結接手的角色手軟軟垂著，擁抱時會整個繞上去；用迴紋針夾手的角色可以把手拆下來遞給你，那是它表達信任的方式。

仿作檢查

「銅釘加奶油色圓手」這一組最接近 ChatGPT 參考圖 2；圓身細腿的骨架仍接近 Mr. Men。如果你覺得太像參考圖，可以把銅釘換成紙膠帶或縫線結，其他都不動。

這一輪修了什麼

初版手臂又長又細，剪影像棒棒糖，改成短而寬、往手腕收窄；銅釘從臉旁移到撕邊上；手套撕出拇指、拿掉字跡；紙舌改斜切；腿改麥黃；改舉左手，讓折角獨占右上角。

實作成本（單一角色）

約 7.5–10 人日

全是剛體紙片，每隻手只有一個關節，日夜共用一組圖，不需要動畫函式庫。三案中最低。

方向 B′　色鉛筆小生物　新形體

漾漾 Tint

一隻用色鉛筆畫出來的小傢伙。頭頂斜插一片削鉛筆刨下來的木屑，胸口留著一滴沒塗到的空白；讀到故事，那張卡片的顏色就從底部把它塗滿。

1角色概念

共振每張故事卡都有自己的色系。漾漾身上大多已經塗好，只留胸口一滴空白。讀到一個故事，那個故事的顏色就從底部把空白塗滿；被深深打動時顏色滿出來，在全身漾開，頭頂的木屑也整片張開。「被打動時顏色會暈開」是第一輪漾漾的核心，這一輪保留下來，所以中文名不變，英文從 Plip（水滴聲）改成 Tint（一抹顏色）。

2外型設計

寬寬的軟方圓頭，約占全高一半，壓在蛋形身體上，中間收窄但沒有脖子。頭頂的木屑底部沿頭頂一段長弧插進去，外緣是六角筆桿攤平後的五段直邊與硬折角，一端捲起。手臂分上臂、前臂兩節，長度固定，末端是奶油色、有大拇指的連指手套；腳又扁又長。顏色從頭頂的薰衣草一路漸變到腳尖的鼠尾草，沒有任何膚色。兩眼靠得很近，平常的嘴是一條歪歪的線，腮紅是三筆斜線。

3個性與情感

安靜、好奇、很會聽故事，會主動打招呼但不吵。它有兩個可以連續調整的情緒刻度：

  • 木屑的開合：收攏是害羞、專心；半開是平常；全開、外緣染上故事的顏色，是被打動
  • 胸口的水位：空 → 讀到一半 → 滿 → 溢出、在全身漾開
  • 其他表情靠眼皮線的高低與傾斜、嘴形和手的位置

4手繪風格

沿用第一輪 B 第一版的畫法：紙紋留下的小點、兩端尖的斜排線疊兩三層、同色系較深的鉛筆描邊，背光側壓得重、受光側斷斷續續。這一版每個部位底下多了一層不透明的底色，飄過首頁的桃色或鼠尾草色塊時，不會透出色塊的顏色。

5Landing Page 的應用想像

示意：修訂版放在首頁截圖上，約 215px 高。

木屑先從某團色塊後面冒出來晃兩下，接著探頭，再用扁扁的腳小步走進來。游標移到某張故事卡上時，它轉過去讀，木屑收攏、眼皮壓低；卡片被打開時，胸口的水位用那張卡的色系升起來。兩隻相遇時互相招手，靠得夠近時胸口的顏色會漾到對方身上，像首頁那些色塊碰到時融在一起。

6未來系列化的潛力

不換顏色，換的是畫它的那支筆。蠟筆畫的角色筆觸粗厚，標誌是一圈剝下來的包裝紙；水彩色鉛筆畫的邊緣會暈開，標誌是被水化開的筆尖；炭筆畫的霧霧的，屬於深夜。筆的長短決定體型：剛削好的瘦高，用到只剩一小截的矮胖、聽過很多故事。胸口空白的形狀決定它收集哪一種故事：一滴是情緒，一個摺角是回憶，一個圓是日常。

仿作檢查

最近的是天線寶寶 Tinky Winky（紫色、頭頂一個東西、胸前一個記號）。這版身體改成霧藍、頭頂是斜插的木屑，相似度降低了，但仍是遠親。木屑單看，有人會讀成王冠或扇貝。

這一輪修了什麼

細長軟管手改成兩節、長度固定、只轉不拉；木屑拿掉尖點，改成寬底斜插（初版剪影像束口袋或蕪菁）；找回第一版的長漸層；材質改成不透明；拿掉睫毛式的眼尾勾線和吐舌。

實作成本（單一角色）

約 12–14 人日

手臂有三段要轉，木屑要拆成幾片扇骨，胸口水位要遮罩加顏色參數。三案中最貴。

方向 B×C　色鉛筆剪紙貼紙　新角色

片片 Flick

一個用色鉛筆上色的剪紙小傢伙。腦後用一顆銅釘別著三張故事卡，聽到故事時，卡片會繞著那顆銅釘一張張扇開。

1角色概念

頭、身體、手腳都是畫紙剪下、塗上色鉛筆，再用銅釘別在一起。腦後的三張卡像一把色票扇：平常轉到頭後只露一角，有人說故事就扇開，聽得越投入扇得越開。胸前切口裡插著一張它準備送人的卡。兩個角色相遇時可以交換一張卡，卡扇裡就留下對方的顏色。

2外型設計

大頭、比頭窄的梨形身體，中間收窄，沒有脖子。卡片窄長、方角，像寫了字的索引卡，從頭頂右側扇開。眼睛是打孔機打出的霧面圓洞，看得到紙的厚度；平常的嘴是一條鉛筆弧線，沒有腮紅，害羞時臉頰才出現三道鉛筆短線。身體只有偏紫的薰衣草一個色系，暖色只在故事卡上。

3個性與情感

安靜、願意聽。它不搶話，可是你一開口，它腦後的卡就先動了。

  • 害羞：三張卡疊在一起轉進頭後，只露一角
  • 好奇、打招呼：卡片半開，前臂滑出來揮手
  • 被故事打動：卡片全開、往外冒鉛筆亮光，眼睛彎成切縫
  • 想分享：從胸前切口抽出一張卡遞給你

4手繪風格

每片紙先用色鉛筆畫在奶油色畫紙上（柔和漸層、斜排線、內側一圈同色系鉛筆線），再撕下來，外圍是白色撕紙纖維邊和淡淡的貼紙投影。也就是 B 的畫法加上 C 的材質。夜紙上靠每一片的白邊撐住輪廓。

5Landing Page 的應用想像

示意：修訂版放在首頁截圖上，約 215px 高。

出場時先只露出三張卡尖，像有人在牆後偷看，接著頭探出來、眨一次眼，再走進來。往下捲到卡片牆時，每有一張卡進入畫面，它腦後同色系的那張就轉高一點。點它一下，卡片全開，從胸前抽出一張卡遞出來，可以當「讀一則故事」的入口。兩隻相遇時各抽一張卡交換，身上就有了對方的顏色。

6未來系列化的潛力

每一位頭上都有一樣「會被故事打開的紙」，打開的方式不同：線圈裝訂的明信片會一張張翻過去，折了四折的信會一折一折攤開。紙和筆也不同：蠟筆塗在牛皮紙上、水彩色鉛筆畫在半透明的描圖紙上、夜晚出現的角色是粉彩畫在黑卡紙上。關節的固定方式決定動作的個性：紙膠帶軟而晃，棉線一頓一頓，卡榫能把手腳拔下來換位置。

仿作檢查

初版的「胸前口袋、白圓手、大頭」是哆啦 A 夢的結構，已改成切口插卡，身體也往紫色移；白圓手還在。臉改成打孔之後，不再是通用的 Q 版臉。遮住卡扇時，身體本身比較普通。

這一輪修了什麼

實作成本（單一角色）

三個方向共同的前提和第一輪一樣：紙紋、毛邊這些質感濾鏡只用來「烤」出圖層，首頁上只動位置、旋轉、縮放與透明度；prefers-reduced-motion 時只留靜態姿勢。

評審、核對與我的推薦

兩位評審看的是初版。修訂後，三位子代理逐條核對必修有沒有真的做到，另一位不讀任何評審意見、只看圖。兩位評審和只看圖的那位，都把摺摺排第一。最後的選擇在你。

C′ 摺摺　最好的修法

六項必修四項做到、兩項部分做到：右手舉不高（右肩正上方是折角），所以改用左手打招呼；手套的拇指要放大才看得見。它最不怪、最原創，舉手在 32px 都讀得出，你喜歡的身體、折角、貼紙感都沒動。核對時新發現的小問題：「被故事打動」時兩顆手套交在下腹正中；主姿勢垂下的那隻手偏長，手套到膝蓋；紙舌的 V 形缺口讓頂端像一個分叉的小角。

B′ 漾漾　最好的筆觸

六項必修五項做到、一項部分做到。色鉛筆保留最多，材質也已經不透明。但新的手臂帶出新的怪：肩頭的圓塊疊在下巴兩側，乍看像雙手捧臉，休息姿勢肚子前又有兩隻手套，像有四隻手；手臂伸直會垂到腳邊，所以每個姿勢都得彎肘。頭紫身藍、中間一道接縫，看起來像穿人偶裝。沒有那支鉛筆提示時，木屑多半被看成王冠。

B×C 片片　最不怪的形體

必修大致都做到了，只有「卡片加大」算部分完成。通用的亮眼大臉、哆啦 A 夢的口袋、48px 像熊耳朵，三個大問題都修掉了，是三案中最「正常」的角色。但它的辨識度幾乎全靠卡扇：卡一收起，就是一個普通的紫色紙玩偶；害羞時露出的桃色卡角像一隻耳朵；舉右手會撞進卡扇；細長的卡縮小後像頭上冒芽。

推薦：以修好手的摺摺當第一個角色

你說 C 沒有太大的問題，只是手有點怪；這一版正是只修手，而且三位獨立看過的人都選它。如果選它，下一步先修四個小地方，都不動身體：「被故事打動」的雙手抱在胸口或一上一下錯開；垂下的手往外張一點，手套停在臀部高度；紙舌只留一刀斜切；拇指撕得更明顯，讓手套在 200px 也看得出是手。

如果你也想要 B 的色鉛筆，比較穩的路不是改選片片，而是把摺摺的紙面換成色鉛筆塗過的紙（參考圖 3 的做法）：只換材質、不換形體，拆件和動態都不用重做。片片的故事卡扇與交換卡片、漾漾的「胸口被故事塗上顏色」，都很適合留給第二、第三隻角色當標誌。

  • 核對時發現

    兩顆奶油色圓手套併在下腹正中，在兩個方向都出現了（漾漾的休息姿勢、摺摺的「被故事打動」）。這正是守則 2 禁止的「底部成對的圓球」，也是你最在意的那種聯想。之後不論選哪一個，所有姿勢都會避開這個位置。

  • 三案都通過

    純黑剪影在 48px 和 200px、上下顛倒、左右翻轉，都沒有讓人聯想到人體部位；和皮卡丘、史迪奇、大耳狗的剪影並排也不會認錯；身上都沒有膚色。
