## 第二輪改了什麼

**業主回饋**：
- 「C 方案只是修正這個吉祥物的形體，可是其實它也沒有很大的問題，可能就是那個手有點怪怪的而已。」
- 第二輪簡報裡的具體意見：手短短的很可愛，但舉起來時看不出是在舉手；手太短，末端也沒有一個東西（業主舉哆啦 A 夢手末端的那顆圓球為例）。
- 看了 ChatGPT 參考圖之後：不要像史迪奇或皮卡丘，但形體也不能怪；要避免退化成兔子、貓、熊或大耳狗。

**這一輪只修手。** 身體、折角、小紙舌、眼睛、嘴、風琴腿、腳、撕邊、紙紋、身體配色都和第一輪第二版相同，身體也沒有縮小。

| 項目 | 第一輪 | 第二輪 | 為什麼 |
| --- | --- | --- | --- |
| 手臂 | 兩小片淡玫瑰色碎紙，長約 60，用膠貼在肩上 | 兩條獨立的紙條，寬 38（手腕處收到 33），肩到手套中心 194，約為身體高的 59% | 回應「手太短，舉起來看不出在舉手」 |
| 手臂顏色 | 淡玫瑰 `oklch(89% 0.032 32)` | 深一階的鼠尾草綠 `oklch(70% 0.047 143)`，和腳是同一張較深的邊角料 | 業主對粉色、膚色很敏感；同一張綠紙的邊角料也最像紙偶 |
| 肩膀 | 膠貼，沒有明確的關節 | 一顆小銅釘（雙腳釘）。這顆釘就是動畫的關節點 | 簡報守則 5：肩膀要有明確的關節點 |
| 手 | 沒有末端 | 一顆奶油色的圓手套（直徑 66，約手臂寬的 1.75 倍），用的是折角背面那種紙，上面有三行淡淡的鉛筆字跡 | 回應「末端沒有一個東西」；顏色、材質都和手臂不同，48px 也看得出是手 |
| 肩膀位置 | 274,452 / 534,448 | 276,412 / 532,414（上移約 40，到腮紅的高度） | 讓舉起時手套「中心」也高過頭頂，垂下時手套剛好停在紙片底緣，不會垂到膝蓋 |
| 主姿勢 | 短手斜舉 | 「嗨」：右邊（畫面右側）的手高舉揮動，另一手自然垂在身側 | 舉手要一眼讀得出 |

**手的做法比較**（`explore.png`）：
- **甲　長紙條・深鼠尾草**：一條紙條加奶油圓手套，手套帶一點字跡。
- **乙　兩節紙條・牛皮紙**：肩、肘各一顆銅釘，像傳統紙偶，揮手時前臂往上折。
- **丙　短紙條・赤陶**：肩到手 140，末端是一張折了一角的小方紙。

**選甲**。乙的牛皮紙加上手肘，第一眼最像一條人的手臂，正是業主最在意的「讓人聯想到皮膚或人體」；丙的手只到頭頂邊，方形的末端在剪影裡像舉著一個盒子，讀不出是手。甲在剪影和 48px 都清楚是在舉手，顏色也最安全，只有一個關節，拆件成本最低。

**跟著修手一起做的小調整**：
- 手套上的字跡從四行密的改成三行細的，邊緣撕得比較平。第一次試畫時，密字跡加上毛毛的白纖維邊，讓手套像一顆棉花球或啦啦隊彩球。
- 手臂紙條的撕邊比身體平直。順著紙紋撕下的紙條本來就比較直；第一次試畫用了身體的撕邊參數，手臂像一條毛毛蟲。
- 手臂從 32 加寬到 38，手套從 30 加大到 33，48px 時手臂約 3px，手套約 6px，才看得清楚。
- 舉起的是畫面右側的手。折角把右上切出一塊空白，舉起的手臂剛好落在這塊空白裡；如果舉左手，手套會和左上的小紙舌擠在一起，頂上兩個凸起容易被讀成一對耳朵。

## 1 角色概念

**核心想法**：摺摺是一張被撕下來的鼠尾草綠色紙。色紙正面有顏色、背面是白的，所以它右上角往前折下的那個「書角」（dog-ear），露出來的是米白的背面。折角底下、貼著身體的那一塊，有幾行別人用鉛筆寫的字。它不知道自己原本是哪張紙，只知道那個角要一直折著，因為底下的字是它最想留著的東西。只有在信任你的時候，它才會把角掀開給你看。

**第二輪補上的手**：它的手臂是撕下身體時剩下的兩條綠色邊角料，用小銅釘釘在身上；手套則是從那張寫了字的紙上撕下來的兩小片。所以它揮手的時候，手上也帶著一點點那幾行字。這是一個很小的細節，不需要觀眾讀懂，但讓手和「藏著字的折角」是同一種紙。

**靈感來源**：
- 人在書頁上折一個角，是在標記「這裡我還想再回來看一次」。
- 小時候的色紙：一面有顏色、一面是白的，一折就看得到兩面。
- 手帳、剪貼簿裡的撕紙拼貼：撕紙時露出的白色纖維邊、膠水貼上去後的一點點陰影。
- 用雙腳釘固定關節的紙偶、拉線跳舞的木頭小人（Hampelmann）這類民間玩具，還有勞作裡的風琴摺紙條。

**和共振理念的關係**（只是呼應，不是硬扣的象徵）：
- 每個角色都是從不同地方撕下來的紙，材質、撕法、折痕都不一樣。這就是「每個人都不一樣」。
- 它把最在意的東西折起來保護著，願意掀開給你看，代表它信任你。
- 現在它可以伸出手：揮手打招呼、伸手邀你一起看、抱住自己。手讓「連結」這件事可以用身體做出來，不必靠文字說明。
- 我們仍然刻意不讓它成為「一張卡片長了臉」：身體是不規則撕下來的圓形紙片，不是矩形，也沒有卡片框。

## 2 外型設計

**輪廓**：一片略圓、邊緣不規則的撕紙，寬高比約 1 : 1.05（和第一輪相同）。
- 右上角沿 45° 的折線往前折下，折線是一道清楚的折邊。
- 左上角有一小片往外斜出的撕剩紙舌。
- 下半身有一道舊摺痕，上方是臉，下方稍微暗一點，是肚子的區分。
- 兩側各有一條用銅釘釘住的紙手臂，末端一顆圓手套。
- 剪影由四個元素組成：右上被折線切平的斜角、左上斜出的小紙舌、兩條末端圓圓的紙手臂、兩條鋸齒狀的腿。

**比例**（`c2-tuck` 的本地座標）：
- 身體紙片約 318×328，腿長約 110，大約是身體的三分之一。
- 手臂：肩釘到手套中心 194，約身體高的 59%；紙條寬 38，到手腕收成 33。
- 手套：直徑 66，約身體寬的 21%。
- 銅釘：半徑約 8。
- 舉手時：手套中心比頭頂（小紙舌頂端）高約 25，整顆手套高出頭頂約 60。
- 垂手時：手套中心約在紙片底緣的高度，落在大腿外側。
- 臉在上半部：雙眼約在紙片高度的 45%，兩眼間距約身體寬的 0.3。

**五官**（直接畫在紙上，沒有另外貼的眼睛紙片，和第一輪相同，只換了腮紅）：
- 眼睛：鉛筆塗滿的直橢圓，左大右小，有一點不對稱。每隻眼睛左上角留一小點沒塗到的紙白當反光。
- 眉毛：平常沒有。只有強烈情緒時才用細鉛筆畫上去。
- 嘴：一條鉛筆小弧，可換成 o 形或軟弧。
- 腮紅：三道短短的赤陶色蠟筆斜線（第二輪新改）。
- 閉眼：橢圓換成一道 ∩ 形鉛筆弧。

**材質**：
- 身體：鼠尾草綠色紙，有淡淡的纖維紋理和少量纖維斑點。
- 折角背面：色紙的白色背面，米白，沒有字。
- 折角底下：身體上有幾行鉛筆字跡，折著時被蓋住，掀開才看得到。
- 手臂（新）：同一張綠紙剩下的較深邊角料，撕成長條，邊緣有白纖維。沿下緣有一道很淡的鉛筆壓線，讓它讀起來是一條扁平的紙條，不是圓柱。肩膀那端是圓頭，銅釘從這裡穿過。
- 手套（新）：一小片奶油色紙，和折角背面同一種紙，稍微舊一點。上面有三行很淡的鉛筆字跡，右下緣有幾筆鉛筆排線，讓它有一點厚度。沒有手指、沒有袖口、沒有橫向的線。
- 銅釘（新）：一顆霧面的黃銅雙腳釘，帶一點顆粒、一道較深的邊和一個小反光，下面有一點陰影。
- 腿：玫瑰色色紙摺成風琴狀，正反兩面深淺交替。
- 腳：同一張綠色紙剩下的邊角，顏色深一點。

**主要色彩**（每個紙色都寫成 CSS 自訂屬性，括號內是變數名稱，值是日間預設）：

| 部位 | 色值 |
| --- | --- |
| 鼠尾草色紙身體（`--c2-body`） | `oklch(80% 0.044 140)` |
| 折角背面（`--c2-flap-back`） | `oklch(94.5% 0.02 86)` |
| 手臂紙條（`--c2-arm`，新） | `oklch(70% 0.047 143)` |
| 手套（`--c2-glove`，新） | `oklch(93% 0.026 86)` |

| 風琴腿亮面／暗面（`--c2-leg` / `--c2-leg-fold`） | `oklch(82% 0.05 22)` / `oklch(71% 0.06 20)` |
| 腳（`--c2-foot`） | `oklch(68% 0.045 142)` |
| 鉛筆（`--c2-ink`） | `oklch(29% 0.018 60)` |
| 眼睛反光（`--c2-glint`） | `oklch(97% 0.01 85)` |
| 腮紅（`--c2-blush`，第二輪改） | `oklch(69% 0.1 38)` |
| 撕邊白纖維（濾鏡內，固定） | `oklch(97.5% 0.012 85)` |

手臂的明度 70% 介於身體（80%）和腳（68%）之間：垂在身前時有白纖維邊和膠水陰影把它和身體分開，舉到身體外時在奶油紙上很清楚。

**最具辨識度的特徵**：
- 色紙圓身體上的一塊白色三角折角，加上一道折邊。
- 銅釘釘住的紙手臂，末端一顆奶油色圓手套。
- 兩條風琴摺腿。
- 縮到 48px、甚至 32px 時，折角和舉起的手都還看得出來（見概念圖 a）。

## 3 個性與情感

**第一印象**：有點害羞、很認真，會把重要的東西好好收著。現在多了一個動作：它會先對你揮手。

摺摺的臉很安靜，情緒主要交給「紙的物理」：折角掀起或壓低、腿伸長或壓扁、小紙舌晃動，現在再加上手臂繞著銅釘擺動。眉毛只在情緒很強的時候才出現，所以一出現就特別有份量。

| 情緒 | 表現 |
| --- | --- |
| 打招呼 | 一手繞銅釘舉高，手套在手腕上左右搖 ±12°；身體往另一邊微微傾，保持平衡。見主插畫。 |
| 開心 | 兩手一起舉高；風琴腿彈一下，原地小跳；落地時身體壓扁再回彈，手臂因為慣性慢半拍落下。 |
| 好奇 | 折角掀開一半，底下的字露出來；一手伸向你，像在問「要不要一起看？」。見概念圖 c。 |
| 害羞 | 用手套把折角按住、壓得更低；身體側轉；腿縮短；腮紅加深。 |
| 感動 | 眼睛瞇成 ∩；這時眉毛才出現，眉尾往下；兩條手臂交叉抱住自己；腿軟掉一點；眼角掛一滴淚。見概念圖「被故事打動」。 |
| 陪伴 | 腿完全收起，坐在地上；把折角整個掀開；伸手和對方的手套碰在一起。 |

## 4 手繪風格

**畫面語言**（和第一輪相同）：
- 撕邊不規則，撕開處露出一圈白色纖維；在夜紙上，這圈白邊就是角色的外輪廓。
- 紙片之間有一點點膠水陰影，看起來像輕輕貼上去的。
- 五官、字跡、排線都用鉛筆直接畫在紙上，筆觸會在紙的凹凸處斷掉。
- 腮紅是蠟筆質感，有空隙。
- 不畫黑色外框，也沒有漸層高光。
- 新增的銅釘是唯一的「金屬」，霧面、帶顆粒，和紙一樣是手作材料，不是亮面的向量圖示。

**SVG 技法**（所有 id 都加上 `c2-` 前綴）：
- `c2-paper`：主要的紙材濾鏡。`feTurbulence` 接 `feDisplacementMap` 讓邊緣變毛糙；`feMorphology dilate` 加上第二次高頻位移，做出白纖維邊；`feGaussianBlur` 加 `feOffset` 做膠水陰影；兩組 `fractalNoise` 經過 `feColorMatrix` 閾值化，以 `operator="in"` 疊在形狀內，做纖維斑點和紋理。身體、手臂紙條都用它。
- `c2-thin`：小紙片用。白纖維邊較窄、陰影較淡、沒有斑點。手套用它，所以手套比較平、不會毛成一顆球。
- `c2-graphite`／`c2-graphite-fill`：鉛筆線與鉛筆塗滿的形狀。
- `c2-crayon`：蠟筆腮紅、折角下的陰影、地面陰影。`c2-crayon-soft`（新）：銅釘下的小陰影。
- `c2-metal`（新）：銅釘。很輕的位移讓圓不那麼完美，再疊一層細顆粒。
- 幾何：用自寫的 seeded 產生器（mulberry32）。
  - 外形：Catmull-Rom 曲線取樣後，沿法線做隨機漫步，偶爾加一個小缺口，就是撕紙的節奏。
  - 手臂紙條（新）：沿肩到手腕的軸線取樣出兩條長邊，肩端補半圓，再用比身體小的撕邊參數（缺口 0.55、漫步 1.8），讓它像順著紙紋撕下的長條；可以有一點點彎（`bend`）。
  - 手套（新）：撕邊的圓，字跡用 `clipPath` 裁在手套形狀裡，右下緣加 7 筆鉛筆排線。
  - 幾何都烘焙在姿勢角度上，所以膠水陰影永遠往右下落；要換姿勢時是轉群組，不必重算形狀。
  - 腮紅（新）：三筆短斜線，每筆用同一條線偏移重描兩次，再套 `c2-crayon`。
- 顏色：紙色都寫成 `style="fill: var(--c2-arm, oklch(…))"`，之後要配主題色或夜間調暗，只要覆寫變數。

## 5 Landing Page 的應用想像

**位置**：
- 桌機：站在 hero 左側桃色漂移色塊的前方或下緣，大約 140–180px 高（舉手時會再高一點）。鼠尾草綠和桃色互補，角色在色塊旁顯得很輕。
- 手機：放在「成為一群最早說故事的人」那一列下方，約 90px 高；或從右緣斜身探頭，只伸出一隻手揮一揮。一次只出現一隻。
- 絕不遮住 H1 和 CTA。舉起的手要預留高度，不能伸進標題。

**出場：紙活過來，然後揮手**
1. 頁面上原本只有一片平躺的撕紙。
2. 折角先掀起來。
3. 風琴腿從底下一節一節展開，把它撐起來。
4. 一條手臂繞著銅釘甩上來，對訪客揮兩下。

**停留**：
- 呼吸：身體從底部做 1 → 0.985 的 scaleY，手臂跟著身體一起動。
- 手臂像鐘擺：身體搖擺時，兩條手臂繞銅釘延遲 80–120ms 跟上，再輕輕晃回來（次要動態，成本很低，但很有紙偶感）。
- 每 3–6 秒眨一次眼；眼睛在 ±3px 內跟著游標。
- 游標停在附近約 1 秒，它會舉起靠游標那一側的手揮一下。

**遇到另一個角色**：
- 折角先立起來，表示注意到了。
- 用風琴腿一跳一跳地走過去。
- 打招呼：舉手；兩隻都舉手時，手套在半空碰一下（擊掌）。
- 陪伴：兩隻一起坐下，摺摺把折角整個掀開，伸手把對方拉近一起看。

**離場與再出現**：
- 離場：轉身前揮手說再見，再跳出畫面；或腿收起、手臂垂下、躺平，變回一片普通的紙。
- 再出現：之後在頁面別處，一片紙又掀起角站起來，先伸出一隻手。

**其他**：
- `prefers-reduced-motion` 時只顯示靜態主姿勢（舉手的「嗨」）。
- 和既有漂移色塊一樣，離開畫面就暫停（IntersectionObserver）。

## 6 未來系列化的潛力

同一個世界觀：**每個角色都是一張不一樣的紙，被不一樣地撕下、折過、接起來、保存下來**。

共同的家族特徵（只有這幾樣，其他都可以不同）：撕邊的白纖維、五官用鉛筆直接畫在紙上、身上某處有一道折痕或一個折起來的地方、某個地方藏著一點字跡。

以下只是舉例，沒有畫出來：

1. **紙材決定身體語言**
   - 描圖紙做的角色：半透明、怕生，和別人重疊時會「透」出兩種顏色。
   - 厚水彩紙做的角色：動作慢、很穩，哭了紙會皺，但不會破。
2. **撕法與折法決定剪影**
   - 收據撕成的長紙條：細長，緊張時會捲成螺旋，很愛說話。
   - 活頁紙：身上有打洞孔，會從孔裡偷看。
3. **接合方式決定動作個性**（第二輪新增的差異軸）
   - 摺摺用銅釘：手臂可以整圈自由甩動，所以它很愛揮手。
   - 用紙膠帶黏手的角色：動作有點僵，每動一下膠帶就皺一下，很容易害羞。
   - 用縫線結接手的角色：手臂軟軟地垂著，擁抱的時候會整個繞上去。
   - 用迴紋針夾手的角色：手可以拆下來，把手遞給你，是它表達信任的方式。

## 形體自我檢查

驗證圖：`work/formcheck.png`（剪影 200px、上下顛倒、左右翻轉、剪影 48px 正／倒／翻、彩色 48／96px），概念圖 a。

**看到什麼**：
- **剪影（200px）**：一團略圓的紙，右上是一刀斜切（折角），左上一小截斜出的紙舌；右邊一條細長的手臂舉過頭頂，末端一顆圓；左邊一條手臂斜斜垂下，末端一顆圓；底下兩條鋸齒腿。讀起來是「一個小傢伙在舉手打招呼」。
- **48px**：折角斜切、舉起的手和那顆手套都還在，手臂約 3px、手套約 6px。32px 時手套仍是一個看得見的點。
- **上下顛倒**：風琴腿變成頭上兩根彈簧，手臂變成往下伸的兩隻腳，像一隻別的小蟲子。兩顆手套一高一低，不會成對地落在底部。沒有看到器官或人體部位的聯想。
- **左右翻轉**：和正面一樣成立，只是變成舉左手；折角改在左上，紙舌在右上。
- **皮膚或人體部位的聯想**：
  - 手臂是綠色紙條，手套是帶字跡的奶油色紙，沒有任何肉色。手臂有肩上的銅釘和下緣的壓線，讀起來是扁平的紙條，不是一根圓柱。
  - 「長條加圓球末端」本身是簡報禁止的形狀，但守則 5 要求手臂末端要有一顆手。我們用四件事讓它只讀成「紙偶的手」：手臂是有撕邊的扁紙條、肩上有金屬釘、手套明顯比手臂寬（約 1.75 倍）而且是另一種顏色和材質、它永遠成對出現在身體兩側。
  - 比較稿乙（牛皮紙加手肘）一出現就像一條人的手臂，所以沒有選它。

**改了什麼**：手套字跡減量、撕邊變平（原本像棉花球）；手臂撕邊變直（原本像毛毛蟲）；手臂與手套加寬加大（48px 才讀得出）；肩膀上移、手臂加長（讓手套中心也高過頭頂）；改舉右手（避免頂上兩個凸起像一對耳朵）；腮紅改成三道赤陶色斜線。

**逐條對照第二輪形體守則**：
1. **一眼是一個角色**：讀得出身體、手、腳。摺摺的頭和身體是同一張紙，這是業主說「沒有很大問題」的地方，所以沒有改。舊摺痕把紙片分成上面的臉和下面的肚子，臉的區域約占全高一半；沒有脖子。
2. **禁止的形狀**：沒有脖子、柄、莖。手臂「長條＋圓末端」的處理見上。腳是兩片扁平、橫放的撕紙，沿用第一輪，不是球。
3. **禁止的顏色**：身體是鼠尾草綠，手臂是更深的綠，手套是奶油色紙。腮紅小，而且和身體不同色系。風琴腿仍是玫瑰色，不是身體主色；如果業主想再少一點粉色，腿可以改成手臂的綠或麥黃，這一輪依指示沒有動。
4. **自我檢查**：如上。
5. **手**：手臂夠長，舉起時手套中心高過頭頂；末端是顏色、材質都不同的圓手套；肩膀是銅釘。
6. **標誌性特徵**：折角。它是紙，不是任何動物的耳朵，也正是「會被故事打開的部位」，掀開的程度就是情緒刻度。左上的小紙舌只有一片，不成對，斜著往外伸，頂端是撕開的。
7. **正面可辨**：臉、舊摺痕分出的肚子、在正面的銅釘。
8. **原創性**：見下一節。

**業主補充的兩個測試**：
- **遮住臉問「這是什麼？」**：會得到「一張折了角的綠色紙，用銅釘釘上兩條紙手臂，底下是風琴摺的紙腿」。答案裡沒有動物名稱，也不是「一團東西」。
- **和皮卡丘、史迪奇、大耳狗的剪影並排**：摺摺頭上沒有任何耳朵，頂上只有一刀斜切和一小截紙舌。皮卡丘靠兩隻尖長耳加閃電尾巴，史迪奇靠兩片寬大的耳朵和寬臉，大耳狗靠兩條長垂耳。三者的辨識度都在耳朵，摺摺沒有耳朵，所以不會被認錯。我們沒有畫出它們的剪影，以免在提案裡複製既有 IP，這裡只用文字比較。
- **臉的公式**：眼睛是直橢圓、左大右小、間距約身體寬的 0.3，位置在紙片中段，不是分很開又很低的那種；嘴是一條小弧，不是 ω；腮紅改成三道赤陶色斜線。整隻沒有絨毛、肉球或奶油色肚子。

## 參考與避免仿作

**參考的只是特徵，不是作品**：
- 民間紙偶與拉線跳舞小人（Hampelmann）用雙腳釘做關節的做法。
- 手帳拼貼的撕紙白邊與膠痕；一面有色、一面是白的色紙；日常的書頁折角；勞作的風琴摺紙條。

**從 ChatGPT 參考圖學到的原則**：
- 參考圖 2（紙手臂）：手臂是獨立的紙條、肩上一顆釘、末端一顆顏色不同的圓手套，而且要長到舉起時高過頭頂。釘子剛好就是動畫的關節點。這四點我們都採用了。
- 參考圖 1、3：結構文法，也就是頭身分明、手腳有末端、正面可辨、剪影有一個突出的標誌。
- 參考圖 3：剪紙貼紙的白邊和紙面上的鉛筆質感，摺摺本來就有。

**刻意沒有照抄的地方**：
- 參考圖 2 的身體是葫蘆形、有腰身，腳是兩個短圓塊；我們保留摺摺第一輪的圓紙片和風琴摺腿。
- 參考圖 2 的手臂和身體同色；我們用腳的深色邊角料，讓手臂讀得出是另一片紙。
- 參考圖 2 把字寫在折角背面；我們維持字藏在折角底下，只在手套上留一點。
- 參考圖 2 的姿勢（從牆後探頭、雙手抱著小紙卡）沒有用。我們的情緒縮圖是「一起看嗎？」和「抱住自己」。第一輪的「好奇探頭」也因此拿掉，避免和參考圖撞。

第二隻角色因為拆件和互動邏輯可以共用，大約再 5–6 天。

**前端建議**：
- 第一階段：每個部件把紙紋「烤」成 2x 的 WebP（含白纖維邊），組成絕對定位的 DOM 或 SVG 紙偶，日夜共用同一組圖；全隻約 70–130KB（比第一輪多兩條手臂、兩顆手套、兩顆銅釘）。動畫只動 transform 和 opacity，用 CSS 或 WAAPI，不需要額外函式庫。
- **陰影要分開烤**：如果把膠水陰影烤進手臂的圖裡，手臂一轉，陰影也跟著轉向。建議把陰影烤成另一組圖層，放在角色下面，在父層平移 (3, 5)，這樣手臂怎麼轉，陰影都往右下落。
- 要跟主題色換色時：SVG 版本直接覆寫 CSS 變數；烤圖版本可以每個主題各烤一組。
- 之後多角色互動狀態變多：改用 **Rive**。骨架加 state machine 很適合紙偶，銅釘就是骨頭的關節；runtime 加檔案大約 100–200KB。
- Lottie 也能做，但放點陣圖的檔案偏大，互動仍要另外寫程式，比較不推薦。

**效能風險**：
- **不要在動畫中保留 `feTurbulence` 和 `feDisplacementMap` 濾鏡**。第一輪評審實測整隻角色的濾鏡一幀約 28ms，這一輪多了手臂與手套，只會更慢。材質一定要先烤成圖。
- 手機上同時最多一隻角色，離開畫面就停止動畫。

## 自評

**最強的地方**
1. **手終於讀得出來，而且是紙偶自己的語言**：手臂是同一張綠紙的邊角料，肩上一顆銅釘，末端是那張寫了字的紙撕下來的手套。舉起來時手套整顆高過頭頂，48px 甚至 32px 都看得出在舉手；銅釘同時就是動畫關節，綁定比第一輪更簡單。

**最弱的地方**
