# B′｜漾漾 Tint

**一句話定位**：一隻用色鉛筆畫出來的小傢伙。頭頂斜插著一片削鉛筆刨下來的木屑，胸口留著一滴鉛筆繞開的空白，等故事來把它塗上顏色。

## 1. 角色概念

- **核心想法**：共振的每一張故事卡都有自己的色系。漾漾是一支色鉛筆畫出來的小生物，身上大多已經塗好了，只有胸口留下一滴空白。它讀到一個故事，那個故事的顏色就會從底部把這滴空白塗滿；被深深打動的時候，顏色會滿出來，在全身漾開，頭頂那片木屑也會整片張開。
- **靈感來源**：削鉛筆時刨下來的木屑。木屑內側是木頭色，外緣是一圈筆桿的漆色。六角形筆桿的外緣攤平以後，是一段一段的直邊，在稜角處折一下，所以木屑的外緣是「直邊＋硬折角」的節奏，每個稜角往內留下一道摺痕；木屑的一端常會自己捲起來。這些就是漾漾頭冠的造型來源。外緣的漆色是它自己那支筆的顏色：薰衣草色。概念圖裡，它腳邊躺著那支薰衣草色鉛筆和一片木屑，這是全圖唯一的場景。
- **和品牌的關係**：它不用象徵「共鳴」，只要把讀故事這件事做出來：讀，然後被染上顏色。被染上的顏色就是那張卡片的色系（桃、薰衣草、鼠尾草、麥黃、霧藍、玫瑰），所以首頁上每一次互動，它身上的顏色都會不一樣。

## 2. 外型設計

- **輪廓**：頭是一顆寬寬的軟方圓（上緣略平、兩頰略鼓），比身體寬很多。頭頂斜插著一片木屑冠：底部沿著頭頂一段長弧插進頭裡，沒有尖點、沒有柄；整片往左傾 27°；外緣是五段直邊和硬折角，靠頭中央那一端捲成一小卷。身體是一顆蛋，頭直接壓在身體上，交界處兩側內收。手臂分兩節，從頭的下緣兩角、頭和身體交界的外側長出來，都畫在頭的前面。短腿，配上又扁又長、腳尖朝外的腳。
- **比例**（800 × 800 的畫布）：頭寬 304、高 248，約占全高（頭頂到腳底）的 50%；連木屑約 57%。木屑冠露出頭外的部分寬約頭寬的 72%，插進頭裡的那段底部弧線（弦長）約頭寬的 37%。上臂長 100、前臂長 108，寬度由肩往腕收窄（58 → 45），比上一版粗約 1.45 倍；手套直徑 76。
- **五官**：
  - 眼睛：深靛色（不是黑色）、上窄下圓的豆形，兩眼中心距離約為頭寬的 26%（ChatGPT 公式大約是 40%）。整張臉集中在頭的中下段，額頭大。眼睛裡的亮點是鉛筆跳過紙面留下的白。每隻眼睛上方有一筆眼皮線，從內側畫到外眼角就停，不再往外勾；表情靠它的高低和傾斜：抬高是驚喜，壓低是專心或想睡，往內斜是擔心。
  - 嘴：平常是一條一邊高一邊低的短線；張嘴留給激動的表情。
  - 腮紅：每邊三筆短斜線，杏色，不畫圓餅。
- **材質**：全身都是色鉛筆，看得到紙紋顆粒和斜向排線。每個部位底下都有一層不透明的底色，所以紙紋白點不會透出後面的頁面或色塊。手套和胸口那一滴是「沒塗到的紙」。
- **主要色彩（OKLCH）**：

- **最有辨識度的特徵**：頭頂那片斜插、有硬折角、一端捲起的木屑，剪影就靠它；其次是胸口那一滴有「水位」的空白，它讓正面可以辨認；再來是薰衣草頭、霧藍身體這兩個大色區，96 px 也分得出來。

## 3. 個性與情感

- **第一印象**：安靜、好奇、很會聽故事的小傢伙。會主動打招呼，但不吵鬧；另一隻手常常輕輕放在肚子上，像在等你說下去。
- **兩個情緒刻度**，都能做成連續的數值，方便動畫和互動控制：
  - **木屑冠的開合**（0 到 1）：收起來時只剩兩三段直邊、壓低、斜得更厲害（害羞、專心、想睡）→ 半開（平常、打招呼，五段）→ 全開時站直、展開到七段，外緣染成故事的顏色（被打動、驚喜）。
  - **胸口的水位**（0 到 1，再加上溢出）：空的 → 讀到一半 → 滿了 → 溢出來，在身體上漾開。
- **其他表情**靠眼皮線、眼睛開闔、嘴形和手的位置。概念圖裡畫了三個：打招呼（主姿勢）；被故事打動（閉眼微笑、雙手捧著臉頰、木屑全開、胸口溢色）；讀故事（雙手拿著一張小卡、眼皮壓低往下看、木屑收攏、水位一半）。

## 4. 手繪風格與 SVG 技法

- **色鉛筆底色**：每個部位先用漸層填色，再用 `feTurbulence`（細的非等向紙紋，加上慢速的手壓變化）做成 alpha 遮罩，咬出紙面的小點。越靠近邊緣鉛筆越淡（`f-tooth1`）。這一版把咬出小點的門檻提高，依紙紋雜訊的分布估算，部分透出的點從約 23% 降到約 11%。
- **不透明的底色**：每個部位底下都有一層往內縮 3 單位的底色（`f-under`），日夜都開著。白天是奶油紙色，頭和身體再帶一點自己的顏色；夜紙上由 CSS 變數（`--b2-under-*`，值在 `gen.py` 的 `NIGHT_VARS`）換成各部位調暗的顏色。實測角色內部（離邊緣 3 px 以上）alpha 低於 235 的像素從上一版的 26% 降到 2.4%；`brightness(0)` 的剪影是實心的，放在首頁的桃色、鼠尾草色塊上也不會透出色塊的顏色（`checks/forms.png`）。
- **排線**：用程式產生一筆一筆兩端尖、中間略彎的筆觸（`taper_stroke`），以約 −57° 的方向排線，像右撇子畫的。依部位的明暗權重撒點：頭用紫色系，身體和手臂用藍色系，身體底部和腳用灰綠。排線層只吃到紙紋的頂端（`f-tooth2`），所以看得到底下的漸層。受光側的淺色排線減半。
- **手的抖動**：每個部位的填色、排線、描邊都放在同一個低頻 `feDisplacementMap`（`f-warp`）裡一起變形，不會對不準。小部位（手套、腿、腳、木屑）用擺幅較小的 `f-warp-s`，木屑的硬折角才不會被抖圓。
- **鉛筆描邊**：沿輪廓算出每一點的法線，背光側（右下）壓力大，受光側壓力小、偶爾斷開；另有一道較淡的第二筆。最後加上石墨跳紙的顆粒（`f-grain`）。前臂上端蓋住手肘的那段圓弧，描邊故意畫得很輕，讀起來是一道彎折，不是一顆螺絲。
- **手臂在自己的座標裡畫一次**：上臂、前臂、手套各自垂直向下畫好，排線方向和明暗依主姿勢的角度預先轉好，所以主插畫看起來是同一隻手畫的；其他姿勢只轉動這三張圖。
- **深色的記號**（眼、嘴、眼皮線）：濃密的筆觸，邊緣粗糙（`f-ink`）。腮紅和溢出的顏色用 `f-bleed`，像吃進紙裡一樣。

## 5. Landing Page 的應用想像

- **出場**：木屑冠先從首頁某團色塊的後面冒出來，斜斜地晃兩下，接著頭、眼睛探出來，再用扁扁的腳小步走進畫面。
- **停留**：呼吸（身體 scaleY 1 到 1.02）、眨眼、木屑隨著呼吸輕輕擺動，眼睛跟著游標看。
- **和故事卡互動**：游標移到某張故事卡上時，它轉過去讀，木屑收攏、眼皮壓低。卡片被打開時，胸口的水位用那張卡片的色系升起來，木屑張開。停在某個顏色一陣子後，顏色慢慢退掉，回到空白。
- **和另一個角色互動**：兩個角色相遇時互相招手。如果靠得很近，兩人胸口的顏色會互相漾到對方身上，像首頁那些色塊碰到時會融在一起。
- **離場**：揮手，轉身小步走出去；或者縮到色塊後面，最後只剩木屑露在外面晃一下，然後收進去。
- **減少動態**：使用者設定 `prefers-reduced-motion: reduce` 時，只顯示靜態的主姿勢（或依情境換成另一張靜態姿勢），不走路、不呼吸、不揮手，也關掉下面提到的「線條沸騰」。胸口水位和木屑開合直接跳到結果，不做過程。
- 首頁放的位置：右側鼠尾草色塊下方、約 200 px 高，不搶標題。因為角色現在是不透明的，飄過任何色塊都不會被染色。

## 6. 未來系列化的潛力（只寫不畫）

不是換顏色，而是換**畫它的那支筆**，以及**它胸口留的空白**：

1. **筆的種類決定材質和個性**：色鉛筆（漾漾，細緻、安靜）；蠟筆（筆觸粗厚、邊緣蠟亮，標誌是一圈剝下來的包裝紙，個性大方）；水彩色鉛筆（邊緣會暈開，標誌是被水化開的筆尖，個性多愁善感）；炭筆（霧霧的、會弄髒手，標誌是一小撮炭粉，個性屬於深夜、話很少）。
2. **筆的狀態決定體型**：剛削好的長鉛筆是瘦高的角色；用到只剩一小截的鉛筆頭是矮胖、年紀比較大、聽過很多故事的角色；斷過芯又接起來的鉛筆，身上有一道接縫。
3. **空白的形狀決定它收集哪一種故事**：一滴（情緒）、一個摺角（回憶）、一個圓（季節與日常）。形狀不同，不是同一個模板換顏色。

## 形體自我檢查（`checks/forms.png`、`checks/silhouette.png`、概念圖 a 欄）

- **純黑剪影（200 px）**：寬方圓的頭、頭頂一片往左斜的鋸齒寬冠、蛋形身體、兩隻扁腳；右手往外斜上舉，手套和頭頂同高，手臂和頭之間有一道往上張開的空隙；左手手肘往外，形成左側一個小凸角。`brightness(0)` 版本沒有隱藏任何東西，是一整塊實心的剪影。一句話描述：「一個頭頂斜插一片鋸齒木屑的小傢伙在招手」。
- **48 px**：彩色版看得到薰衣草色的頭、霧藍的身體、頭右上方的奶油色手套點和頭頂的木屑；純黑版裡，舉起的手和頭之間有缺口，讀得出是在舉手。胸口那一滴在 48 px 看不見，這可以接受，它是近看的細節。
- **左右翻轉**：讀法不變，只是改成用左手招手、木屑往右斜。
- **上下顛倒**：蛋形身體和兩隻扁腳到了上面，像一個綁了小蝴蝶結的袋子；寬頭到了下面，鋸齒木屑像一圈底座；舉起的手變成垂下的手。沒看到任何人體部位或器官的聯想。
- **有沒有讓人聯想到皮膚或人體部位**：全身沒有膚色、桃色、粉米色；沒有脖子、柄、莖；腳是扁長的，不是底部成對的圓球。肩膀的圓頭和裡面那一筆弧線，我特別確認過不會讀成身體上的圓點（它在手臂的頂端，顏色和手臂一樣，弧線很淡）；胸口那一滴是有水位的水滴形，不是圓形。
- **這一輪修掉的問題**：
  1. 手臂原本是細長軟管加圓末端，垂下時像觸手，舉手要拉長 1.4 倍。改成兩節、固定長度、加粗，只轉不拉。
  2. 木屑冠原本從一個尖點長出來，剪影像束口袋、糖果紙、蕪菁，也像第一輪 A 頭上的芽。改成寬底、斜插、硬折角、一端捲起。
  3. 試過讓木屑冠只坐在頭的左上角，結果它和右上方的手套在剪影裡變成一對「熊耳朵」；也試過低而寬、正坐在頭頂的版本，剪影像一頂王冠。最後選擇寬底插在頭頂偏左、往左斜、比頭頂寬的版本，它在剪影裡是一整片斜斜的鋸齒冠，不是兩個圓凸起。
  4. 為了讓舉起的手和頭分開，頭往左歪 4°，舉起的手肘稍微往外彎；手臂和頭之間的空隙，在頭頂往下 30～70 單位處約 40～60 單位。
- **遮臉測試**：「這是什麼？」答案應該是「一個頭上斜插著一片鉛筆木屑的小傢伙」，不是動物，也不是一團東西。
- **和皮卡丘、史迪奇、大耳狗並排**：頭頂是一整片斜的鋸齒冠，不是一對耳朵，也沒有垂下來的長耳，不會被認錯。

## 參考與避免仿作

- **相近的既有角色，以及刻意避開的特徵**：
  - **天線寶寶的 Tinky Winky**（紫色、頭頂有天線、肚子有螢幕）：漾漾的頭頂是一片寬底、斜插的木屑，不是天線；胸口只有一小滴有水位的空白，不是長方形螢幕；臉直接畫在頭上。這一版的身體已經是霧藍，只有頭是薰衣草，「紫色全身＋頭頂一個東西＋胸前一個記號」的相似度比上一版低。
  - **Grimace（紫色圓團）**：頭身分開、手腳有末端、身體換成霧藍，沒有那種一整團紫色的感覺。
  - **哆啦 A 夢**（藍身體＋白圓手＋白肚子）：手是有大拇指的連指手套，頭是薰衣草色，沒有白臉、白肚子、鈴鐺。
  - **走路草、蕪菁娃娃、頭頂發芽的熊**（圓頭頂一叢從一點長出的葉）：木屑冠底部是一段長弧，沒有尖點，邊是直邊和硬折角，不是葉子的弧線。
  - **公雞的雞冠、王冠**：木屑冠是斜的，有一端捲起，邊上有一圈漆色和摺痕，裡面是木頭色，靠這些讀成木屑。
  - **三麗鷗、皮卡丘、史迪奇、大耳狗**：完全沒有耳朵，剪影並排不會認錯。
  - **Sonny Angel**（頭戴動物帽）：木屑是它身體的一部分，會隨情緒開合，不是帽子。
  - **米奇系的白手套**：有大拇指的連指手套是卡通通則，這裡做成奶油色、鉛筆畫的。
- **從 ChatGPT 參考圖學到、並用上的原則**：
  - 結構文法：頭大身小、頭身之間收窄、手腳都有清楚的末端、正面有一個記號。
  - 參考圖 2：手臂是可以單獨轉動的部件，末端是奶油色手套，舉起來可以到頭頂，肩膀就是關節點；舉手、放下都只是旋轉。
  - 參考圖 1：同色系較深的鉛筆外框、紙紋顆粒、柔和的疊色漸層。
  - 參考圖 3：「會動的標誌部位就是情緒刻度」（參考圖用耳朵，漾漾用木屑冠）。
- **刻意沒有照抄的**：任何哺乳類耳朵；分很開的黑橢圓眼＋ω 嘴＋圓腮紅這張臉；絨毛、肉球、奶油色大肚子這組布偶配件；正面站好、雙手下垂的布偶站姿；參考圖 2 的銅釘（那是 C 的材質，漾漾的關節是一筆鉛筆弧線）；剪紙貼紙的白色撕邊（也是 C 的）。

**前端技術建議**：

- **烘焙＋SVG／CSS transform（建議先做）**：每個部位烘成 2x 的 WebP 點陣圖層，用 transform 動。手臂只旋轉，這條便宜的路現在走得通。主姿勢以 2x（約 260 px 框）輸出，評審實測全身約 52 KB；整組部件估 70～85 KB。因為角色已經不透明，白天那一組直接放在夜紙上也成立（試過，見下）；若想要夜裡較亮的描邊，只需另外烘一層描邊，不必整套重烘。
- **Rive（要做互動時）**：狀態機裡放「木屑開合」「胸口水位」兩個數值，加上「故事色系」顏色參數，正好對應這個角色的核心互動。手臂用一般骨頭就好，不需要網格。
- **Lottie**：不支援 SVG 濾鏡，鉛筆質感必須先輸出成點陣圖層；可以做，但木屑開合會比較生硬。
- **效能風險**：現在的質感來自即時的 `feTurbulence`／`feDisplacementMap`（`character.svg` 約 349 KB，gzip 後約 100 KB）。只要動畫在動，每一格都要重算濾鏡，評審實測只動一隻手就掉到約 48 fps、第一格卡 400 ms，所以上線一定要先烘焙。若想保留手繪的抖動，可以為每個部位準備 2～3 張略有不同的紋理，每秒換 8 次左右（「線條沸騰」）；減少動態時關掉。
- 換色系時，只要換水位、溢色和木屑外緣這三層的顏色，可以用 CSS 變數或 Rive 的顏色參數控制，不需要重畫。

## 自評

- **最強**：
  1. 兩個標誌都是情緒刻度，也都來自鉛筆和紙的世界（木屑會開合，空白會被塗滿），和「讀故事、被打動」直接接上，胸口的顏色就用那張故事卡的色系。
  2. 業主喜歡的色鉛筆質感和長漸層都留著，而且結構補齊了：頭身分開、兩節的手臂只靠旋轉就能舉手、放下、捧臉、拿卡片，舉起時一眼看得出是在打招呼。角色變成不透明以後，放在首頁任何色塊上都乾淨，日夜也能共用一套圖。
- **最弱**：
  1. 木屑冠在純黑剪影裡是一整片鋸齒，單看剪影可能被讀成王冠或雞冠；「鉛筆木屑」這層意思要靠彩色時的木頭色、漆色外緣、摺痕和捲邊來說，第一次出場時最好讓那支鉛筆一起出現。
  2. 為了讓手套舉到頭頂，手臂還是比一般 Q 版角色長；休息時要把手肘往外、手放到肚子上，才不會垂到臀線以下。「手垂在身體兩側」這種站姿這個角色做不到。

### 沒改的，和理由

- **白天的底色不是純奶油紙色**：品牌評審建議白天用奶油紙色。手套和木屑我照做了；頭和身體的底色是奶油紙色再帶一點自己的顏色（`oklch(94.5% 0.018 300)`、`oklch(94.5% 0.016 238)`）。純奶油色的話，紙紋孔在 48～96 px 會變成一顆顆亮白的閃點，和形體評審「受光面白點減半、讓大塊色面露出來」的要求相反；帶一點色以後白點變柔和，但角色一樣是不透明的，不會透出頁面或色塊。
- **木屑冠的傾斜方向選左，不選右**：往右斜（朝舉起的手）時，木屑和手套在剪影裡容易黏成一團；往左斜則讓整個剪影一邊是冠、一邊是手，比較均衡。但只放在頭的左上角又會和手套湊成一對「熊耳朵」，所以底部仍然插在頭頂中間偏左。
- **肩關節沒有用銅釘或縫線**：銅釘是 C 的材質，縫線會把它帶回布偶的感覺。漾漾的關節是一筆鉛筆弧線，和全身的畫法一致。
- **沒有改成「休息時雙手垂在身體兩側」**：要讓手套舉到頭頂，手臂就得有一個頭那麼長；垂直放下會落到臀線以下。照形體評審給的另一個選項，休息時把手放在肚子前面。
- **身體的拆件結構沒有加呼吸用的父層**：這不在必修裡，拆件表裡已註明做呼吸時要在身體、頭、手臂外面再包一層。地面陰影在夜紙上偏亮的問題也一樣，只在拆件表裡註明。
- **沒有新增姿勢或變體**：概念圖仍然是主姿勢加兩個情緒縮圖；`checks/rig.png` 是品牌評審要求的旋轉測試，不是新姿勢。
