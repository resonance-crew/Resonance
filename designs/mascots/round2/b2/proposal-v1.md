# B′｜漾漾 Tint

**一句話定位**：一隻用色鉛筆畫出來的小傢伙。頭頂有一片削鉛筆刨下來的木屑，胸口留著一滴鉛筆繞開的空白，等故事來把它塗上顏色。

概念圖：`concept.png`；角色本體：`character.svg`（`character.png` 是它的渲染）；剪影草案：`explore.png`；形體檢查：`checks/silhouette.png`。所有圖都由 `gen.py`、`explore.py` 以 SVG 畫出。

## 1. 角色概念

- **核心想法**：每一張故事卡在共振都有自己的色系。漾漾是一支色鉛筆畫出來的小生物，身上大多已經塗好了，只有胸口留下一滴空白。它讀到一個故事，那個故事的顏色就會從底部把這滴空白塗滿。被深深打動的時候，顏色會滿出來，在全身漾開；頭頂那片木屑也會像扇子一樣整片張開。
- **靈感來源**：削鉛筆時刨下來的木屑。木屑內側是木頭色，帶著放射狀的木紋；外緣是一圈波浪狀的筆桿漆色。六角形的筆桿削一圈會出現六個波浪，所以木屑的邊緣是起伏的，這個起伏就是漾漾頭冠的邊。木屑外緣的顏色就是它自己那支筆的顏色：薰衣草色。概念圖裡，它腳邊躺著那支薰衣草色鉛筆和一片木屑，這是全圖唯一的場景。
- **和品牌的關係**：它不用象徵「共鳴」，只要把讀故事這件事做出來：讀，然後被染上顏色。被染上的顏色就是那張卡片的色系（桃、薰衣草、鼠尾草、麥黃、霧藍、玫瑰），所以首頁上每一次互動，它身上的顏色都會不一樣。「每個人不一樣，但能彼此理解」在這裡就是：同一個角色，被不同的故事染成不同的顏色。

## 2. 外型設計

- **輪廓**：頭是一顆寬寬的軟方圓（上緣略平、兩頰略鼓），比身體寬很多。頭頂正中偏右立著一片 V 字形的木屑扇，從一個點長出來，往兩側張開。身體是一顆蛋，頭直接壓在身體上，交界處兩側內收，有一道頭的陰影。兩條細長的軟管手臂，末端是奶油色的連指手套。短腿，配上又扁又長、腳尖朝外的腳。
- **比例**：頭的高度約占全身（不含木屑）50%，含木屑約 60%。手臂舉起時，手套頂端和頭頂齊高。
- **五官**：
  - 眼睛：深靛色（不是黑色）、上窄下圓的豆形，兩眼中心距離約為頭寬的 25%，比 ChatGPT 公式的約 40% 近很多。整張臉集中在頭的中下段，額頭大。眼睛裡的亮點是鉛筆跳過紙面留下的白，不是貼上去的圓點。每隻眼睛上方有一筆眼皮線，越過外眼角後往上一勾，表情主要靠它：抬高是驚喜，壓低是專心或想睡，往內斜是擔心。
  - 嘴：一邊高一邊低的小開口，像話剛要說出口，不用 ω。
  - 腮紅：每邊三筆短斜線，杏色，不畫圓餅。
- **材質**：全身都是色鉛筆，看得到紙紋顆粒和斜向排線。手套和胸口那一滴是「沒塗到的紙」。
- **主要色彩（OKLCH）**：

| --- | --- |
| 身體主色（薰衣草） | `oklch(82% 0.045 293)` |
| 頭頂受光 | `oklch(88% 0.032 300)` |
| 下半身、偏藍 | `oklch(77% 0.05 280)` → 霧藍 `oklch(75% 0.048 248)` |
| 陰影排線 | `oklch(68% 0.058 285)`、`oklch(65% 0.058 252)`，最深處 `oklch(56% 0.062 275)` |

- **最有辨識度的特徵**：頭頂的木屑扇，剪影就靠它；其次是胸口那一滴有「水位」的空白，它讓正面可以辨認。

## 3. 個性與情感

- **第一印象**：安靜、好奇、很會聽故事的小傢伙。主動打招呼，但不吵鬧。
- **兩個情緒刻度**，都能做成連續的數值，方便動畫和互動控制：
  - **木屑冠的開合**（0 到 1）：收攏成一把合起來的扇子（害羞、專心、想睡）→ 半開（平常、打招呼）→ 整片張開到將近 190°，外緣染成故事的顏色（被打動、驚喜）。
  - **胸口的水位**（0 到 1，再加上溢出）：空的 → 讀到一半 → 滿了 → 溢出來，在身體上漾開。
- **其他表情**靠眼皮線、眼睛開闔、嘴形和手的位置。概念圖裡畫了三個：打招呼（主姿勢）；被故事打動（閉眼微笑、一滴淚、雙手捧著臉頰、木屑全開、胸口溢色）；讀故事（雙手拿著一張小卡、眼皮壓低往下看、木屑收攏、水位一半）。

## 4. 手繪風格與 SVG 技法

- **色鉛筆底色**：每個部位先用漸層填色，再用 `feTurbulence`（細的非等向紙紋，加上慢速的手壓變化）做成 alpha 遮罩，咬出紙面的小白點。越靠近邊緣，鉛筆越淡（`f-tooth1`）。
- **排線**：用程式產生一筆一筆兩端尖、中間略彎的筆觸（`taper_stroke`），以約 −57° 的方向排線，像右撇子畫的。依部位的明暗權重撒點：背光側用紫、藍、深紫三層疊色，受光側用淺薰衣草和一點奶油色。排線層只吃到紙紋的頂端（`f-tooth2`），所以看得到底色。
- **手的抖動**：每個部位的填色、排線、描邊都放在同一個低頻 `feDisplacementMap`（`f-warp`）裡，一起變形，所以不會對不準。小部位（手套、腿、腳）改用擺幅較小的 `f-warp-s`，形狀才不會被抖散。
- **鉛筆描邊**：沿輪廓算出每一點的法線。背光側（右下）壓力大，線比較粗；受光側壓力小，偶爾會斷開。另外有一道較淡的第二筆，稍微偏離第一筆。最後加上石墨跳紙的顆粒（`f-grain`）。
- **深色的記號**（眼、嘴）：濃密的筆觸，邊緣粗糙（`f-ink`）。腮紅和溢出的顏色用 `f-bleed`，像吃進紙裡一樣，沒有硬邊。
- **夜紙**：每個部位底下有一層往內縮 6 單位的底色，顏色從 CSS 變數讀（`--b2-under-lav` 等，值寫在 `gen.py` 的 `NIGHT_VARS`）。白天不設定，紙紋的白點就是紙本身；夜裡設成淺色，白點仍然亮亮的，邊緣那 6 單位則照樣是斷的。描邊顏色也用變數（`--b2-pen`）在夜裡調亮。

## 5. Landing Page 的應用想像

- **出場**：木屑先從首頁某團色塊的後面冒出來，晃兩下，接著頭、眼睛探出來，再用扁扁的腳小步走進畫面。
- **停留**：呼吸（身體 scaleY 1 到 1.02）、眨眼、木屑隨著呼吸輕輕擺動，眼睛跟著游標看。
- **和故事卡互動**：訪客把游標移到某張故事卡上時，它轉過去讀，木屑收攏、眼皮壓低。卡片被打開時，胸口的水位用那張卡片的色系升起來，木屑張開。停在某個顏色一陣子後，顏色慢慢退掉，回到空白。
- **和另一個角色互動**：兩個角色相遇時互相招手。如果靠得很近，兩人胸口的顏色會互相漾到對方身上，像首頁那些色塊碰到時會融在一起。
- **離場**：揮手，轉身小步走出去；或者縮到色塊後面，最後只剩木屑露在外面晃一下，然後收進去。

## 6. 未來系列化的潛力（只寫不畫）

不是換顏色，而是換**畫它的那支筆**，以及**它胸口留的空白**：

1. **筆的種類決定材質和個性**：色鉛筆（漾漾，細緻、安靜）；蠟筆（筆觸粗厚、邊緣蠟亮，標誌是一圈剝下來的包裝紙，個性大方）；水彩色鉛筆（邊緣會暈開，標誌是被水化開的筆尖，個性多愁善感）；炭筆（霧霧的、會弄髒手，標誌是一小撮炭粉，個性屬於深夜、話很少）。
2. **筆的狀態決定體型**：剛削好的長鉛筆是瘦高的角色；用到只剩一小截的鉛筆頭是矮胖、年紀比較大、聽過很多故事的角色；斷過芯又接起來的鉛筆，身上有一道接縫。
3. **空白的形狀決定它收集哪一種故事**：一滴（情緒）、一個摺角（回憶）、一個圓（季節與日常）。要做到形狀不同，不是同一個模板換顏色。

## 形體自我檢查（`checks/silhouette.png`、概念圖 a 欄）

- **純黑剪影（200 px）**：寬方圓的頭、頭頂一片 V 字扇、蛋形身體、兩隻扁腳；一隻手高舉，手套比頭頂略高，另一隻手往外垂，和身體之間有空隙。一句話描述：「一個頭頂插著一片扇子的小傢伙在招手」。
- **48 px**：彩色版看得到頭右上方的奶油色手套點和頭頂的木屑；純黑版裡，舉手是頭右側的一個凸起，木屑是頭頂的小冠。胸口那一滴在 48 px 看不見，這可以接受，它是近看才看的細節。
- **左右翻轉**：讀法不變，只是改成用左手招手。
- **上下顛倒**：蛋形身體和兩隻扁腳到了上面，像一個有兩個小把手的瓶子；寬頭到了下面。沒看到任何人體部位或器官的聯想。
- **過程中發現並修掉的問題**：
  1. 第一版的胸口是一塊奶油色橢圓，看起來就是布偶的奶油色肚子，邊緣還有點毛毛的。改成胸口偏上的一滴，裡面有水位線，讀起來像一個小瓶子或徽章，不像肚子，也不像肚臍。
  2. 第一版的頭冠是 150° 的寬扇，坐在頭頂正中央，剪影變成「戴了一頂漁夫帽」。改成從一個點長出來、大約 100° 的 V 字扇，拿掉後面那一片。
  3. 試過把木屑放到頭的左上角，結果它和右上方舉起的手套在剪影裡變成一對「老鼠耳朵」。所以放回頭頂。
  4. 垂下的那隻手原本貼著身體，剪影裡會黏成一團，所以往外擺開。
  5. 第一版主色考慮過霧藍，但「藍色身體＋白色圓手＋白肚子」就是哆啦 A 夢，所以改成以薰衣草為主、霧藍只在下半身。手套也做成有大拇指的連指手套，不是圓球。
  6. 全身沒有膚色、桃色、粉米色；腳是扁長的，不是底部成對的圓球；沒有脖子、柄、莖。
- **遮臉測試**：「這是什麼？」答案應該是「一個頭上插著一片鉛筆木屑的小傢伙」，不是動物，也不是一團東西。

## 參考與避免仿作

- **相近的既有角色，以及刻意避開的特徵**：
  - **天線寶寶的 Tinky Winky**（紫色、頭頂有天線、肚子有螢幕）：漾漾的頭頂是會開合的扇形木屑，不是天線；胸口只有一小滴有水位的空白，不是長方形螢幕；頭很大，臉直接畫在頭上，不是穿著連身衣、臉在窗裡。這是我覺得最需要留意的一個，色系和「頭頂＋胸前」的配置有一點遠親的味道。
  - **哆啦 A 夢**（藍身體＋白圓手）：主色改成薰衣草，手是有大拇指的手套，沒有白臉、白肚子、鈴鐺。
  - **彩虹熊的肚子圖案**：胸口不是圓形白肚，也沒有圖案，只有一滴空白和水位。
  - **Kirby、胖丁的圓身加一撮捲毛**：頭是方圓，身體分開，木屑是扇形，不是捲毛。
  - **三麗鷗、皮卡丘、史迪奇、大耳狗**：完全沒有耳朵，剪影並排不會認錯。
  - **Sonny Angel**（頭戴動物帽）：木屑是它身體的一部分，會隨情緒開合，不是帽子。
  - 另一個要留意的是：木屑扇單獨看可能讓人想到銀杏葉或扇貝。靠的是外緣那圈筆漆色、放射狀木紋，以及底部那一小點深色筆芯，讓它讀得出是鉛筆木屑；首頁第一次出場時，可以讓角色旁邊出現那支鉛筆。
- **從 ChatGPT 參考圖學到、並用上的原則**：
  - 結構文法：頭大身小、頭身之間收窄、手腳都有清楚的末端、正面有一個記號。
  - 參考圖 2：手臂是可以單獨轉動的長條，末端是奶油色手套，舉起來可以高過頭，肩膀就是關節點。
  - 參考圖 1：同色系較深的鉛筆外框、紙紋顆粒、柔和的兩色疊色。
  - 參考圖 3：「會動的標誌部位就是情緒刻度」（參考圖用耳朵，漾漾用木屑扇）。
- **刻意沒有照抄的**：任何哺乳類耳朵；分很開的黑橢圓眼＋ω 嘴＋圓腮紅這張臉；絨毛、肉球、奶油色肚子這組布偶配件；正面站好、雙手下垂的布偶站姿；剪紙貼紙的白色撕邊（那是 C 的材質，B′ 不搶）。

**前端技術建議**：
- **Rive（建議）**：用骨頭做軟管手臂和肘的彎曲，用網格做木屑扇的開合；狀態機裡放兩個數值，「木屑開合」和「胸口水位」，加上「故事色系」這個參數，正好對應這個角色的核心互動。
- **Lottie**：不支援 SVG 濾鏡，鉛筆質感必須先輸出成點陣圖層，網格變形也比較弱。可以做，但木屑開合會比較生硬。
- **純 SVG／CSS**：只用 transform 移動各部位群組，適合靜態圖加上很輕的待機動作。
- **效能風險**：現在的質感來自即時的 `feTurbulence`／`feDisplacementMap`。只要動畫在動，每一格都要重算濾鏡，手機上一定會卡。上線前請把每個部位「烤」成 2x 的 WebP 點陣圖層，再拿去做動畫。若想保留手繪的抖動，可以為每個部位準備 2 到 3 張略有不同的紋理，每秒換 8 次左右（「線條沸騰」效果），成本很低，也很有色鉛筆的感覺。
- 換色系時，只要換水位、溢色和木屑外緣這三層的顏色，可以用 CSS 變數或 Rive 的顏色參數控制，不需要重畫。

## 自評

- **最強**：
  1. 兩個標誌都是情緒刻度，也都來自鉛筆和紙的世界（木屑會開合，空白會被塗滿），和「讀故事、被打動」直接接上。胸口的顏色就用那張故事卡的色系，品牌連結很自然，不需要硬扯象徵。
  2. 保留了業主喜歡的色鉛筆質感和兩色疊色的漸層，同時補上第一輪缺的結構：頭身分開、有手套的手、扁平的腳、正面記號。縮到 48 px，打招呼還是讀得出來。
- **最弱**：
  1. 手臂是細長的軟管，舉手時要拉長約 1.4 倍才碰得到頭頂；垂下時手套位置偏低，近看有一點「麵條手」。之後可以讓肩膀再寬一點，或讓垂下的手更常拿著東西。
  2. 木屑扇單獨看，可能被讀成銀杏葉或扇貝，「鉛筆木屑」這層意思需要靠第一次出場的那支鉛筆來說明。另外，「薰衣草色＋頭頂一個東西＋胸前一個記號」和 Tinky Winky 有一點遠親的味道，需要業主看看是否在意。
  3. 質感完全靠 SVG 濾鏡，動畫前一定要先烤成點陣圖，否則效能有風險。
