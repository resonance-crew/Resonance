# 第二輪 B×C｜片片 Flick（色鉛筆剪紙貼紙）

**一句話定位**：一個用色鉛筆上色的剪紙小傢伙。腦後插著幾張故事卡，聽到故事時，卡片會一張張扇開。

- 角色本體：`character.svg`（800×800，透明背景，可拆件）／`character.png`
- 概念圖：`concept.svg`／`concept.png`（1600×1000）
- 剪影草案：`explore.svg`／`explore.png`
- 檢查圖：`checks/sheet.png`（48／96px、純黑剪影、上下顛倒、左右翻轉、夜紙）、`checks/poses.png`（三個姿勢並排）、`checks/shy.svg`、`checks/moved.svg`
- 產生器：`gen/kit.py`（撕邊幾何、鉛筆筆觸、濾鏡）、`gen/flick.py`（角色與姿勢）、`gen/concept.py`、`gen/explore.py`。執行 `python3 -I gen/flick.py`、`python3 -I gen/concept.py` 就能重畫。

## 剪影草案與選擇

`explore.png` 裡有三個草案，都是同一個方向：「會被故事打開的紙」。

1. **卡扇**：腦後插著幾張故事卡，聽故事時扇開。
2. **信封蓋**：頭是一個信封，蓋子會往上翻開。
3. **衍紙捲**：頭上有一捲捲起來的紙條，打開後變成一道浪。

選 1。卡扇在剪影上是一組分開的紙片，收起、半開、全開三種狀態一眼就看得出來，能直接當情緒刻度。它用的又正好是共振的產品本身：故事卡和卡片的色系。2 的信封蓋翻開後，剪影像一棟有屋頂的房子，「長了臉的信封」也很常見。3 的紙捲收起時像頭上的包包頭或蝸牛殼，打開後變成一根觸角，剛好違反「柄、莖」的禁令。

## 第二輪改了什麼

這是新的混合方向，不是摺摺換畫法，也不是漾漾剪成紙。下面依照業主第一輪的回饋，逐條說明怎麼處理：

| 業主的回饋 | 這一輪的做法 |
| --- | --- |
| 喜歡 B 的色鉛筆畫法，尤其是第一版的漸層 | 每片紙都是先畫在奶油色畫紙上，再撕下來。底色有紙紋留白，從受光面到背光面是一層漸層，上面再疊斜向排線，陰影裡混一點霧藍色鉛筆，邊緣內側有一圈斷斷續續的同色系深色鉛筆線 |
| 喜歡 C 的剪紙貼紙材質，放在畫面上像一張貼紙 | 每一片紙外圍都有白色撕紙纖維邊，還有淡淡的貼紙投影；卡片和手套用比較薄的紙，撕邊和投影也比較細 |
| A、B 的形體不對，顏色讓人聯想到皮膚甚至生殖器 | 身體主色是薰衣草紫，不用任何肉色系。沒有脖子，沒有長莖，底部沒有成對的圓球（腳是比高度寬很多的扁平紙片），頭和身體分得很清楚 |
| C 的手短短的很可愛，但舉起來看不出在舉手，末端沒有東西 | 手臂是用銅釘固定在肩膀上的紙條，末端是一隻奶油色、有大拇指的圓手套。紙條是「抽拉式」的，舉手時會從銅釘下抽長，手套能舉到頭頂的高度。48px 的純黑剪影裡，仍看得出一隻斜舉起來的手 |
| 業主補充：ChatGPT 的圖都有點像史迪奇或皮卡丘 | 全身沒有任何耳朵，剪影的標誌是故事卡扇。臉不用「分很開的黑橢圓眼＋ω 嘴＋圓紅腮紅」：眼睛是打孔打出來的洞，位置在頭的正中間，沒有腮紅，只有情緒強烈時才在臉頰畫三道鉛筆短線。不用絨毛、肉球，也沒有奶油色大肚子 |

**試過但拿掉的東西**（都有渲染出來比較過）：

- **霧藍色身體**：藍色身體配奶油色圓手套，很像哆啦 A 夢，所以改成薰衣草紫。
- **兩段式手臂**：手肘也用銅釘，看起來像機器人或人體模型。改成一條紙條，只在肩膀釘一顆銅釘。
- **故事卡置中插在頭頂**：純黑剪影像一頂高禮帽，彩色時又像插在烤吐司機裡的吐司。現在改到右上方，往一側扇開，卡片也變窄，剪影就是三片分開的紙片。
- **舉起的手停在頭的左上角**：剪影裡像一隻熊耳朵。手臂改成往外斜舉，手臂和頭在剪影上分開了。
- **眼睛上的睫毛線**：看起來像在斜眼、不以為然。改成兩道柔和的弧形鉛筆眉。
- **圓角方形的頭**：像石頭或機器人的頭。改成柔軟的超橢圓，下緣稍微寬一點。
- **口袋裡露出的綠色卡角**：太像一片嫩芽，改成麥黃色、方角、有一道鉛筆線的卡片角。

## 1 角色概念

**核心想法**：片片是一個用紙剪出來的小傢伙，頭、身體、手腳都是畫紙剪下來後，再用色鉛筆塗上顏色。它腦後插著幾張故事卡，就像有人把鉛筆夾在耳後一樣自然。平常卡片收著，只露出一點角；有人開始說故事，卡片就一張張扇開。聽得越投入，扇得越開。胸前的小口袋裡也藏著一張卡，那是它準備好要送人的故事。

**靈感來源**：
- 手裡握著一把撲克牌、慢慢把牌攤開的動作：每張牌繞著同一個點轉開。
- 用雙腳釘（銅釘）固定關節的紙偶，還有立體書裡的「抽拉紙條」機關。
- 手帳和剪貼簿裡撕下來的紙，以及它的白色纖維邊。
- 共振本身的故事卡：每張卡有自己的色系（桃、薰衣草、鼠尾草、麥黃、霧藍、玫瑰）。

**和共振理念的關係**（呼應，不硬扣象徵）：
- 它的標誌不是某種動物的部位，而是「聽故事」這件事本身的樣子：故事讓它打開。
- 卡扇裡每張卡的顏色都不一樣，代表它聽過不同的人、不同的故事。
- 兩個角色相遇時可以交換一張卡（見第 5 節），每個角色的卡扇就會留下別人的顏色。這是「每個人都不一樣，但能彼此共鳴」最直接、也最安靜的畫面。
- 遮住臉問「這是什麼？」，可以用一句不提動物的話回答：「一個腦後插著故事卡的紙做的小傢伙」。

## 2 外型設計

**輪廓**：
- 頭是一片柔軟的超橢圓紙，約 302×236，下緣稍寬。
- 身體是一片比頭窄的圓梨形紙，約 232×170。頭壓在身體上面，中間收窄，但沒有脖子。
- 右上方插著三張故事卡，往右扇開，這是剪影的標誌。
- 兩條手臂紙條用銅釘固定在身體上緣兩側，末端是奶油色圓手套。
- 兩條短腿，腳是扁平的紙片，略微朝外。

**比例**（以 800 畫布的主姿勢為準）：
- 頭頂到地面約 480，頭占 236，約一半。連同卡扇，頭部這一團占全高約六成。
- 手臂休息時約 150 長，手套在臀部旁邊；舉起時紙條抽長到約 215，手套到頭頂的高度。

**五官**（全部在 `bc-face` 裡，不烤進頭）：
- **眼睛**：兩個打孔打出來的洞，略直的橢圓，左大右小一點點。洞裡是深紫墨色，上緣再暗一層（紙板邊的陰影），只有一個小反光。主姿勢的下緣微微往上推，看起來像在笑。眼距約頭寬的三成，位置在頭的正中間，不偏低。
- **眉毛**：兩道柔和的鉛筆弧線，情緒都靠它：抬高是好奇，中間往上皺是不安。
- **嘴巴**：一個小小的半月形孔，上緣平、下緣圓，裡面露出一點赤陶色的舌頭。安靜時換成一條鉛筆弧線。
- **腮紅**：沒有。害羞或被感動時，才在臉頰畫三道斜斜的鉛筆短線。

**材質**：
- 奶油色畫紙上塗色鉛筆，紙紋會從筆觸的空隙露出來。
- 每片紙外圍都有白色撕紙纖維邊和淡淡的貼紙投影。
- 卡片和手套用比較薄的紙。
- 肩膀上有黃銅色雙腳釘。
- 胸前有一個奶油色紙口袋，縫線是鉛筆畫的虛線，口袋裡露出一角麥黃色卡片。

**主要色彩**（括號是 SVG 裡的 CSS 自訂屬性，可以換主題或夜色）：

| 部位 | 色值 |
| --- | --- |
| 鉛筆底下的畫紙（`--bc-paper`） | `oklch(96.8% 0.012 85)` |
| 頭：薰衣草（`--bc-head`） | `oklch(85% 0.034 296)` |
| 頭的陰影／深色（`--bc-head-shade`／`--bc-head-deep`） | `oklch(72% 0.05 292)`／`oklch(59% 0.06 288)` |
| 陰影裡混的霧藍鉛筆（`--bc-head-mix`） | `oklch(78% 0.04 245)` |
| 身體、手臂、腿：深一階的薰衣草（`--bc-body`） | `oklch(75% 0.045 290)` |
| 身體的陰影／深色 | `oklch(64% 0.055 288)`／`oklch(51% 0.06 284)` |
| 手套、口袋：奶油色（`--bc-mitt`） | `oklch(95.5% 0.022 88)`，陰影 `oklch(86% 0.035 78)` |
| 打孔的洞（`--bc-ink`） | `oklch(31% 0.04 282)`，上緣 `oklch(19% 0.03 282)` |
| 銅釘 | `oklch(76% 0.085 82)` |
| 故事卡色帶 | 麥黃 `oklch(89% 0.06 88)`、鼠尾草 `oklch(86% 0.05 140)`、桃 `oklch(88% 0.05 52)` |
| 撕紙纖維邊 | `oklch(98.5% 0.008 85)` |
| 揮手、亮光的鉛筆記號 | `oklch(58% 0.06 285)`（中間色調，奶油紙和夜紙上都看得到） |

身體只有薰衣草紫這一個色系，暖色只出現在故事卡的色帶上，而且面積很小。

**最具辨識度的特徵**：腦後那一手故事卡。它會從「收起、只露一角」變成「半開」，再變成「全開、往外冒亮光」。在 48px 的純黑剪影裡，仍看得到右上方三片分開的紙片。

## 3 個性與情感

**第一印象**：安靜、好奇、願意聽。它不搶話，可是你一開口，它腦後的卡片就先動了。

**個性**：一個收集故事的聽眾。一開始有點害羞，卡片收在腦後；慢慢信任你以後，卡片才會扇開。被故事打動時，它會把胸前口袋裡那張卡拿出來送給你。

**情緒怎麼表現**（標誌部位、眼睛、手三者一起動）：

| 情緒 | 卡扇 | 眼睛與眉 | 手 |
| --- | --- | --- | --- |
| 安靜／害羞 | 收起，沉到頭後，只露出一角 | 上眼瞼壓低、眼神看旁邊，眉心往上 | 垂在兩側 |
| 好奇／在聽 | 半開，中間那張稍微抬起 | 圓眼、抬眉 | 自然垂下或托著臉 |
| 打招呼 | 半開 | 下緣微笑 | 紙條抽長，高舉揮手 |
| 被故事打動 | 全開，往外冒鉛筆亮光 | 眼睛笑成彎彎的縫，臉頰三道鉛筆線 | 雙手張開 |
| 低落 | 三張卡一起往後垂 | 眼睛下垂 | 手垂到最短 |
| 想分享 | 一張卡抽得特別高 | 眼睛看向那張卡 | 從胸前口袋抽出一張卡 |

## 4 手繪風格（SVG 技法）

全部是純 SVG，自己畫的，沒有外部圖片或字型。所有 id 都以 `bc-` 開頭。

- **撕紙邊**（學自第一輪 C）：每片紙的輪廓是種子化的 Catmull-Rom 曲線，再沿法線推出「緩慢漂移＋細碎咬痕」，就是手撕的邊（`kit.tear`）。濾鏡 `bc-paper`、`bc-thin` 的做法：
  - 先用低頻 `feTurbulence` 加 `feDisplacementMap`，讓邊緣再撕一次。
  - `feMorphology dilate` 擴出一圈，再用高頻雜訊擾動，填上近白色，就是白色纖維邊。
  - 模糊加位移，做出貼紙投影。
  - 最後疊上紙張纖維的斑駁和少量纖維斑點。
- **色鉛筆**（學自第一輪 B 第一版）：
  - 每片紙先鋪一層奶油畫紙底。
  - 再鋪一層從亮到暗的 `linearGradient` 色層，用 `bc-tooth1` 遮罩：細的各向異性雜訊當紙紋，粗的雜訊當手的輕重，邊緣再淡一點，所以紙紋會從色層裡露出來。
  - 上面疊三組手產生的斜向錐形筆觸，用 `bc-tooth2` 讓筆觸只附著在紙紋的凸點上：背光面的陰影、靠邊的深色、混入的第二支霧藍鉛筆。受光面用奶油色筆觸「擦亮」。
  - 邊緣內側加一圈斷斷續續的深色鉛筆線（`bc-graphite`）。
  - 筆觸的寬度和數量會依照每片紙的大小調整，所以小紙片也是細筆。
- **故事卡**：薄紙、頂端是色帶，下面是一圈圈的鉛筆連筆（像字但不是字）。鼠尾草色那張的色帶上畫了三道小波浪，呼應共振的標誌。
- **臉**：眼睛和嘴是「打孔」，用深色填滿，上緣疊一層更深的陰影，只留一個小反光；`bc-punch` 讓孔的邊緣帶一點點紙纖維。眉毛和臉頰線是多次輕微偏移的鉛筆線。
- **一支筆原則**：所有鉛筆線都經過同一個 `bc-graphite` 濾鏡，和網站「同一支筆畫的」手繪感一致。
- **夜紙**：每片紙都自帶奶油畫紙底和白色撕邊，所以放在 `oklch(21% 0.012 60)` 上，輪廓由白邊撐住，裡面的鉛筆線不會消失（見概念圖 b）。

## 5 Landing Page 的應用想像

- **出場（探頭）**：先只有三張卡的卡尖從畫面側邊冒出來，像有人在牆後偷看。接著頭探出來，眨一次眼，再用紙偶的步伐走進來：腿繞著髖部擺動，身體每一步上下彈一下。
- **停留**：
  - 待機時身體做極小的呼吸（`scaleY` 1 到 1.02），每 4～7 秒眨一次眼，卡扇跟著呼吸開合 ±3°。
  - 臉（`bc-face`）會往游標的方向平移 ±6，眼睛再多移 ±4。
  - 首頁 hero 的三團色塊漂近時，它抬頭看。
- **互動**：
  - 游標停在它身上，或停在「真實的人生故事」標籤上時：卡片半開、抽長手臂揮手。
  - 往下捲到卡片牆時，每有一張卡片進入畫面，它腦後就有一張同色系的卡抬高一點。
  - 點它一下：卡片全開、冒出鉛筆亮光，然後從胸前口袋抽一張卡遞出來，可以當作「讀一則故事」的入口。
- **兩個角色**：
  - 兩隻相遇時先互相注意（臉轉向對方），各自抬起一張卡，然後交換。
  - 一張卡繞著兩人之間的弧線飛過去，插進對方的卡扇。
  - 之後兩人的卡扇裡都有對方的顏色，這就是「共振」留下的痕跡。
- **離場**：卡片收起、手最後揮一下，然後像一張貼紙被撕起來那樣，從一角翹起滑出畫面（進階做法）；簡單做法是轉身走出去。
- **減少動態**：遵守 `prefers-reduced-motion`，只顯示靜態主姿勢。

## 6 未來系列化的潛力（只寫不畫）

系列裡的每一位都遵守同一套結構文法：頭身分明、紙條手配圓手套、正面有一個紙做的記號、頭部有一樣「會被故事打開的紙」。三個差異軸如下：

1. **它收著的紙，以及這張紙怎麼打開**
   - 片片：一手故事卡，扇開。
   - 另一位：背上一疊明信片，像翻頁一樣一張張翻過去。
   - 另一位：頭頂一張折了四折的信，會一折一折攤開，攤開後才露出裡面的字。
   - 每一位的標誌動作不同，剪影也不同。
2. **紙材和筆**
   - 片片：薰衣草色鉛筆畫在畫紙上。
   - 另一位：蠟筆塗在牛皮紙上，筆觸粗、顆粒大。
   - 另一位：水彩色鉛筆畫在描圖紙上，半透明，疊到別的角色身上時看得見重疊的顏色。
   - 夜晚出現的角色：粉彩畫在黑卡紙上，身上是亮的。
3. **關節的固定方式，也就是動作的個性**
   - 片片：銅釘，轉得乾脆。
   - 另一位：紙膠帶當關節，動作軟、會晃。
   - 另一位：棉線縫的關節，走路一頓一頓。
   - 另一位：卡榫插槽，手腳能拔下來換位置，動作冒失。

- **48px**：
  - 彩色版：看得到薰衣草色的頭身、舉起的奶油色手套，還有頭上三個小色塊。
  - 純黑剪影：仍看得出右上方鋸齒狀的三片，以及一隻往外舉的手。
  - 卡片的字和口袋在這個尺寸會消失，這是預期中的。
- **上下顛倒**：像一個倒立的小人，卡扇變成在左下方的一把扇子，手臂和手套像一個鐘擺。沒有看到器官或人體部位的聯想。
- **左右翻轉**：讀法一樣，只是卡扇換到左邊。角色本來就是不對稱的，翻轉不會讓它變成別的東西。
- **皮膚或人體部位的聯想**：
  - 主色是薰衣草紫，沒有任何肉色。
  - 沒有脖子，沒有莖。
  - 底部沒有成對的圓球：腳的寬度約是高度的 2.5 倍，而且是平底。
  - 手臂是用銅釘固定的紙條，末端的手套有大拇指、顏色也不同，所以讀起來是手，不是「長條加圓球」。
  - 口袋放在胸前偏一側，是方形加縫線，不在身體中線上，所以不會讀成肚臍或其他單點。
- **改過的地方**：
  - 早期版本裡，舉起的手套停在頭的左上角，剪影像一隻熊耳朵，卡扇也像一頂歪掉的帽子，於是把手臂往外斜開、卡片拉開間距。
  - 雙手垂下時太長、碰到地面，看起來像猩猩手，於是改成抽拉式紙條：休息時短，舉起時才抽長。
- **兩個測試**：
  1. 遮住臉問「這是什麼？」，答案是「一個腦後插著故事卡的紙偶」，不是某種動物，也不是一團東西。
  2. 和皮卡丘、史迪奇、大耳狗的剪影並排：它們的剪影都靠一對耳朵，片片頭上沒有對稱的突起，只有一側的一扇紙片，不會被認錯。

## 參考與避免仿作

**相近的既有角色，以及刻意避開的地方**：
- **哆啦 A 夢**：藍色身體加白色圓手和肚子上的口袋。片片的主色改成薰衣草紫，沒有白臉、白肚子、項圈；手套有大拇指；口袋是偏一側的小紙口袋，不是肚子正中央的半月形。
- **紙箱機器人阿楞（Danbo）、一般機器人公仔**：不用方塊。關節只在肩膀有銅釘，不在手肘、膝蓋上打釘，頭和身體都是軟的曲線。
- **Tearaway 的 Iota（信封頭）、Paper Mario**：頭不是信封，也不是會翻面的薄紙片人。卡片是插在腦後的獨立物件。
- **奶昔大哥（Grimace）等紫色吉祥物**：頭身分明，身體小，紫色低彩度，又有卡扇，剪影完全不同。
- **大耳狗、ChatGPT 第三張的淡紫色垂耳狗**：沒有任何耳朵。
- **史迪奇、皮卡丘**：沒有耳朵、沒有 ω 嘴、沒有圓紅腮紅。
- **第一輪的摺摺**：
  - 摺摺的標誌是它自己身體的一角往前折下來；片片的標誌是插在腦後、獨立的幾張卡，會繞著同一點扇開。
  - 摺摺的身體是一整張撕下來的圓紙，片片頭身分開。
  - 摺摺的手是貼上的碎紙片，片片是銅釘紙條加手套。
  - 摺摺的腿是風琴摺，片片是短腿加扁平腳。
- **第一輪的漾漾**：不從池子升起，沒有細頸，也不用杏桃膚色。

**從 ChatGPT 參考圖學到的原則**：
1. **結構文法**：大頭配上分得開的身體，手腳有清楚的末端，剪影有一個突出的標誌。這樣角色不會怪（來自第一張）。
2. **手**：手臂是用銅釘固定的獨立紙條，末端是奶油色圓手套，銅釘剛好就是動畫的關節點（來自第二張）。片片直接採用這個做法，再加上「抽拉」，讓舉手能高過頭。
3. **材質**：白色撕紙邊、紙上的色鉛筆顆粒與漸層（來自第三張）。
4. **用一個部位當情緒刻度**：第三張是「耳朵垂下和豎起」。片片把這個原則搬到卡扇上：收起、半開、全開。

**刻意沒有照抄的部分**：
- 任何形狀的動物耳朵。
- 低而分很開的黑橢圓眼、ω 嘴、圓紅腮紅。
- 絨毛、肉球、奶油色大肚子。
- 第二張那種沒有頭、整體是一團的身體，以及它右上角的折角。
- 第三張的垂耳狗形體。

**技術建議**：
- **動態本身很簡單**：所有動作都是剛體的旋轉和位移（卡片繞同一點轉、手臂繞銅釘轉加上沿軸位移、眼睛縮放），沒有變形，用 SVG＋CSS 或 Web Animations 就能做。
- **效能風險在濾鏡**：撕邊、色鉛筆用的 `feTurbulence`、`feDisplacementMap`、`feMorphology` 很吃效能，如果每一格都重算，手機上會掉格。
  - 建議做法：把每個部位連同紙紋，先烘成 2 倍解析度的 WebP 或 PNG 圖層，執行時只移動圖片。
  - 首頁上的靜態圖，可以直接用 SVG 原檔。
- **Rive 很適合**：骨骼可以直接對應銅釘和手腕；卡扇三種狀態可以做成 state machine，由 hover 和捲動驅動；檔案小。Lottie 也可以，但同樣要先烘好紙紋貼圖。
- 不建議用 Lottie 重現 SVG 濾鏡。

## 自評

**最強的地方**
- **標誌就是產品本身**：腦後那一手故事卡，用的是共振卡片的色系，同時又是讀得懂的情緒刻度（收起→半開→全開）。在 48px 的純黑剪影裡還認得出來，也很適合延伸成「兩個角色交換卡片」這種共振的畫面。
- **材質正是業主喜歡的組合**：B 的色鉛筆顆粒加漸層，C 的白色撕邊加貼紙投影。在夜紙上靠白邊依然成立。拆件只需要旋轉和位移，動態成本低。

**最弱的地方**
- **頭和身體的形狀都很單純**：臉也偏向主流的可愛（大而深的眼睛），角色的原創性大多靠卡扇和材質撐著。如果卡扇被遮住，它就是一個普通的紫色紙偶。
- **兩個妥協和一個成本**：
  - 「抽拉手臂」是動畫上的妥協：舉起的手比休息時長，仔細看的人會發現。
  - 薰衣草色在大面積時有一點「紫色吉祥物」的感覺。
  - 色鉛筆和撕邊都很依賴濾鏡，正式做動畫前，一定要先把紋理烘成圖片。
