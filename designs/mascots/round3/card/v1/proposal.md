# 摺摺系列 · 第三輪｜卡片：聆聆 Nod

**一句話**：一張淡紫色的橫式索引卡。你說話的時候，它一邊點頭，一邊把重要的話記在格線上；頭上歪戴一頂深青綠的紙貝雷帽，手長一點，總是微微張開，隨時準備抱人。

檔案（都在本資料夾）：

- `rig.svg`：拆件骨架（照 kit.md「Rig contract」：viewBox 0 0 700 760、地面 y = 700、置中 x = 350、平的 `data-part` 群組）。
- `parts/`：`node ../kit/export-parts.mjs rig.svg parts --scale 0.8` 的輸出，16 個部件，`problems: []`，`recomposeDiffPct: 0`。
- `concept.svg` / `concept.png`（1600×1000）：概念圖。
- `gen/`：產生器。在本資料夾執行 `node gen/build.mjs`，同一組參數（`gen/card.mjs` 的 `G`、`C`）同時寫出 `rig.svg` 和 `concept.svg`。`lib.mjs` 是摺摺的幾何小工具原封不動複製過來的。
- `checks/`：自我檢查圖（見最後一節）。

## 1 角色概念

聆聆是一張從某人的卡片盒裡走出來的索引卡。卡片上方那道赤陶色的標題線，本來是給人寫標題的；底下一行一行的淡藍格線，本來是給人記重點的。它沒有被寫滿：標題欄有一小段鉛筆字，右下角和左下角各有幾個字，其他地方都還空著。

它最喜歡的事是聽。別人說話的時候，它會點頭，把一兩個字記在自己的格線上。聽到真正打動它的故事，整張卡會被字寫滿（`torso-alt`），那是它的「掀開」：摺摺掀開折角給你看底下的字，聆聆則是讓你看見它把你的話記了滿滿一張。

和共振理念的呼應（只是呼應）：一張卡片原本是拿來「記下別人說的話」的。聆聆代表「好好聽完一個人說話」這件事。

## 2 紙材與外型

**紙材**：

- 身體：淡紫色索引卡紙 `oklch(84% 0.046 292)`，是**剪刀剪的**卡紙，不是撕的：沿用摺摺的紙材濾鏡，但邊緣位移從 3.2 降到 1.4，保留白色纖維邊、往右下的膠水陰影、紙紋和纖維斑點，所以讀起來是「剪的」。四個圓角半徑各不相同（20–27），上緣有 2 單位的斜度和一點點弧，左右兩邊不是完全的直線，所以它是「一張有人剪過、帶著走過的卡」，不是一個圖示。
- 卡面：一道赤陶色標題線 `oklch(62% 0.14 45)`（全身唯一一大段赤陶色，仍然只是細線）；九道很淡的印刷格線 `oklch(60% 0.06 255)`，透明度 0.36；幾段鉛筆連筆字（是筆跡的節奏，不是真的字）。
- 手臂與腿：同一張卡紙的深一階邊角料 `oklch(67% 0.056 293)`。
- 腿的下半截：往後折的那一面，再深一點 `oklch(60.5% 0.06 295)`。
- 腳：撕出來的梅紫色鞋底 `oklch(50% 0.052 300)`。
- 手套：家族共用的奶油色連指手套 `oklch(93% 0.026 86)`，拇指朝身體那一側。
- 銅釘：家族共用的霧面黃銅。

全身沒有膚色、桃色或粉紅色；最大的兩塊顏色是淡紫（hue 292）和帽子的深青綠（hue 195）。

**業主的三點，對照**：

- **肩膀往下放**：摺摺第二輪的肩釘差不多在眼睛正下方；聆聆的銅釘在嘴巴下方 34 單位，在卡片的正中間高度。
- **銅釘往內移**：兩顆銅釘都釘在卡面上，離側邊 18 單位（約 2.1 個銅釘半徑），手臂紙條的圓頭壓在卡片邊緣上，被銅釘一起釘住；銅釘不再壓在輪廓線上。
- **手短一點**：手臂從銅釘到手套中心 106，整隻伸直（含手套）130，約卡片高的一半。靜止時手套最低點 y ≈ 610–612，在髖部（y = 622）之上；手舉直時手套頂端剛好到卡片頂端（y = 364），還是舉得起來、看得出在舉手。這是系列裡「手比較長」的一隻，但只是「比腿長、夠抱」，不是長手臂。

## 3 頭飾：一頂歪戴的紙貝雷帽

**是什麼**：一頂用深青綠粉彩紙 `oklch(52% 0.06 195)` 剪的貝雷帽。帽緣是一條更深的青綠紙條 `oklch(42% 0.05 200)`，平平地貼在卡片上緣，上面有一排鉛筆縫線；帽身在左邊鼓起，往右斜下，蓋過卡片的右上角，帽簷垂到卡片右邊外面一點。帽子頂端**沒有**小尾巴（貝雷帽常見的那一小截）：試過一版有，剪影裡像鍋蓋的提鈕，也是一根直立的小突起，所以拿掉了。

**為什麼適合它**：

- 聆聆是愛聽故事、愛記字的那種人，貝雷帽是「畫畫、寫字的人」的帽子，戴起來像一個在咖啡館裡安靜聽人說話的小詩人。
- 橫式卡片的頂端是平的，一頂往一邊垂的帽子剛好打破長方形，讓剪影有一個「歪一邊」的重點，不再只是一個盒子。
- 帽子垂在右邊，右手的手套舉起來剛好碰得到帽簷，所以「脫帽打招呼」是它的招牌動作（主姿勢）。

**48px 讀成什麼**：一張淡紫色卡片頭上歪戴一頂深綠色的帽子（`checks/checks.png` 第一列、概念圖 a）。帽子比卡片暗很多，又往右垂過卡片的角，所以讀成「戴在頭上的帽子」，不是耳朵、角或一根突起。32px 時仍是「紫色小卡＋綠帽子」。

顏色是比過五種之後選的（`checks/beret-colours.png`）：芥末黃讀起來像麵包或派皮；可可棕在小尺寸像頭髮或香菇；靛藍和第五隻「夜」的午夜藍紙太像；酒紅是紅色系，業主對肉色、粉色很敏感，所以避開。深青綠最清楚，也和家族裡其他身體的顏色（鼠尾草、霧藍、奶油黃、午夜藍）都分得開。

## 4 個性與情感

**溫暖、穩重、很會聽。** 腿短，走路是小碎步，不趕時間；手長一點，靜止時也微微張開。它很少說話，主要用三件事表達：點頭（身體往前傾一點再回來）、帽子（脫帽、壓低、被嚇到時跳起來）、卡片上的字（聽得越投入，寫得越多）。

| 情緒 | 表現 |
| --- | --- |
| 打招呼 | 右手套托起帽簷，帽子以左邊帽緣為支點往上翹 6°；左手張開；嘴巴張開笑。概念圖主姿勢。 |
| 專心聽 | 臉往下滑一點、眼睛看下面，一下一下點頭（身體前傾 3° 再回來），偶爾眨眼。概念圖 c 左。 |
| 開心 | 眨成笑眼（∩），兩手張開往上，小碎步原地踏兩下，帽子慢一拍跟著彈。 |
| 害羞 | 兩手套貼到臉頰兩側（左手約 −28°、右手約 −152°），腮紅加深；或右手把帽子往下拉一點。 |
| 被故事打動 | 卡片上寫滿了字（`torso-alt`），眼睛瞇起，雙手在胸前抱住自己，帽子往右滑一點。概念圖 c 右。 |
| 陪伴 | 走到對方旁邊，用靠近對方的那隻手搭在對方肩上。 |

## 5 在首頁上會做的事

**出場**：從最近的畫面邊緣沿著一條「台階」（hero 底部的波浪、故事卡上緣、CTA 區的波浪上緣）小碎步走進來：腿左右擺 ±10°、身體上下晃 3 單位、往前進方向傾 2°；停下來後先把帽子扶正（右手碰一下帽簷），再看向訪客。

**活動**（一次停留挑一兩個）：

1. **脫帽打招呼**：見主姿勢。訪客滑鼠靠近時就做這個。
2. **坐在故事卡上讀標題**：坐在一張故事卡的上緣，兩條短腿垂在封面前面晃（一腿往前一腿往後、輪流），臉往下滑、眼睛看下面，點兩下頭。讀完時卡片上的字會多一行（可以只是 `torso-alt` 淡入 30% 再淡出，像記了一筆）。
3. **在「寫下你的故事」旁邊**：用左手往按鈕的方向招一招（左手在 150°–200° 之間來回），再點點頭，像在說「我聽著」。
4. **靠在「瀏覽所有故事」按鈕上**：身體斜靠過去 6°，近按鈕的那隻手搭在按鈕上緣。

**離場**：脫一下帽子當作再見，轉向最近的邊緣小碎步走出去；或者在故事卡後面慢慢往下沉，最後只剩帽子，再一起消失。

**遇到另一隻**：

1. 注意到：臉滑向對方，帽子跳一下（往上 6 單位、慢一拍落回）。
2. 小碎步走到大約一個身體寬的距離。
3. 對對方脫帽。
4. 共振：兩隻一起上下晃兩三拍，中間出現三條鉛筆波浪線，腮紅變深。
5. 聆聆的版本：**抱一下**。它把靠近對方的那隻手往對方伸過去（右手往 −10° 到 0°），手套搭在對方的肩上，兩隻一起晃一拍；或者遞給對方一張小紙條（它本來就是會寫字的卡片）。

**部件**（`rig.svg`，由後往前；pivot 都是 rig 單位）：

| 部件 | parent | pivot | 備註 |

**手臂的角度**（0° = 朝右，90° = 朝下，−90° = 朝上）：

- 大揮手用**左手**：−110° 到 −135° 之間來回。右手舉直會碰到垂下來的帽簷（手臂畫在帽子前面，看起來像扶著帽子），所以右手專門用來脫帽：約 −72°，同時 `deco` 轉 −6°。
- 手平舉橫過身體時，紙條在 y ≈ 494，**在嘴巴下方**，不會遮臉（這是肩膀放低的好處）。左手 −20° 到 −40°、右手 −140° 到 −160° 會碰到臉頰，害羞時才用。
- 抱住自己：左 30°、右 150°。抱別人：靠近對方的那隻手 −10° 到 0°（右手）或 180° 到 190°（左手）。

**注意事項**：

- 臉可以在 ±12 內滑動：往上 12 時眼睛頂端在 y ≈ 410，仍在標題線（402）下方；左右都還在卡面內。
- 帽子往右垂過卡片右緣約 42 單位：身體往右傾、或靠近另一隻時，要算進寬度。
- 膠水陰影是烤在部件裡的（和摺摺一樣），手臂轉很大角度時陰影會跟著轉；在 120px 時幾乎看不出來。
- 夜紙不需要額外部件：同一組圖在 `oklch(21% 0.012 60)` 上靠白纖維邊和淡紫的明度就站得住（概念圖 b）。
- 腮紅用的是摺摺現在的三道斜線；kit 說「摺摺先決定，其他跟著」，如果摺摺改成柔和的圓形，改 `gen/card.mjs` 的 `cheeks()` 再重跑一次即可。
- 所有紙色都是 CSS 自訂屬性（`--cd-card`、`--cd-beret`…），預設值就是日間的顏色。
