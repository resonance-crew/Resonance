# 摺摺系列 · 第三輪｜卡片：聆聆 Nod

**一句話**：一張淡紫色的橫式索引卡。你說話的時候，它一邊點頭，一邊把重要的話記在格線上；頭上歪戴一頂青綠色的紙貝雷帽，右邊軟軟地塌在卡角上；手臂紙條藏在卡片後面，從兩側伸出來，微微張開，隨時準備抱人。

檔案（都在本資料夾）：

- `rig.svg`：拆件骨架（照 kit.md「Rig contract」：viewBox 0 0 700 760、地面 y = 700、置中 x = 350、平的 `data-part` 群組）。
- `parts/`：`node ../kit/export-parts.mjs rig.svg parts --scale 0.8` 的輸出，16 個部件，`problems: []`，`recomposeDiffPct: 0`。
- `concept.svg` / `concept.png`（1600×1000）：概念圖。
- `gen/`：產生器。在本資料夾執行 `node gen/build.mjs`，同一組參數（`gen/card.mjs` 的 `G`、`C`）同時寫出 `rig.svg` 和 `concept.svg`。`lib.mjs` 是摺摺的幾何小工具原封不動複製過來的。
- `checks/`：自我檢查圖（見「自我檢查」與最後的「第三輪評審後修改」）。
- `v1/`：第一版的紀錄（rig、概念圖、提案、`parts/rest.png`、`gen/`），不再修改。

## 1 角色概念

聆聆是一張從某人的卡片盒裡走出來的索引卡。卡片上方那道赤陶色的標題線，本來是給人寫標題的；底下一行一行的淡藍格線，本來是給人記重點的。它沒有被寫滿：標題欄有一小段鉛筆字，右下角和左下角各有幾個字，其他地方都還空著。

它最喜歡的事是聽。別人說話的時候，它會點頭，把一兩個字記在自己的格線上。聽到真正打動它的故事，整張卡會被字寫滿（`torso-alt`），那是它的「掀開」：摺摺掀開折角給你看底下的字，聆聆則是讓你看見它把你的話記了滿滿一張。

和共振理念的呼應（只是呼應）：一張卡片原本是拿來「記下別人說的話」的。聆聆代表「好好聽完一個人說話」這件事。

## 2 紙材與外型

**紙材**：

- 身體：淡紫色索引卡紙 `oklch(84% 0.046 292)`，是**剪刀剪的**卡紙，不是撕的：沿用摺摺的紙材濾鏡，但邊緣位移從 3.2 降到 1.4，保留白色纖維邊、往右下的膠水陰影、紙紋和纖維斑點，所以讀起來是「剪的」。四個圓角半徑各不相同（20–27），上緣有 2 單位的斜度和一點點弧，左右兩邊不是完全的直線，所以它是「一張有人剪過、帶著走過的卡」，不是一個圖示。
- 卡面：一道赤陶色標題線 `oklch(62% 0.14 45)`（全身唯一一大段赤陶色，仍然只是細線）；九道很淡的印刷格線 `oklch(60% 0.06 255)`，透明度 0.36；三段鉛筆連筆字（標題欄一段、右下兩行；是筆跡的節奏，不是真的字）。
- 手臂與腿：同一張卡紙的深一階邊角料 `oklch(67% 0.056 293)`。
- 腿的下半截：往後折的那一面，再深一點 `oklch(60.5% 0.06 295)`。
- 腳：撕出來的梅紫色鞋底 `oklch(50% 0.052 300)`。
- 手套：家族共用的奶油色連指手套 `oklch(93% 0.026 86)`，拇指朝身體那一側。
- 銅釘：家族共用的霧面黃銅。

全身沒有膚色、桃色或粉紅色；最大的兩塊顏色是淡紫（hue 292）和帽子的青綠（hue 195）。

**業主的三點，對照**：

- **肩膀往下放**：摺摺第二輪的肩釘差不多在眼睛正下方；聆聆的銅釘在嘴巴下方 28 單位，約在卡片高度的一半。
- **銅釘往內移**：照摺摺的做法，手臂紙條藏在卡片後面，看得到的銅釘頭畫在卡面上，離側邊 24 單位（約 2.7 個銅釘半徑）；卡片的輪廓線是乾淨的一整條，銅釘落在一整片淡紫紙面上，不在邊上。
- **手短一點**：手臂從銅釘到手套中心 103，其中一半藏在卡片後面，看得到的只有卡片側邊外約 36 的紙條和手套。靜止時手套最低點 y ≈ 615，在髖部（y = 622）之上；手舉直時手套頂端在 y = 381，高過卡片頂端（391），還是舉得起來、看得出在舉手。這是系列裡「手比較長」的一隻，但只是「比腿長、夠抱」，不是長手臂。

## 3 頭飾：一頂歪戴的紙貝雷帽

**是什麼**：一頂用青綠粉彩紙 `oklch(57% 0.055 195)` 剪的貝雷帽。帽緣是一條更深的青綠紙條 `oklch(47% 0.05 200)`，平平地壓在卡片上緣（蓋過卡片頂邊約 10 單位，像真的戴上去），上面有一排鉛筆縫線；帽身扁扁的，左邊薄、在左半邊稍微鼓起，往右斜下，右邊軟軟地塌下來蓋住卡片的右上角，只超出卡片右緣 18。帽頂有三道鉛筆虛線縫線匯到一點（布帽拼片的線）。帽子頂端**沒有**小尾巴（貝雷帽常見的那一小截）：試過一版有，剪影裡像鍋蓋的提鈕，也是一根直立的小突起，所以拿掉了。

**為什麼適合它**：

- 聆聆是愛聽故事、愛記字的那種人，貝雷帽是「畫畫、寫字的人」的帽子，戴起來像一個在咖啡館裡安靜聽人說話的小詩人。
- 橫式卡片的頂端是平的，一頂往一邊垂的帽子剛好打破長方形，讓剪影有一個「歪一邊」的重點，不再只是一個盒子。
- 帽子垂在右邊，右手的手套舉起來剛好碰得到帽簷，所以「脫帽打招呼」是它的招牌動作（主姿勢）。

**48px 讀成什麼**：一張淡紫色卡片頭上歪戴一頂青綠色的帽子（`checks/checks.png` 第一列、`checks/stage-48-zoom.png`、概念圖 a）。帽子比卡片暗很多，帽緣壓在卡片頂邊上、右邊塌過卡片的角，所以讀成「戴在頭上的帽子」，不是耳朵、角或一根突起。32px 時仍是「紫色小卡＋綠帽子」。

顏色是比過五種之後選的（`checks/beret-colours.png`，第一版的比較）：芥末黃讀起來像麵包或派皮；可可棕在小尺寸像頭髮或香菇；靛藍和第五隻「夜」的午夜藍紙太像；酒紅是紅色系，業主對肉色、粉色很敏感，所以避開。青綠最清楚，也和家族裡其他身體的顏色（鼠尾草、霧藍、奶油黃、午夜藍）都分得開。第三輪評審後調亮一階（L 52% → 57%），讓臉先被看到、帽子第二。

## 4 個性與情感

**溫暖、穩重、很會聽。** 腿短，走路是小碎步，不趕時間；手長一點，靜止時也微微張開。它很少說話，主要用三件事表達：點頭（身體往前傾一點再回來）、帽子（脫帽、壓低、被嚇到時跳起來）、卡片上的字（聽得越投入，寫得越多）。

| 情緒 | 表現 |
| --- | --- |
| 打招呼 | 右手移到卡片前面，手套托起右邊塌下來的帽簷，帽子以左邊帽緣為支點往上翹約 7°；左手張開；嘴巴張開笑。概念圖主姿勢。 |
| 專心聽 | 臉往下滑一點、眼睛看下面，一下一下點頭（身體前傾 3° 再回來），偶爾眨眼。概念圖 c 左。 |
| 開心 | 眨成笑眼（∩），兩手張開往上，小碎步原地踏兩下，帽子慢一拍跟著彈。 |
| 害羞 | 兩手移到前面，手套貼到臉頰兩側（左手約 −20°、右手約 −160°），腮紅加深；或右手把帽子往下拉一點。 |
| 被故事打動 | 卡片上寫滿了字（`torso-alt`），眼睛瞇起，雙手移到前面、在胸前抱住自己，帽子往右滑一點。概念圖 c 右。 |
| 陪伴 | 走到對方旁邊，用靠近對方的那隻手搭在對方肩上。 |

## 5 在首頁上會做的事

**出場**：從最近的畫面邊緣沿著一條「台階」（hero 底部的波浪、故事卡上緣、CTA 區的波浪上緣）小碎步走進來：腿左右擺 ±10°、身體上下晃 3 單位、往前進方向傾 2°；停下來後先把帽子扶正（右手碰一下帽簷），再看向訪客。

**活動**（一次停留挑一兩個）：

1. **脫帽打招呼**：見主姿勢。訪客滑鼠靠近時就做這個。
2. **坐在故事卡上讀標題**：坐在一張故事卡的上緣，兩條短腿垂在封面前面晃（一腿往前一腿往後、輪流），臉往下滑、眼睛看下面，點兩下頭。讀完時卡片上的字會多一行（可以只是 `torso-alt` 淡入 30% 再淡出，像記了一筆）。
3. **在「寫下你的故事」旁邊**：用左手往按鈕的方向招一招（左手在 150°–200° 之間來回），再點點頭，像在說「我聽著」。
4. **靠在「瀏覽所有故事」按鈕上**：身體斜靠過去 6°，近按鈕的那隻手搭在按鈕上緣。

**離場**：脫一下帽子當作再見，轉向最近的邊緣小碎步走出去；或者在故事卡後面慢慢往下沉，最後只剩帽子，再一起消失。

**遇到另一隻**：

1. 注意到：臉滑向對方，帽子跳一下（往上 6 單位、慢一拍落回）。
2. 小碎步走到大約一個身體寬的距離。
3. 對對方脫帽。
4. 共振：兩隻一起上下晃兩三拍，中間出現三條鉛筆波浪線，腮紅變深。
5. 聆聆的版本：**抱一下**。它把靠近對方的那隻手往對方伸過去（右手往 −10° 到 0°），手套搭在對方的肩上，兩隻一起晃一拍；或者遞給對方一張小紙條（它本來就是會寫字的卡片）。

## 6 仿作檢查

**手臂的角度**（0° = 朝右，90° = 朝下，−90° = 朝上）：

- 手臂平常在卡片後面；手套要蓋到卡面上的動作（脫帽、捂臉頰、抱自己、抱別人、遞紙條）要把手臂移到前面（引擎的 `front`）。
- 大揮手用**左手**：−120° 到 −145° 之間來回（從 −120° 起手套整個露在卡片外；比 −120° 更直，手套會有一半藏到卡片後面）。右手專門用來脫帽：朝 `deco` 的 pivot 舉起（約 −107°，概念圖主姿勢用 −77°、托住右邊塌下來的帽簷），**這時右手要在前面**，否則手套會整個藏在卡片和帽緣後面。
- 手平舉橫過身體時，紙條在 y ≈ 508，**在嘴巴下方**，不會遮臉（這是肩膀放低的好處）。左手 −15° 到 −25°、右手 −155° 到 −165° 會碰到臉頰，害羞時才用。
- 抱住自己：左 30°、右 150°。抱別人：靠近對方的那隻手 −10° 到 0°（右手）或 180° 到 190°（左手）。

**注意事項**：

- 臉可以在 ±12 內滑動：往上 12 時眼睛頂端在 y ≈ 429，仍在標題線（425）下方；左右都還在卡面內。
- 帽子往右塌過卡片右緣只有約 18 單位（第一版 42）。
- 膠水陰影是烤在部件裡的（和摺摺一樣），手臂轉很大角度時陰影會跟著轉；在 120px 時幾乎看不出來。
- 夜紙不需要額外部件：同一組圖在 `oklch(21% 0.012 60)` 上靠白纖維邊和淡紫的明度就站得住（概念圖 b）。
- 腮紅用的是摺摺現在的三道斜線；kit 說「摺摺先決定，其他跟著」，如果摺摺改成柔和的圓形，改 `gen/card.mjs` 的 `cheeks()` 再重跑一次即可。
- 所有紙色都是 CSS 自訂屬性（`--cd-card`、`--cd-beret`…），預設值就是日間的顏色。

## 第三輪評審後修改

依據：系列評審（`review/critic-series.md`，判定「修改」）、舞台評審（`review/critic-stage.md`）、盲測（`review/blind.md` 第 4 號）。第一版原封不動留在 `v1/`；對照圖是 `checks/review-before-after.png`。

**必修，兩點都做了**：

1. **銅釘離開邊緣**：照摺摺的接法，`arm-l`、`arm-r` 改畫在 `torso` 後面（rig 的順序：影子、腿、手臂、卡片…），兩顆看得到的銅釘頭畫進 `torso`，每隻手臂自己的銅釘留在部件裡（靜止時被卡片蓋住，引擎把手臂移到前面時用它）。銅釘離側邊 18 → 24，約 2.7 個銅釘半徑（評審說的 158→166、542→534 是在舊卡片上離邊 26；卡片縮成 0.9 倍後等比例是 23，取 24，銅釘半徑 8.5 → 9 讓它在舞台上看得清楚）。手套留在原來相對卡片的位置（卡片下面兩角旁邊），手臂從 106 改成 103，**沒有加長**；看得到的紙條約 36。
2. **整隻小一點**：卡片 420 × 268 → 378 × 241（×0.9，以卡片下緣中點縮，寬高比不變，腿不變），`data-height` 336 → 309。帽子懸出卡片右緣 42 → 18。同比例面積 1.50 → **1.18 倍摺摺**（目標 1.15–1.2），舞台寬 154 → 144 px，手機 113 → 106 px。

**建議修，採用**：

- 帽子調亮：`--cd-beret` 52% → 57%、`--cd-beret-band` 42% → 47%，臉先被看到、帽子第二，仍比卡片暗很多。
- 帽子右邊塌下來蓋住卡片右上角，像軟的布帽；帽頂三道鉛筆虛線縫線匯到一點；沒有加頂上的小尾巴。

**和評審數字不一樣的地方**：

- 帽子比評審要的更小：約第一版的 53%（評審是 ×0.9 再少 20%，約 65%）。把帽身壓扁、左端削薄以後才像一頂軟貝雷帽，而不是一個圓頂或一顆麵包（`checks/beret-variants.png`），面積自然少了一些；48px 仍讀得出是帽子。
- 舞台寬 144 px，不是約 135：卡片本身已經 108 px 寬，要到 135 只能讓手套貼著卡片、看不到紙條，手就不像手了。面積已經在目標內。

**舞台評審**：

- `deco` 的 pivot 318 371 → **480 394**：帽子靠右壓在卡片頂邊的地方。右銅釘到這點 119，引擎量到的手臂長 149（×1.1 = 164），搆得到，脫帽會選右手、朝這點舉起。
- `torso-alt`：是「同一面寫滿了字」，不是背面，所以臉留著，**不加 `data-hides`**（系列評審也說臉留著是對的）。字繞開臉，臉滑 ±12 也碰不到字（`checks/alt-slide.png`）。
- 點擊範圍、走路速度、遮擋的形狀是引擎和原型的事，rig 不用改。

**盲測的印象**：

- 「帽子太大、太偏右、超出身體，像快滑下來或另一個漂浮的東西」：帽子小了將近一半、懸出只剩 18，帽緣壓在卡片頂邊上（蓋過頂邊約 10），右邊塌下來蓋住卡角，看起來是戴著的。
- 「臉相對於卡片太小」：卡片縮了、臉保持原大小，眼距 108 → 100。
- 「手寫字縮小後變成髒點」：字從四段減成三段（標題欄一段、右下兩行），斷字少一點，舞台大小下是一條筆跡。
- 「五個裡最寬、最重」：面積 1.18 倍摺摺。
- 「左上角空蕩」：帽子左端往左挪一點（300 → 281），左上保留標題欄的字；帽子仍歪向右邊，這是它的樣子。
- 「像海綿寶寶，剪影像貨車、漢堡」：沒有改卡片的形狀（評審要保留橫式索引卡）。剪影仍是「長方形戴一頂扁帽」，是索引卡這個點子本來的限制；淡紫、格線和歪戴的扁帽把它和海綿寶寶分開。

**保留**：淡紫索引卡、赤陶標題線、淡格線和鉛筆字、臉在標題線下、短短的兩段色腿、脫帽打招呼、寫滿字的 `torso-alt`（臉留著）、青綠帽色。
