## 角色概念

吊牌是用來「給」的東西：寫上名字、綁上禮物，交到某個人手上。牽牽就是一張還沒寫上名字的吊牌。它背面寫好了「給：」，冒號後面卻一直空著，因為它還在找那個人。所以它走到哪裡都帶著一點想送出去的心意：雙手捧著一張折好的小紙條，看到喜歡的人，就轉過身讓對方看見背後的「給：」。

名字取「牽」：吊牌靠一條繩子牽在禮物上，「牽線」是把兩個人連起來，「牽掛」是心裡惦著某個人。它頭上那個蝴蝶結，就是它自己的那條繩子。英文名 Twine 是紙繩，也有「纏在一起」的意思。和摺摺（摺）一樣，名字是一個做勞作時的動作。

和共振的關係：摺摺把重要的字摺起來收好；牽牽則是把東西交出去。一個收、一個給，同一張勞作桌上兩種在乎別人的方式。

## 紙材與外型（比例、手腳長短）

**紙材**：霧藍色的模切卡紙（一般禮物吊牌用的厚卡紙）。邊緣是**剪刀剪的**，不是撕的：外形有一點手剪的微抖，位移比摺摺的撕邊小、慢（`tg-card` 濾鏡位移 1.6、低頻），但保留同一套白色纖維邊、往右下的膠水陰影、紙紋和少量斑點，所以一看就是同一盒紙。正面印著一圈細細的內框線（模切吊牌常見的印刷框），離刀線 13 單位。頂端打了一個孔，套著黃銅雞眼；孔是真的洞，看得到後面的頁面。

**形狀**：細長的五角形，角都剪圓了（半徑 10–15）。寬高約 1 : 2，比例是吊牌，不是房子。

**腳**：長。兩段和手臂同色、比手臂窄一點的卡紙條，膝蓋用小銅釘接起來，像拉線紙偶的腿；末端是撕出來、顏色再深一點的小鞋底，腳尖朝外。

**臉**：和摺摺同一支筆：兩顆鉛筆塗滿的直橢圓眼、各一個反光點，分得比較開；一道小小的弧當嘴；腮紅是三道赤陶色蠟筆短斜線（沿用摺摺第二輪的做法）。沒有鼻子、眉毛（平常）、睫毛。

**背面**（`torso-alt`）：吊牌轉過來是沒有塗層、淡一點的那一面，沒有印框，**沒有臉**；上面用鉛筆手寫「給：」，後面一條空白的線；兩顆肩釘從背面看是壓平的釘腳（兩顆往不同方向撇開，不會排成一對像閉著的眼睛）；紙繩從頂邊繞過來、穿進雞眼。釘在正面的東西轉過來就在紙的後面：手臂只看得到從兩側露出來的手套，蝴蝶結只看得到吊牌尖頂兩旁的兩個環。這些都畫在 `torso-alt` 裡，rig 的 `torso-alt` 寫 `data-hides="face arm-l arm-r deco"`，舞台翻到背面時把臉、兩隻手臂和正面的蝴蝶結藏起來。字是用筆畫路徑畫的，不靠字型。

## 頭飾

**是什麼**：吊牌自己的那條繩子。一條赤陶色的紙繩（紙拉菲草，攤開是一條有皺摺的扁紙帶），從背面繞過頂邊、穿過黃銅雞眼，在雞眼正上方打成一個蝴蝶結：兩個橫向、扁扁的環（越往外越寬，在結那裡收緊）、一個結、兩條末端剪成 V 字的短尾巴，尾巴往兩邊斜下，夾著底下的雞眼。蝴蝶結永遠打在正中、打得平平的，不歪向任何一邊。繞過頂邊的那段繩子只到吊牌尖頂為止，不會從兩個環中間豎起來。

**為什麼適合它**：吊牌的繩子就是它「綁到禮物上」的那條線，是它最核心的東西。綁成蝴蝶結，就是它把自己打理好、準備好要被送出去的樣子；有點拘謹、很講究整齊的個性，也剛好表現在一個綁得端端正正的結上。它緊張時會去整理這個結。蝴蝶結也是情緒刻度：開心時兩個環往上翹一點，害羞或失落時往下垂（`perk` 參數，−1 到 1）。

**48px 讀成什麼**：一個小小的暖色蝴蝶結戴在頭頂，像頭上的髮飾（見 `checks/size-48.png`、`checks/checks.png`）。兩個環是**橫向**、扁平、往外張、中間被結束緊的形狀（蝴蝶領結那種 ⋈），不是兩顆往上豎起的圓，所以不會讀成耳朵；剪影裡它是一條橫在頂上、中間收腰的扁帶，也不是一根往上豎的角或觸角。蝴蝶結的環伸出五角形頂部的斜邊，所以剪影一眼就有它。

## 個性與情感

**第一印象**：溫和、有禮貌、有一點拘謹。站得直直的（它是一張挺挺的卡紙），走路步伐大而小心。遞東西一定用雙手，像遞名片那樣；打招呼前會先微微鞠個躬（整張紙往前傾一下）。心裡一直想著要把什麼交給誰，但遇到人問「是給我的嗎？」又會害羞起來。

| 情緒 | 表現 |
| --- | --- |
| 打招呼 | 先鞠躬（身體往前傾 10–12°），再舉起一隻手套在臉旁揮兩下；蝴蝶結的兩個環翹一下，結還是在正中。概念圖主姿勢是揮手加另一手拿著小紙條：「嗨，這是給你的。」 |
| 開心 | 眼睛換成 ∩，蝴蝶結往上翹，長腿踮一下，整張紙輕輕彈一下。 |
| 好奇 | 臉往那邊滑過去，身體跟著斜一點，手套舉到胸前。 |
| 害羞 | 被問「是給我的嗎？」：兩隻手套舉到臉旁、眼睛閉起、嘴變成小 o、腮紅加深、蝴蝶結兩個環往下垂（結仍在正中）、膝蓋往內靠。見概念圖 c 右。 |
| 下定決心 | 轉過身，讓你看背面的「給：」，用手套指著那條空白的線。這是它的招牌動作（`torso-alt`）。 |
| 感動 | 雙手把紙條捧在胸前，眼睛閉起，身體慢慢晃一下。 |

## 在首頁上會做的事

**出場**：
- 從最近的視窗邊緣，沿著 hero 底部的手繪波浪或卡片上緣，用長腿大步走進來（`data-walk="walk"`，步幅大、身體起伏小，像一張被拿著走的吊牌）。
- 或從 QR 卡片後面升起：蝴蝶結先冒出來，接著是雞眼和眼睛，最後整張紙站上來。

**活動**（一個點選兩三樣）：
1. **站到「成為一群最早說故事的人」那排頭像的尾巴**，像其中一員，對訪客鞠躬；然後轉過身讓大家看背面的「給：」。
2. **坐在故事卡的上緣**，身體底邊擱在卡片頂邊，長腿垂在卡片前面輕輕晃，低頭讀標題，偶爾眨眼（概念圖 c 左）。腿長，坐在卡片上最好看。
3. **站在「寫下你的故事」旁邊**，雙手捧出一張折好的小紙條遞向訪客；再轉過身，用手套指著背後「給：」後面的空白：故事要寫給誰。
4. 指著 QR 卡片（手短，所以站得很近、身體斜過去指）。

**離場**：對訪客微微鞠一躬，轉向最近的邊緣大步走出去；或沉回某個元素後面，最後只剩蝴蝶結，然後也沉下去。

**遇到另一隻**：
- 先停下來、臉轉向對方，鞠一個小躬。
- 走到大約一個身寬的距離，雙手把小紙條遞給對方（stage spec 的「遞紙條」變體，最適合它）；接著一起共振：兩隻同一個節奏上下晃兩三拍，中間三道鉛筆波浪，腮紅加深。
- 如果對方是摺摺：摺摺把折角掀開，把紙條收進去，再壓好（一個給、一個收）。
- 遇到比它矮很多的角色（例如打洞圓點）會先蹲低一點（腿往外撇、身體下沉）再鞠躬。

**剪影檢查**（`checks/checks.png`）：
- 正立：一張頂上綁著蝴蝶結的吊牌，下面兩條細長的紙偶腿；主姿勢一手舉起揮動、一手垂下拿著紙條。

## 給動畫的備註

**部件**（`rig.svg`，由後到前）：`shadow`、`leg-l`、`leg-r`（各含腳，`data-len=195`，支點在髖 320,505／380,505）、`torso`（支點 350,516）、`torso-alt`（`data-variant-of="torso"`、`data-hides="face arm-l arm-r deco"`，manifest 裡是 `hides`）、`deco`（蝴蝶結、穿進雞眼的那段繩子，支點是結 350,152）、`cheeks`、`eye-l`、`eye-r`、`eye-l-shut`、`eye-r-shut`、`mouth`、`mouth-o`、`arm-l`、`arm-r`（支點是肩釘 279,394／421,394，`data-angle` 111.5／68.5）。根元素：`data-face-center="350 328"`、`data-height="567"`、`data-walk="walk"`。雞眼畫在 `torso` 裡，因為它是卡紙的一部分。

**注意事項**：
- **手臂在身體前面**：銅釘釘在紙面上，手臂紙條壓在卡紙正面，這樣手套才能捂臉、在肚子前面捧東西、遞紙條。系列評審同意牽牽保留這個做法（其他幾隻改成摺摺那樣藏在紙後），條件是銅釘離紙邊至少 3 顆釘半徑：現在是 3.1。
- **手臂角度**：揮手約 −128°（手套在臉旁）；兩手在肚子前捧紙條約 53°／127°；舉到臉旁約 −76°／−104°。手短，舉不過頭頂，也碰不到蝴蝶結，這是刻意的（「整理頭飾」只會讓蝴蝶結自己晃一晃）。
- **腿**：整條腿繞髖擺動，大步走時建議 ±16–20°。膝蓋銅釘只是畫上去的，不會彎。坐在卡片上時，把身體底邊（y≈520）放在卡片頂邊，腿畫在卡片前面。
- **轉身（`torso-alt`）**：建議身體 scaleX 1→0，換成 `torso-alt`，再 0→1。`torso-alt` 的 `hides` 是 `face arm-l arm-r deco`：背面沒有臉；手臂和蝴蝶結轉過去就在紙後面，背面這張圖自己畫了從兩側露出的手套和尖頂兩旁的蝴蝶結環（站姿的位置），所以引擎只要把這四樣藏起來，不用搬動圖層。引擎若只認得 `face`，手臂和蝴蝶結會照常疊在背面上，位置和背面畫的幾乎重合，不會出錯，只是看起來沒那麼像轉過身。
- **蝴蝶結**：繞結的支點最多 ±8° 晃，走路時慢半拍；鞠躬時往前甩一點；**每次晃完都回到正中**，不能停在歪一邊（停歪了會讓人想到 Hello Kitty）。開心往上翹、害羞往下垂，要換圖的話可以另外做 `deco` 的變體（這次沒做）。
- **臉的滑動**：臉兩側到紙邊至少還有 20 單位，±12 的滑動不會滑出紙外。
- **小紙條**：概念圖裡拿著的紙條不在 rig 裡。若要做「遞紙條」，可以加一個 `note` 小部件跟著手套走（之後再做）。
- **大小**：照 kit 的比例（摺摺 420 單位 = 桌機 120px），牽牽含蝴蝶結約 167px 高、手機約 122px。系列評審認為它細、面積只有摺摺的 0.85 倍，不重，rig 的高度不變；舞台評審建議舞台高度改成 unit ×（h／420）^0.7（牽牽約 148px），那是引擎的事，rig 不用跟著改。
- **坐在地上**：腿長，引擎現在坐地的腿角（±78°）會讓它像劈腿。建議引擎依腿長縮小（長腿約 35°、`legS` 0.5，像腿往前伸），`clear` 用坐下時的寬度。
- **赤陶色的 CTA 區塊**：蝴蝶結的顏色和那塊底色太接近，白色纖維邊還撐得住輪廓，但蝴蝶結會不明顯。建議它在 CTA 只站在「寫下你的故事」那顆奶油色按鈕旁邊，或走在波浪頂邊的米色那側。
- **日紙上的手套**：48px 時奶油色手套在米色頁面上很淡（摺摺也是），120px 以上沒問題。
