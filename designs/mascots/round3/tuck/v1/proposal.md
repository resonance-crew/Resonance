# 摺摺 Tuck · 第三輪（業主選定版的修訂）

**一句話**：一張被撕下來的鼠尾草綠色紙。它一直折著一個角，因為折角底下藏著幾行字；兩條紙手臂從紙後面伸出來，用銅釘釘在紙面上，頭上用一根迴紋針夾著撕紙做的瀏海。

這是業主選定的設計，所以只改業主點出來的地方，其他都照第二輪：鼠尾草綠撕紙、右上的折角和底下的鉛筆字、臉（眼睛、反光、嘴、三道赤陶色蠟筆腮紅）、麥黃風琴腿、綠色腳、奶油色連指手套、霧面銅釘、白纖維撕邊和膠水陰影。

## 1 角色概念

摺摺是一張被撕下來的鼠尾草綠色紙。色紙一面有顏色、一面是白的，所以它右上角往前折下的那個角，露出來的是米白的背面。折角底下有幾行別人用鉛筆寫的字。它不知道自己原本是哪張紙，只知道那個角要一直折著，因為底下的字是它最想留著的東西。只有在信任你的時候，它才會把角掀開給你看。

它是這套「同一張勞作桌上做出來的紙偶」裡的第一隻：大家紙不一樣、形狀不一樣，但都用銅釘接手、都戴同一種奶油色連指手套。

這一輪多了一個小習慣：它用一根迴紋針把瀏海夾起來，免得讀字的時候頭髮掉下來擋住。迴紋針本來就是夾紙、留住一疊紙的東西，和它「把重要的東西收好」的個性是同一件事。

## 2 紙材與外型

**輪廓**：一片略圓、邊緣不規則的撕紙，寬高比約 1 : 1.03。右上角沿 45° 折下；下半部有一道舊摺痕（這一輪往下移了 12，讓它待在銅釘下面），摺痕下方稍暗，是肚子的區分。

**比例**（摺摺座標）：

- 紙片約 318 寬 × 329 高；腿長約 110–114，約紙片的三分之一。
- 眼睛在紙片高度約 45%，嘴巴線 y 444。
- **肩膀**：銅釘中心 y 470（左）／472（右），在嘴巴線下方 26–28，摺痕上方約 10–15。
- **銅釘**：半徑 9.5（第二輪 8.6，放大一點，舞台上半徑約 2.6 px），中心離撕邊 21，釘在紙面上。
- **手臂**：紙條從銅釘往外，肩端寬 46、手腕寬 40；肩到手套中心 120。紙條的肩端塞在紙片後面，所以看起來是從撕邊底下伸出來，再被銅釘從正面釘住。
- **手套**：手掌半徑約 31.5，連拇指寬約 71。
- **站好**：手臂往外斜 32°（左 122°、右 58°），手套中心在 y 572／574，就是紙片底緣、腿冒出來的地方（臀線）；膝蓋約在 y 617，手套碰不到。
- **舉手（主姿勢「嗨」）**：左臂 −117°，身體往另一邊斜 3°，左腳微抬。手套中心約 y 363，高過眼睛（y 396），在紙片外側、和輪廓之間留了空隙。

**舉手高度，老實說**：手臂短了、肩膀低了，手套到不了頭頂（第二輪是靠 164 的長度做到的）。我選擇維持短手臂，不把肩膀再往上提，改用角度：手臂斜 −117° 往外上方舉，讓手套落在頭的上半部旁邊、離開輪廓，加上身體往反方向斜 3°。96 px、48 px 和剪影都看得出是在舉手（`checks/sizes.png`、`checks/stage-size.png`）。如果要更直立（比 −110° 更直），手套會碰到紙片邊緣、在剪影裡黏成一團，所以不建議。

**紙材**：

- 身體：鼠尾草綠色紙，纖維紋理、少量斑點。
- 折角背面：色紙的白色背面。折角底下：幾行鉛筆字。
- 手臂：同一張綠紙剩下的較深邊角料，沿下緣一道很淡的鉛筆壓線，表示它是扁的紙條。
- 手套：奶油色紙，圓手掌加一個朝外的拇指（站好時拇指朝外、手心朝前；舉起來時拇指就自然轉向頭，像揮手的手）。拇指和手掌之間一道撕出來的 V 形缺口，缺口往內一道短鉛筆線。
- 銅釘：霧面黃銅雙腳釘，帶顆粒、深色邊和一個小反光，下面一點陰影。
- 腿：麥黃色紙摺成風琴狀。腳：綠紙邊角料，顏色深一點。

## 3 頭飾

**是什麼**：四綹撕紙瀏海，兩種深淺的麥黃紙交錯，從頭頂靠近折角的地方往左撥過去、垂在頭的左上側，末端撕成尖的，最外面一綹稍微超出紙片的輪廓。根部用一根銅色迴紋針（標準的雙圈迴紋針形狀）夾住。每一綹中間有一道很淡的鉛筆線，讓它看起來是紙條，不是葉子或火焰。

**為什麼適合它**：

- 摺摺是收著字、愛讀字的那一隻。迴紋針是書桌上最常見的「把紙留住」的東西，拿來當髮夾很合它。
- 迴紋針和肩膀的銅釘是同一種黃銅，瀏海和腿是同一種麥黃紙：頭和腳、頭和肩，都是同一盒勞作材料。
- 瀏海整片往同一邊垂，不是直立的一根，所以不會再像耳朵、角或天線；也刻意不用綠色，避免看起來像發芽。

**48 px 讀成什麼**：頭的左上角一小片淺黃、底緣參差的頭髮，旁邊一個金色小亮點；120 px 時看得出是一片撥到旁邊的瀏海加一根髮夾。剪影裡它只讓左上的輪廓稍微毛一點，不增加任何突起（`checks/stage-size.png`、`checks/sizes.png`）。

**試過但沒選的**（`work/explore-deco.png`）：往上翹再往左彎的一撮，像羽毛或鳥冠；頭頂一束，像青蔥。最早的版本三條圓頭紙條從同一點散開，像一隻手或皇冠。

## 4 個性與情感

**第一印象**：有點害羞、很認真，會把重要的東西好好收著。但它會先對你揮手。

臉很安靜，情緒主要交給紙的物理：折角掀起或壓低、腿伸長或壓扁、瀏海晃一下、手臂繞著銅釘擺。眉毛只在情緒很強的時候才出現。

| 情緒 | 表現 |
| --- | --- |
| 打招呼 | 左手繞銅釘舉到頭的上半部旁邊，手套左右搖 ±12°；身體往另一邊斜 3°，左腳抬起。（主插畫） |
| 開心 | 原地一跳，兩手往外上方張開（−132° 和 −50°），眼睛笑成彎線，嘴巴張開，瀏海晃一下。兩隻手套離得很開。（概念圖 c 右） |
| 好奇／信任 | 折角立起來，露出底下的字（`torso-alt`），一隻手往折角那邊舉，像在問「一起看嗎？」。（概念圖 c 左） |
| 害羞 | 兩隻手往內收到紙片後面（「把手藏到背後」——它的名字就是 tuck），眼睛看旁邊，腮紅加深，腿縮短。 |
| 感動 | 眼睛瞇成彎線，這時眉毛才出現，眉尾往下；兩手垂下、往外攤開一點；腿軟掉一點。不再把兩隻手套疊在肚子中間。 |

## 5 在首頁上會做的事

尺寸照 kit：桌機約 120 px 高、手機約 88 px。

**出場**（擇一）：

- 從比較近的畫面邊緣沿著一條「平台」走進來（hero 結尾那條手繪波浪的浪頂、故事卡的頂邊、CTA 區塊的波浪上緣），風琴腿一伸一縮，身體往前進方向微斜，臉往前方滑。
- 從一張故事卡後面升起來：先冒出瀏海和迴紋針，再是眼睛，看一眼，再整個站上卡片頂邊。

**活動**（每次兩三個）：

1. **坐在故事卡頂邊讀標題**：屁股坐在卡片頂邊，腿垂在卡片正面，臉往下滑一點、眨眼，像在讀卡片的標題。（概念圖 c 左）
2. **掀開折角給你看**：讀著讀著，把折角立起來（`torso-alt`），舉手往折角那邊比，眼睛看向你；過一兩秒再把角折回去。這是它的招牌動作。
3. **對訪客揮手**：游標靠近時看向游標，舉手揮兩下。
4. **整理髮夾**：左手舉到瀏海旁邊，瀏海晃一下（`deco` 繞根部轉 ±4°），再放下。
5. 站在「寫下你的故事」旁邊，手往按鈕的方向舉，像在說「你也寫一張」。

**離場**：揮一下手，從比較近的邊緣走出去；或沉回卡片後面（腳先、身體、最後是瀏海和迴紋針）。

**遇到另一隻**：

- 折角先立起來一下，表示注意到了；臉往對方滑。
- 走到大約一個身寬的距離，用靠近對方那隻手揮手。
- 共振：兩隻一起上下擺兩三拍，中間冒出三條鉛筆波浪線，腮紅加深。
- 摺摺自己的變化：把折角掀開給對方看底下的字；或兩隻用靠近的那隻手套在半空擊掌。

**點擊**：第一下，開心地原地一跳（眼睛換成彎線）；第二下，害羞：兩手收到紙後面、腮紅加深，然後走掉。

## 6 仿作檢查

- **Snipperclips（Snip／Clip）**：同樣是紙做的、有臉、有腳。差別：它們是幾何形（半圓、方形）的乾淨剪紙，細腳、沒有手；摺摺是撕出來的不規則圓片、有折角、有銅釘關節和連指手套、風琴腿。
- **Humpty Dumpty、Mr. Men／Little Miss**：圓身體加細手腳、Little Miss 有頭髮和髮飾。差別：摺摺是平的撕紙、帶纖維白邊和膠水陰影，手腳是紙條和風琴摺，頭上是紙瀏海加迴紋針，最主要的辨識是右上的折角。剪影並排不會認錯（`checks/sizes.png`）。
- **Paper Mario、Tearaway（Iota／Atoi）**：不是把立體人物壓扁，也不是信封頭。
- **Kirby**：不是粉紅、不是鼓起來的球。
- **剪影自查**：200／48 px、上下顛倒、左右翻轉都看過。沒有耳朵、角、器官或膚色的聯想；倒過來時兩條風琴腿朝上，像一隻翻過來的小甲蟲，沒有人體的聯想。瀏海是黃紙、往旁邊垂，不像葉子或芽。

**注意事項**：

- **手臂在紙片後面**：紙條從撕邊底下伸出來，所以銅釘頭畫在 `torso` 上（它是圓的、在 pivot 上，不轉也看不出來）。每條手臂也帶著自己的銅釘（被紙片蓋住），所以如果某一拍要把手臂畫到紙片前面（例如兩手擋臉），手臂看起來還是釘好的。
- **手臂看得到的角度**：左臂大約從 75°（垂直略往內）經 180°（往左）到 −110°（往左上）；右臂鏡像，105° → 0° → −70°。再往內轉，手套會躲到紙片後面，害羞時正好用這個。舉手不要比 −110° 更直，手套會碰到紙片邊緣、剪影黏成一團。
- **不要**把兩隻手套放到下腹中間碰在一起。
- 手臂紙條的膠水陰影刻意做短（偏移 1, 2），手臂轉到哪裡陰影都不會甩得太遠；身體、腿、瀏海的陰影照常往右下。
- 臉可以左右滑 ±12，四周都還在紙上。眼睛 2.5–6 秒眨一次。
- `deco` 只做小幅晃動（±4°，跳完之後晃一下、整理髮夾時晃一下），不要轉成直立。
- 掀折角：`torso` ↔ `torso-alt` 直接替換；想要兩段感，可以先把 `torso` 的 scaleY 壓到 0.98 一拍再換。
