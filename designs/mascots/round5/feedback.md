# 第五輪 · 業主回饋（2026-10-28）

看過首頁上線的角色動態（第四輪，6cb8ae52）之後的觀察，依原話整理。

## 節奏

- **進場和退場都太快**：不管是出現到畫面裡，還是離開時倒下，速度都很快。
- **倒下的退場要再慢一點**：更像紙片倒下的感覺。
- **走路太快**：有些角色進場特別快，可能是角色設定本來就走得快。不同角色、不同情境的走路速度可以不一樣，但差異不要那麼大。
- **動作和動作之間要有一點停留**：現在像是很快地一直在做事情，沒有休息；一般的互動中間會有一點停留，不用很久。
- **停留不能像卡住**：演戲有「空臺動作」——沒在做事的時候也有一些小動作，不一定很明顯，但看得出動畫還在、沒有中斷，只是讓整個節奏更好。

## 要修的地方

- **「成為一群最早說故事的人」右邊**：角色站起來做動作，有時會消失一陣子，然後又出現。
- **拿筆寫字**：角色拿筆在紙上寫、再收起來時，筆的角度怪怪的；手其實沒有拿到筆，手和筆沒有黏在一起。
- **QR code 後面探頭**：角色有時跑到 QR code 旁邊探頭，但出來得不夠多，看起來還是整個被擋在 QR code 後面。

## 原因與處理

- **消失又出現**：首頁 hero 是 `min-height: 100vh`、內容垂直置中，視窗高度一變（瀏覽器面板開合、視窗拉高拉矮），「最早說故事的人」那一排就跟著上下移。舞台重新量測時發現訪客的落腳點動了，就整台重建：角色演到一半直接消失，1–2 秒後新舞台的第一位又常選同一點出現（第一位偏好能相遇的地方，這裡就是）。第四輪的程式審查記過這一條（review-code N1）。在瀏覽器把視窗高度從 800 改成 740 就能重現。現在改成角色跟著落腳點一起上下移、照常演完；落腳點不見、變形或橫移時，角色像捲走時一樣好好退場，舞台不再重建（只有寬度改變、換版型時才重建）。
- **走路**：基本步速改成跟腿長關係較小，五隻在桌機上每秒 77–96 px（原本 81–155 px，差近 2 倍；現在約 1.25 倍）。原本走遠路會小跑到 1.8 倍、趕時間再加到 2.6 倍，現在小跑最多 1.25 倍、趕時間最多 1.45 倍，進出場走路的時間上限從 2.6 秒放寬到 4.2 秒。起步慢慢加速，走到定點前最後一兩步放慢再停。點點的跳步也放慢（一跳 0.5 → 0.6 秒）。
- **進場、退場**：彈出（像立體書站起來）0.42 → 0.8 秒；爬上卡片 1.0 → 1.35 秒，探出、滑出 0.9 → 1.2 秒，退回 0.7–0.8 → 1.0–1.1 秒。倒下退場 0.34 → 約 1 秒，改成紙片倒下：先踮一下，開始倒得慢、越倒越快（高度是倒下角度的餘弦，角度隨時間平方增加，像一張卡片倒下），兩手往上揚、身體微晃，平貼後輕彈一下再淡去。
- **停留與空臺動作**：到定點後先停 0.7–1.2 秒，動作和動作之間停 1.3–2.7 秒，離開前再停 0.5–0.9 秒。停留時不會靜止：呼吸、重心左右換（坐著時兩腳輕晃）、兩手微微擺、視線跟著飄；偶爾一個很小的節拍——點個頭、慢慢眨一次眼，或腳尖點兩下。來訪時間從 9–16 秒拉長到 12–20 秒，讓停留不會吃掉動作。
- **動作本身**：都稍微放慢——看 2.2 → 2.8 秒、揮手 1.5 → 1.9 秒（每秒 2.6 → 2 下）、招手、指、伸懶腰、跳兩下（中間喘一口氣）、讀書、晃腳、躲一下都一樣；兩隻打招呼、相遇、碰手、遞紙條也慢了一些。
- **拿筆**：原本筆是直立的、以手套「外緣」為中心浮在紙上，筆尖還戳出紙外。量了五隻的手臂圖，手套的中心在手臂長度的 0.63–0.69 處，引擎一直把 0.82 處（手套外緣）當成手的位置。現在：紙由一隻手捏住遠離筆那側的邊；筆尖落在正在寫的那一行，跟著三行字一筆一筆走；另一隻手轉到讓手套中心握在筆身上的位置，筆斜約 35°、筆頂朝外上方。聆聆、悄悄身體寬、手短，兩隻手套碰不到一起，就改拿大一點的紙條讓筆搆得到（會擋到嘴巴，像把字條舉在胸前寫）。五隻都在瀏覽器裡放大確認過。
- **QR code 探頭**：露出的身體從六成改成約八成，而且一定讓兩隻眼睛和眼外一點都露在外面（卡片側邊的探頭也適用）。QR code 只有左側有探頭點：右側緊貼下載徽章，沒有空間。

## 第二次回饋（同一天，看過上面的修改後）

- **倒下後又站起來，再消失**：點點在下載徽章旁和牽牽共振完，倒下，又很快站起來，過一陣子才消失。原因：兩隻相遇後各走各的路時，旁邊被徽章或 QR code 擋住、走不出去的那隻會倒回頁面上；但這一幕要等另一隻走出畫面才算結束，這段時間每一格都把姿勢重設回站著，所以倒下的那隻又站了起來，等另一隻走完才一起消失（走路放慢後等得更久，所以更明顯）。現在倒下後就一直平貼在頁面上，倒完當下就消失。
