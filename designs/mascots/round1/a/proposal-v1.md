# A｜色鉛筆小生物：聽芽 Tingya

**一句話定位**：頭上長著一根蕨芽般捲起的「聽芽」，聽見故事時會慢慢舒展、害羞時捲緊的安靜小傢伙。它不搶話，它在聽。

- 主插畫：`character.svg`（800×800，透明背景，可拆件）
- 概念圖：`concept.svg` / `concept.png`（1600×1000）
- 探索草稿：`explore.svg` / `explore.png`
- 產生器（可重現、可調參數）：`_build/`（`python3 build_concept.py` 會重畫 character.svg 與 concept.svg）

---

## 1 角色概念

**核心想法**：一隻用「芽」聽故事的小生物。它頭頂那根捲起的芽，同時是耳朵，也是一株還沒長開的植物。聽到一個好故事，芽就舒展一點點；被說中心事，芽會整個打開、在尖端輕輕顫動；害羞或想躲的時候，芽就捲緊、垂到腦後。

**靈感來源**
- 蕨類的捲芽（fiddlehead）：嫩葉捲成一圈，會一天一天慢慢舒展。
- 耳蝸：人耳裡負責「聽」的那個構造也是一圈螺旋。
- 兩者疊在一起，就成了一個「會長大的耳朵」。

**與共振的關係（自然呼應，不硬扣）**
- 共振的第一步是傾聽。聽芽的主要動作不是說，而是聽；它最有魅力的瞬間，就是聽到故事時那個舒展的反應。
- 「用生命影響生命」：它是被故事養大的，聽得越多，芽長得越開。不用說教，看它的芽就知道它被觸動了。
- 未來每隻生物的芽或接收器官都會因為聽過的故事而長得不一樣，正好對應「每個人的生命故事都不一樣」（見第 6 節）。

**探索過程（`explore.png`）**：同一個領域內畫了三個剪影：
1. ① 聽芽：圓肚身體加一根捲芽。
2. ② 垂葉：低矮寬身，兩片葉狀耳垂到地面。
3. ③ 高腳：一團絨球放在兩條細長腿上。

選 ① 的原因：
- 即使塗成實心剪影，那個捲也一眼可認。
- 「捲緊 ↔ 舒展」本身就是一條情緒刻度，最適合做動態。
- ② 太接近垂耳兔類角色（Molang 一系）的印象。
- ③ 的臉部面積太小，細腿也不好做親和的姿態，容易被讀成鳥或灰塵精靈。

定稿前改過三版，詳見「參考與避免仿作」：
1. 第一版是光滑的蛋形，像一顆馬鈴薯。
2. 第二版把頭頂收成尖點，太像史萊姆。
3. 第三版加了捲尾巴，像小豬。

## 2 外型設計

**輪廓與比例**
- 頭身一體的「球莖」形：下寬上圓，最寬處在下半部，像坐著的小塊根。
- 頭頂正中收成一個柔軟的小凸起，芽就從那裡長出來，身體和芽是同一個生命，不是插上去的配件。
- 身體約 335×378（以 800 畫布計），芽再往上伸約一半身高；整體高寬比約 1.7 : 1。
- 主姿勢整體向左傾 4°，像在側耳傾聽。

**五官**
- 眼睛：
  - 大而低、間距寬：眼睛中心在身體高度約 51%，兩眼間距約身寬三分之一。前額留得多，看起來安靜、專注，有點像海豹寶寶的神情。
  - 深棕直立橢圓，用密排線塗滿而不是平塗。
  - 眼底有一抹暖琥珀色的反光。
  - 只有一個小小的留白光點，不做動漫式的多重閃光。
- 上眼瞼：一道較重的鉛筆線，眼瞼高低就是主要的情緒控制。
- 眉毛：只有兩筆短短的弧，負責「好奇／擔心／感動」的斜度。
- 嘴：極小，預設是一道淺淺的微笑弧。
- 臉頰：玫瑰色的短排線。

**四肢與其他部位**：
- 手：圓頭連指手套狀的小手兩隻。
- 腳：藏在身體下方的小圓腳兩隻，各有兩道趾線。
- 尾巴：身後一截柔軟的短尾。
- 影子：地面一片鉛筆排線的影子。

**材質**：色鉛筆塗在有紋理的紙上。

**主要色彩**（白天／奶油紙）

| 角色 | 用途 | oklch |
| --- | --- | --- |
| 淡毛色 | 輕壓的底色 | oklch(86% 0.05 68) |
| 主毛色 | 主要排線（杏桃燕麥色） | oklch(78% 0.08 60) |
| 陰影 | 交叉排線，偏赤陶 | oklch(65% 0.095 44) |
| 深陰影 | 陰影邊緣 | oklch(53% 0.085 40) |
| 芽尖 | 捲芽最內圈的玫瑰赤陶 | oklch(70% 0.1 30) |
| 腮紅 | 臉頰 | oklch(72% 0.11 20) |
| 眼睛 | 深暖棕 | oklch(28% 0.035 45) |
| 眼底反光 | 琥珀 | oklch(58% 0.1 58) |
| 輪廓 | 同一支深棕鉛筆 | oklch(36% 0.04 50) |
| 底層 | 不透明墊底，等於紙色 | oklch(96.5% 0.015 75) |

夜紙：
- 輪廓換成奶油色鉛筆 oklch(88% 0.03 75)。
- 毛色提亮到 oklch(80% 0.05–0.07 60–68)。
- 底層換成調過色的中間調 oklch(66% 0.06 60)。這就像在黑紙上畫色鉛筆會先墊一層底色。
- 眼睛、臉部線條維持深色，因為它們畫在毛色上，不是畫在紙上。

所有顏色都寫成 CSS 自訂屬性（`--a-ink`、`--a-fur`、`--a-under`…），換紙只要覆寫變數。

**最具辨識度的特徵**：頭頂那根「粗捲細莖」的蕨芽。
- 莖細，捲的部分反而膨大，最內圈帶一點玫瑰色。
- 48px 剪影裡，它仍是唯一一眼就能認出的形狀（見 concept 右上）。

## 3 個性與情感

**第一印象**：聚會裡坐在角落、你說話時會整個轉過來看著你的那個人。安靜、有點害羞、很專心，不吵不鬧但讓人安心。

**情緒表達**：主要靠芽和眼睛兩個部位，四肢只是輔助。

| 情緒 | 芽 | 眼／眉／嘴 | 身體 |
| --- | --- | --- | --- |
| 好奇 | 先伸出去、半舒展，朝聲音的方向探 | 眼瞼全開、看向對方，眉上揚，嘴成小小的「o」 | 身體斜傾，臉滑向一側（概念圖「好奇探頭」） |
| 開心 | 像彈簧一樣上下彈兩下 | 眼睛彎成 ∩，嘴角上揚 | 小跳一下，尾巴搖 |
| 害羞 | 捲緊、垂到腦後 | 眼神往下，腮紅排線加深、範圍擴大 | 臉往下縮，手捂臉頰，躲到東西後面 |
| 感動 | 整根舒展開，尖端輕輕顫動 | 眼睛閉成 ∪，一滴淡藍的淚，眉尾內側上揚，嘴成微抖的波線 | 雙手收到胸前（概念圖「被感動」） |
| 陪伴 | 慢慢偏向身旁的角色，兩根芽尖輕碰 | 半閉眼 | 坐著，呼吸起伏放慢，和對方同步 |

## 4 手繪風格

**筆觸**
- 上色全部是短排線，一筆約 26–64px，每筆角度隨機偏 ±3.4°，帶一點弧度。
- 不是從邊到邊的整齊規線，看起來像真的一筆一筆塗上去。
- 主排線約 58°；陰影處再加約 −28° 的交叉排線，只出現在背光的右下方，往亮面自然淡出。
- 左上留一塊受光區，壓力較輕、紙色透出。肚子也略淺。

**線條**：「同一支筆、輕重不同的重描」。
- 每個輪廓由 2–3 道帶壓感、頭尾漸細的鉛筆線疊成。
  - 主線約繞一圈多一點，接縫處會重疊、變深。
  - 第二、三道只描局部，並略微偏移。
- 線條不是 SVG 的固定 stroke-width，而是程式產生的變寬多邊形，所以有真的輕重。
- 芽的捲曲處另加幾道短刻痕，像蕨葉捲起的邊緣。

**色彩**
- 低彩度的暖色系（色相 40–70），和首頁的桃色漂移色塊、赤陶強調色同一家族。
- 臉頰和芽尖用玫瑰色點綴。

**材質（SVG 技法）**
- **紙紋（`#a-tooth`）**：
  - `feTurbulence` fractalNoise 先經 `feColorMatrix` 轉成 alpha（α = 2.7R − 0.62），再用 `feComposite operator="in"` 疊進色塊。
  - 顏料只留在紙紋凸起處，凹處透出紙。
  - 所有部位共用同一個雜訊種子，所以紙的凹點在不同顏色間對得上，像同一張紙。
- **手不穩**：用低頻 `feTurbulence` 加 `feDisplacementMap`（scale 4），讓色塊微微溢出或不到線，邊緣不會貼得太準。
- **鉛筆石墨（`#a-lead`）**：線條另有一層較細的顆粒和 1.8 的毛邊位移。
- **眼睛（`#a-tooth-dense`）**：用「重壓」版本的紙紋，深色幾乎塗滿，只留零星白點，避免眼睛看起來像毛線編織。
- **底層（`.a-under`）**：每個體塊下面墊一層不透明底色，白天等於紙色。
  - 首頁的漂移色塊不會從角色身上的紙紋縫隙透出來。
  - 夜晚改成中間調，角色才不會變成一團髒灰。
- **小尺寸**：96px／48px 的版本不是單純縮小，而是用同一支筆重畫，線寬固定約 1.3–1.6px。這呼應網站「一支筆」原則。結果是芽的捲在 48px 仍讀得出來，剪影也成立。

整體呈現：看得見排線方向、看得見紙紋，輪廓有輕有重，沒有任何光滑漸層或 3D 高光。

## 5 Landing Page 的應用想像

**放在哪裡**
- 首頁 hero 的下緣，站在頁面底線上，靠左下（桃色色塊附近）或右側（鼠尾草色塊旁）。
- 大小：桌面約 160–220px 高，手機約 100–120px。
- 一次最多兩隻，永遠不壓到主標「讓生命影響生命」和下載區。

**和漂移色塊共處**：把色塊當成它生活的地形，而不是背景。
- 色塊是小丘、是可以躲的地方。
- 兩團色塊相遇長出「頸部」時，像一座臨時的橋，它可以從上面跳過去。
- 色塊本身照常緩慢漂移；角色只在色塊的邊緣活動，不改變色塊的動畫。

**出場**
- 第一個出現的永遠是芽：從色塊後面或頁面邊緣先探出一個捲（概念圖「好奇探頭」的邏輯）。
- 停兩拍，芽慢慢伸直一點，身體才跟著探出來。
- 或者用兩隻小腳一跳一跳走進來，每一步身體壓扁再彈回。

**停留**
- 呼吸：身體 scaleY 1 → 1.02，約 3.5 秒一次。
- 眨眼：每 3–6 秒隨機一次。
- 芽尖：偶爾像在辨認方向一樣轉一下。

**看向訪客**
- 游標移動時，臉部群組 `a-face` 在身體上往游標方向滑 ±12px，眼睛光點跟著偏，芽也微微轉向。不必轉整個身體。
- 訪客停在主標或捲動到故事卡時，芽半舒展，像在聽。

**遇到另一個角色**
1. 先是芽注意到：芽尖轉向對方。
2. 接著眼睛看過去，身體再轉。
3. 互相靠近。
4. 打招呼：兩根芽尖輕輕碰一下，碰到的瞬間在空中留下兩三道很淡的鉛筆波紋，自然帶到品牌 logo 的波浪。
5. 陪伴：並排坐著，呼吸節奏慢慢同步。這是「共振」最安靜的一種表現，不用任何字說明。

**離場與再出現**
- 芽捲緊，身體縮一下，躲進色塊後面，或一跳一跳走出畫面。
- 過一陣子，同一個芽尖從另一團色塊後面冒出來。
- 訪客會開始等它，那就是建立關係的時刻。

**節制**
- 遵守 `prefers-reduced-motion`：只保留靜態姿勢和眨眼。
- 離開視窗時暫停，比照現有色塊的作法。

## 6 未來系列化的潛力

同一個世界觀：一群「被故事養大」的小生物。每一隻都有自己接收故事的器官，聽過的故事讓那個器官長成各自的樣子。它們共用同一支鉛筆、同一張紙、同一套暖色系，但外型、接收方式和個性都不同，不是換色或換配件。

**差異軸一：接收故事的器官（決定剪影與招牌動作）**
- 聽芽：用捲芽聽，舒展就是被觸動。
- 例：一隻低矮寬身、背上長滿苔絨的小生物。故事聽進去不會說出口，而是在感動時從背上飄出幾顆蒲公英般的絨種。慢條斯理，像外婆。
- 例：一隻用尾巴當第三隻腳、細細長長的小傢伙。它用尾巴尖去感覺地面的震動，好奇時尾巴彎成問號。話多、坐不住。

**差異軸二：筆觸語言（同一支色鉛筆，不同的塗法）**
- 聽芽：斜向排線。
- 苔絨那隻：點描、小圓圈螺旋塗，看起來毛茸茸、有顆粒。
- 長尾那隻：沿著身形走的長弧線，看起來光滑、有速度感。
- 這樣即使只看一小塊局部，也分得出是誰。

**差異軸三：身形與移動方式（決定動畫的個性）**
- 聽芽：雙腳小跳步。
- 苔絨：像毛毛蟲一樣緩慢起伏滑行。
- 長尾：靠尾巴一彈一彈。
- 每個角色的出場、離場方式自然不同，同框時節奏也不同，畫面才有生活感。

## 參考與避免仿作

**參考的是自然物，不是既有角色**
- 蕨類捲芽和耳蝸的螺旋，取其「捲起、舒展」的結構。
- 色鉛筆技法參考的是一般繪本的排線、紙紋上色習慣，不針對特定作品。

**主動檢查過的相近既有角色，以及刻意避開的特徵**

| 相近角色 | 相似處 | 怎麼避開 |
| --- | --- | --- |
| 皮克敏（Pikmin） | 頭上長植物 | 聽芽的芽是粗捲細莖、沒有葉子或花，顏色和身體同色；身體是矮胖球莖，不是細長身形 |
| 勇者鬥惡龍史萊姆 | 第二版頭頂收成尖點、下寬上尖，一度太像水滴形加一撇的史萊姆 | 已改回圓頂；芽是長長的螺旋而不是一撇；身體有手、腳、尾巴；色鉛筆暖色排線，沒有光滑藍色和大嘴笑 |
| Barbapapa | 梨形一體的身體 | 有分開的四肢與腳，不會變形；招牌是芽，顏色也不同 |
| 小豬尾巴 | 第三版的尾巴也做成小捲，看起來像小豬 | 改成柔軟短尾，讓「捲」只屬於頭上的芽 |
| Molang 與垂耳兔類 | 探索 ② 的垂葉耳 | 已淘汰 |
| 龍貓的灰塵精靈、各種毛球角色 | 探索 ③ 的絨球 | 已淘汰 |
| Kirby | 圓形加小腳 | 聽芽是直立球莖、杏桃色，不是粉紅正圓 |
| 角落生物、卡娜赫拉 | 簡潔臉孔（深色眼、腮紅、小嘴）是這類角色的共通語言 | 聽芽的眼睛較大、低位寬距，帶上眼瞼的鉛筆線和暖色眼底反光，不是極小的點眼 |

剩下的風險：聽芽的臉和身體仍在「可愛圓身」的類型慣例內，辨識度主要靠芽。若需要更強的臉部個性，可以把「半垂的厚上眼瞼」做成固定招牌。

**前端建議**
- **不要在動畫中即時跑這些濾鏡。** `feTurbulence` 與 `feDisplacementMap` 只要所在元素被變形，瀏覽器常常就要每幀重新點陣化濾鏡區域，很耗效能。目前 character.svg 有 26 個濾鏡群組、159 個路徑，靜態沒問題，動起來在手機上會掉幀。
- **建議作法**：每個部件用 2× 烘焙成透明 WebP／AVIF，動畫只動 transform 和 opacity，GPU 合成即可。
- **第一期**：idle（呼吸、眨眼、看游標）、探頭出場、躲回色塊，用 SVG／HTML 加 CSS／WAAPI 就夠，最輕。芽的舒展用 3–4 張狀態圖交叉淡入。
- **互動變多時改用 Rive**：兩個角色互相注意、狀態機（傾聽、好奇、害羞、感動）、芽的網格變形都適合 Rive，執行環境約百來 KB。
- **Lottie 只適合線性片段**：例如出場、離場。點陣材質放進 Lottie 檔案會變大，互動性也有限，不建議當主力。
- **深色模式**：若烘焙成點陣，需要日、夜兩組圖。比較省的作法是把輪廓層分開，用 CSS mask 染色，只有毛色層要兩組。
- **效能注意**：首頁已經有一個 30fps 的 metaball canvas。角色動畫應同樣在離開視窗時暫停，並和色塊共用一個 requestAnimationFrame 節奏，避免兩套迴圈互搶。

## 自評

**最強的地方**
- 招牌部位同時解決了三件事：
  - 辨識：48px 剪影仍可辨認。
  - 情緒：捲緊到舒展就是一條連續的情緒刻度。
  - 品牌：它在「聽」，而且被故事養大。
- 動畫上，一個「舒展程度」的參數就能帶出好奇、害羞、感動，很適合做首頁上會呼吸、會注意你的角色。
- 色鉛筆的排線和紙紋放在共振的奶油紙上很融洽，符合「一支筆」的網站語言。也已確認在夜紙上成立：奶油色鉛筆輪廓加上調色底層。

**最弱的地方**
- 除了芽以外，身體和臉仍在「可愛圓身、深色眼、腮紅」的類型慣例裡。身體是一顆相當素的球莖，辨識度幾乎全押在芽上。
- 色鉛筆質感無法即時動畫，必須烘焙成圖。芽的舒展也不是單純旋轉就能做，需要多張狀態圖或 Rive 網格變形，這是三個方向中比較吃動畫成本的一點。
- 夜紙版靠調色底層才成立，整體略平。
