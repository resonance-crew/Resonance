# B｜蠟筆流體生命：漾漾 Plip（第二版）

**一句話定位：首頁那團薰衣草色塊托起的一滴杏桃色。它聽故事，聽到心裡去了，顏色就會暈開。**

- 中文名「漾漾」：「漾」是水波一圈一圈盪開，也是顏色在紙上暈開。
- 英文名 Plip：一滴水落進水面時那聲很小的「噗」。

檔案：

- `character.svg`：角色本體，已拆件
- `concept.svg` / `concept.png`：概念圖
- `gen.py`：產生上述 SVG 和檢查頁的腳本，筆觸、配色、姿勢都從這裡改；第一版腳本留在 `gen-v1.py`
- `checks/`：這一輪的驗證圖
  - `sizes.png`：48／96 px 與剪影，主姿勢、探頭、第一版並列
  - `blob-day.png`、`blob-night.png`：合成在首頁色塊上
  - `over-text.png`：白天壓在字上
  - `night-pools.png`：夜色塊 L23% 與 L28% 並列
  - `neck-stretch.png`：頸部 scaleY 1.35

## 1　角色概念

**核心想法。** 拍一滴水落進水面的高速攝影，會看到水面先凹下去，接著彈起一根細細的水柱，柱頂托著一顆圓圓的水珠。漾漾就是那一刻活了過來，只是材料換成蠟筆的顏色。

- 水柱是池子本身升起來的，所以和池子同樣是薰衣草色。
- 柱頂托著的那一滴是另一種顏色（杏桃），也就是它的頭和臉。
- 水柱升起後往前一彎，把那滴顏色遞到你面前。

**池子就是首頁的色塊。** 共振首頁的 hero 區有幾團桃、鼠尾草、薰衣草色塊慢慢漂移，兩團相遇時會長出一段頸部、混色、融成一團（metaball）。漾漾不另外帶一個池子：

- 它的池子就是首頁右下那團薰衣草色塊，同一個色票、同一個透明度、同一種顆粒。
- 角色本身只有升起來的頸、頭和一隻手。
- 頸的下緣淡出成透明，接到下面任何顏色上。

所以它不是放上頁面的吉祥物，而是本來就住在那些色塊裡的生命。

**和共振理念的關係**（自然呼應，不硬扣象徵）：

- 一團色塊托起另一種顏色的一滴，看起來就像在小心地捧著別人的東西。不用解釋，看了就知道。
- 它被打動時，臉頰的顏色會往下流進池子裡（暈開）。兩隻漾漾的池子碰在一起時，漣漪會互相穿過、交疊。
- 故事、共鳴、連結都由身體的行為表達，而不是畫在身上的符號。每一隻頭頂都有一個自己的「旋」。

## 2　外型設計

**輪廓（主姿勢）**
- 頭：一顆寬大於高的扁圓（寬 300、高約 224，約 1.35：1）。下緣略飽滿，像被托住的水珠。
- 頸：細、有明顯收腰。最細處約 47，只有頭寬的六分之一；往上在下巴底下微微展開，往下在水面張開後淡出。
- 頸的彎：先往上升，再往前彎進頭的後下方，像半個問號。頭往左歪 5°。
- 手：另一束細細的水柱從池面濺起，頂端一顆小掌，在臉旁邊揮。
- 地上：兩三圈斷續的漣漪，用網站「一支筆」的線畫。

**比例**
- 主姿勢從頭頂到最外圈漣漪約 418 單位，頭佔一半。
- 頸可以縮到 0（頭沉到水面，見「被感動」），也可以拉成一整個問號（見「好奇探頭」）。

**五官**
- 眼睛是水滴形，尖端朝上微微向內，傾斜角比第一版小一半，所以表情是專注、好奇，而不是擔心。
- 每隻眼的外上緣有一道鉛筆線（眼瞼），抬高就是睜大、好奇，壓低就是睏、害羞。
- 眼裡只有一道蠟筆跳過紙面留下的白，不是貼紙式的閃光。
- 嘴是小小張開的笑：底下一塊深色蠟筆，上緣一道鉛筆線，嘴角往上翹。
- 臉頰的紅暈用斜排線畫，下面再墊一層暈開的色。
- 沒有眉毛，只有強烈情緒時才會冒出兩小筆（也是鉛筆畫的）。

**材質**
- 頭、頸、手：油性粉彩（或蠟筆）厚塗在有紋理的紙上，紙面凹處留白，邊緣毛糙。
- 線：鉛筆，只描頭的上緣、眼、口和頭頂的旋，不描全身。
- 池子：首頁色塊本身，平塗加顆粒，沒有粉彩。

**主要色彩**

| 用途 | oklch |
| --- | --- |
| 頭（杏桃奶油） | `oklch(86.5% 0.058 64)` |
| 頭的陰影排線 | `oklch(76% 0.085 46)`，更深處 `oklch(68% 0.095 40)` |
| 頭頂受光面的奶油粉彩 | `oklch(95.5% 0.028 88)` |
| 頸、手（首頁薰衣草，色相 290，降低彩度成粉彩） | `oklch(79% 0.05 293)` |
| 頸往頭頂變淺處 | `oklch(84% 0.04 305)` |
| 頸的陰影排線 | `oklch(68% 0.058 292)`，亮面 `oklch(90% 0.028 300)` |
| 池子 | 直接用網站色票 `--color-lavender`：白天 `oklch(80% 0.07 290)`，夜間 `oklch(30% 0.045 290)`，透明度 0.25，和 hero 的 `.blob2` 一樣。畫面上實測：白天約 `oklch(92% 0.01 312)`，夜間約 L23% |
| 一支筆（鉛筆，中間調） | 白天 `oklch(50% 0.05 50)`，夜紙 `oklch(64% 0.035 62)` |
| 腮紅 | `oklch(74% 0.1 22)` |
| 眼、嘴（暖黑褐） | `oklch(30% 0.035 42)`，口內 `oklch(62% 0.11 25)` |

**最具辨識度的特徵：身上三件不會變的事**
1. 扁圓的頭，加上一段細腰、彎成半個問號的頸。這是剪影，48 px 也看得出來。
2. 一支筆描的頭頂、水滴形的眼睛、頭頂一個鉛筆畫的旋。旋放大到首頁尺寸約 12 px 半徑、2 px 線寬。
3. 從首頁色塊裡升起，走到哪都帶著漣漪。

其餘部分都可以伸長、壓扁、長出手、沉回水裡。

## 3　個性與情感

**第一印象**：一個很認真聽你說話的小傢伙。它不是站著看你，而是把脖子彎過來、頭歪一點，湊近你。

| 情緒 | 身體怎麼表現 |
| --- | --- |
| 好奇 | 頸拉長、彎成一整個「？」，頭歪向一邊；眼瞼的線抬高，冒出兩道往上拱的眉，嘴是小小的「喔」。可以只伸頭和頸從畫面邊緣探進來，池子留在畫面外（概念圖「好奇探頭」） |
| 開心 | 頭上下彈，漣漪變密、往外擴；手從池面濺起來揮動，臉頰變暖，嘴角的線翹得更高 |
| 害羞 | 頸縮短，頭往下沉到一半，頭頂的旋縮緊；眼瞼的線壓低，腮紅的顏色滲進池子 |
| 感動 | 頭沉到水面，下半顆淡進池子裡；眼睛閉成兩道弧，眼角掛一顆薰衣草色的淚珠，臉頰的顏色往下流，在水面暈成一圈玫瑰色；手貼在臉頰上（概念圖「被感動」） |
| 陪伴 | 兩隻漾漾的池子靠近、相融成一池（就是首頁色塊融合的動作），兩顆頭靠在一起，手在中間碰一下，兩組漣漪同步漾開 |

## 4　手繪風格

**筆觸與色彩**
- 頭、頸、手：沒有外框，形狀靠色面本身。每個部位疊兩到三層：先鋪一層淺底，再用深一號的同色系排線畫陰影（光從左上來），最後在受光面疊奶油色粉彩。
- 頭和頸是兩支蠟筆：頸是池子的薰衣草；頭是杏桃，只在下巴底下沾一點薰衣草，接得起來。
- 一支筆：網站的主線是 1.8 px、次線 1.2 px。本稿設定在首頁以 320 px 顯示整張 800 畫布（每單位 0.4 px），所以：
  - 主線 4.5 單位，用在頭的上緣、眼瞼、嘴、旋、內圈漣漪；
  - 次線 3 單位，用在外圈漣漪和手邊的水面。
  - 鉛筆是中間調，白天和夜紙各一個值。每道線畫兩次：第二次細一點、淡一點、沒對準第一次，像手重描過。

**SVG 技法**（全部在 `gen.py`，固定種子，可重現）

1. **圖層由後到前**
   - `b-pool`：首頁色塊
   - `b-ripples`：鉛筆
   - `b-underpaint`：打底
   - `b-crayon`：粉彩本體，裡面是 `b-figure`，拆件都在這裡
   - `b-meniscus`、`b-wave-marks`：鉛筆

   `b-pool` 和 `b-ripples` 各自獨立，可以分別隱藏。
2. **部位只留色面和手抖邊**：每個部位只有 `b-f-warp` 一個濾鏡。它用兩層 `feTurbulence` + `feDisplacementMap`：低頻 0.016、位移 13 做手繪的大抖動，高頻 0.5、位移 7 做蠟筆邊緣的毛糙。
3. **一層共用的紙紋**
   - 紙紋是 `b-m-tooth` 遮罩，套在 `b-crayon` 上。座標是角色的根空間，不在任何部位的 transform 裡。
   - 遮罩內容：非等向分形雜訊（0.36 × 0.7）當紙面凹凸，加上極低頻雜訊（0.03）模擬手的輕重，再用 `feComponentTransfer` 取門檻。
   - 所以部位被拉長、壓扁時，顏色和邊緣跟著變形，紙紋顆粒不會（見 `checks/neck-stretch.png`）。
4. **打底**
   - `b-underpaint` 用 `<use>` 引用整個 `b-figure`，經 `feMorphology erode` 內縮 7 單位：白天填紙色（不透明），夜間填「自身顏色乘 0.62」。
   - 因為從角色本身的剪影算出來，任何部位怎麼動，打底都跟著動，不用每個部位各寫一個。
   - 內部的紙紋凹處露出打底：白天是紙，所以文字不會從身體裡透出來（見 `checks/over-text.png`）；夜間是暗一階的自身顏色，不會變成髒黑點。
   - 最外圈 7 單位沒有打底，凹處直接露出底下的頁面，邊緣保持蠟筆的斷口。
5. **頸根淡出**：頸和手的根部用漸層 `mask` 淡成透明，不是淡成某個顏色，所以下面是 hero 色塊、夜紙或別的底色都接得上。
6. **一支筆**
   - 每道線是一個「落筆輕、中段穩、收筆提起」的填色外形，不是等寬 stroke。
   - 頭頂的線套 `b-f-wob`，和頭的 `b-f-warp` 共用同一個低頻雜訊，所以會落在已經抖動過的邊上。
   - 漣漪的線套 `b-f-pencil`：小幅抖動，加上石墨跳過紙紋的空隙。
7. **池子**：和 `OrganiBlob` 同一個形狀家族（variant 3）。
   - 填 `var(--color-lavender)`，透明度 0.25。
   - 疊一層 `ShapeGrain` 同配方的顆粒：`fractalNoise`、去飽和、alpha 0.2，頻率換算成首頁尺寸，強度跟著 `--grain-scale`。
8. **夜紙開關**：都是 CSS 自訂屬性，外層設好就切換。
   - `--b-under`：打底濾鏡換成夜間版
   - `--b-pen`：夜間的筆色
   - `--b-figure`：輕微壓暗
   - `--color-lavender`、`--grain-scale`：直接沿用網站的值

## 5　Landing Page 的應用想像

**放在哪裡**：只放在色塊裡。
- 桌機：右下那團薰衣草色塊，或主標右側。
- 手機：只從右緣伸頸進來。

整合時把 `b-pool` 隱藏，頸根直接淡進頁面上的那團色塊，漣漪畫在色塊上（`checks/blob-day.png`、`checks/blob-night.png`）。標題、副標、下載區維持原樣。

**出場**（三種，隨機輪替）：
- **落下**：一顆小水滴從頁首 logo 的三道波浪附近落下，掉進色塊時「噗」一下漾開兩圈漣漪，水柱彈起，托著頭升出來。
- **探頭**：只把頭和頸從視窗右緣伸進來，彎成「？」，先看標題，再轉過來看訪客。
- **浮出**：色塊表面先冒一個小泡，頭慢慢浮上來，頸跟著長出來。

**停留**：
- 慢慢呼吸（頸 1.02 倍伸縮），每 3–6 秒眨一次眼。
- 頭微微跟著游標歪（±6°），瞳孔偏移 ±3 px，眼瞼的線跟著抬。
- 游標停在下載按鈕上時，從池面濺起一隻手揮一揮。
- 訪客往下捲時，它稍微沉下去一點，好像在目送。

**遇到另一個角色**：首頁本來就會讓兩團色塊相遇、長出頸部、融合。所以互動是現成的：
1. 兩團色塊靠近時，兩隻先注意到對方（轉頭、眼睛看過去），頸往彼此彎。
2. 額頭輕碰一下，兩組漣漪交疊，交會處的顏色互染一點點。
3. 分開時各自帶走一點對方的顏色，幾秒後才褪掉。

**離場與再出現**：
- 頭沉回色塊（頸縮短、頭淡進去），色塊變回一團普通的漂移色塊，紙上留一圈慢慢淡掉的漣漪。
- 過一陣子，它從另一團色塊裡升出來。它不是固定在某個位置，而是「住在顏色裡」。

**手機與無障礙**
- 手機上只出現一隻，從右緣伸頸進來。
- `prefers-reduced-motion` 時，頭靜止坐在色塊裡（短頸），只保留眨眼。

## 6　未來系列化的潛力

同一個世界觀是「每個角色都是液體的一個瞬間，從首頁某一團顏色裡長出來，用不同的筆畫在同一張紙上」。差異來自下面三個軸，而不是換色或加配件：

1. **液體的「時刻」決定身體結構和個性。**
   - 漾漾是「回彈升起」：好奇、主動湊近。
   - 「垂」是一滴從頁首掛下來、拉得長長的水珠，倒吊著看人，動作慢、愛沉思、話很少。
   - 「泡」是一顆浮著的泡泡，身體是一層薄膜，膽小又輕飄，被碰到就會破了再重組。
   - 「濺」是一攤啪地濺開、身邊散著小水點的角色，熱鬧、停不下來。
   - 「絲」像拉開的蜂蜜絲，身體連著兩個點，負責把大家牽在一起。

   五個剪影完全不同，卻都是同一種物理現象的親戚。
2. **黏稠度決定動態節奏。** 稀的角色（像水）晃動快、頸能拉很長、容易濺。稠的角色（像膏狀顏料）動作慢、能保持捏出來的尖角、比較固執。同樣是「打招呼」，兩種黏稠度做出來是兩種性格。
3. **筆的種類決定質地。** 漾漾是油性粉彩加一支鉛筆。其他角色可以是：
   - 水性色鉛筆：邊緣有水漬暈開
   - 粉筆：乾、粉粉的、會掉屑
   - 蠟筆刮畫：底色從刮痕透出來

   紙、「一支筆」的線條重量，以及「從首頁色塊長出來」這件事不變，所以放在一起仍是同一個世界。

## 參考與避免仿作

**實際參考的只有兩樣**：水滴回彈（Worthington jet）的物理現象，以及共振首頁自己的 metaball 色塊。沒有拿任何既有角色當參考圖。完成後主動比對過下列角色和造型：

| 相近的既有角色或造型 | 像在哪裡 | 刻意避開了什麼 |
| --- | --- | --- |
| 寶可夢「臭泥」（Grimer） | 同樣是「從自己的一灘裡冒出來的生物」 | 沒有往下滴的手臂、沒有大嘴、不是暗紫色污泥質感。漾漾的池子是首頁的淺色塊，身上只有一段細頸、一滴頭、一隻手 |
| 巴巴爸爸（Barbapapa） | 會變形的軟體生物 | 不用洋梨形單色身體、不用平滑向量；漾漾是「細頸托著一滴」，而且兩色 |
| 勇者鬥惡龍史萊姆 | 水滴形加臉 | 頭是扁圓，頭頂沒有尖角；水滴形只用在眼睛 |
| 百變怪（Ditto） | 無定形加點點眼 | 不用點點眼 |
| Molang | 小眼睛分很開＋小嘴 | 試過「小眼分很開」的臉，太像就放棄了 |
| 嚕嚕米的 Hattifattener | 管狀身體、從側面長出手 | 手不是從身體側面長出來的一把手指，而是池面濺起的單一小掌 |
| なめこ（Nameko）等菇類角色 | 第一版的「圓頭＋粗頸」剪影 | 這一版改成細腰彎頸，頭從頸的後下方被托起，不是正中央頂著一個蓋；`checks/sizes.png` 的 48 px 剪影已不是菇或燈泡 |
| 寶可夢「蚊香蝌蚪」的肚子漩渦 | 漩渦花紋 | 漾漾的旋在頭頂、是一道鉛筆線，不在肚子上、不是大面積黑白漩渦 |
| 尼斯湖水怪的通俗圖像 | 從水面伸出長頸 | 沒有隆起的背、沒有爬蟲的頭；頭是一滴有正臉的扁圓，頸就是池子本身。這是民間圖像，不是特定 IP |
| 皮克斯檯燈 | 頸往前彎得太多時，剪影會像檯燈 | 剪影草稿裡試過「大幅前彎」，像檯燈或蓮蓬頭，所以主姿勢只彎半個問號 |

靜態剪影仍有一點「細繩繫著氣球／棒棒糖」的讀法。彎頸、頸根的張開、漣漪和那隻手是用來打散這些讀法的。

## 實作成本粗估

| 項目 | 人日 |
| --- | --- |
| 插畫完稿（主姿勢、探頭、沉下、側身，加 4 個表情頭） | 2–3 |
| 拆件與烘焙（頭、眼、嘴、手、旋各自烘成 2 倍解析度的 WebP；頸和池不烘） | 1–1.5 |
| `DriftingBlobs` 對外介面：指定一團色塊給角色，頭底放一個 lobe，頸由引擎自然長出；兩套迴圈同步 | 2.5–3.5 |
| 出場：落下→彈起→升出 | 1.5 |
| 停留：呼吸、眨眼、看游標、揮手 | 1 |
| 互動：兩池相融、碰額頭、漣漪交疊 | 2 |
| 離場：沉回、縮成水珠 | 1 |
| 夜色、reduced-motion、手機、效能調校 | 1.5–2.5 |
| **合計** | **約 12–16 人日（一位插畫兼動態，加一位前端）** |

第一版估 11–13 人日。這一版採用動態評審的實作路線，把色塊耦合和夜色的風險算進去，所以調高。

**前端建議**

- **首選：SVG/Canvas，接上現有 metaball 引擎。**
  - 頭、眼、嘴、手、旋做成烘焙好的獨立圖層，只動 transform。
  - 頸和池直接交給 `driftingBlobs` 畫：池是那團色塊，頭底一個 lobe，頸就是兩團之間自然長出的 neck。
  - 顆粒用和 hero 相同的螢幕空間顆粒疊上。
  - 這是唯一能讓「伸縮不拉紋路、又和首頁同一套語言」的做法，但要改 `DriftingBlobs`。
- **不再首選 Rive。** 網格變形會連烘在貼圖裡的紙紋一起拉長，和這一版把紙紋移到螢幕空間的做法相反。
- **不建議 Lottie。** 不支援 SVG 濾鏡和網格變形，頸彎曲會很僵。

**效能風險**
- `character.svg` 是靜態稿，只適合靜態圖和縮圖：
  - 9 個濾鏡、24 處引用、222 個 path、約 110 KB。
  - 打底用 `<use>` 把整隻角色再畫一次，紙紋遮罩鋪滿整個角色範圍。
  - 這些若在動畫中逐格重算，一定掉幀。
- 動畫版：
  - 濾鏡全部換成烘焙圖層加螢幕空間顆粒。
  - 頸的毛邊交給 metaball 輪廓加一點位移雜訊。
  - 同時在場的角色最多 2 隻。

## 自評

**最強的地方**
- 「住在首頁色塊裡」現在在畫面上兌現了：池子就是那團色塊（同色票、同透明度、同顆粒），頸是那團顏色升起來的，合成在首頁上看不出接縫（`checks/blob-day.png`、`blob-night.png`）。
- 變形本身就是表情：伸長是好奇，沉下是害羞，顏色暈開是感動。新加的鉛筆眼瞼和唇線讓靜態圖也有表情可調，不全靠動態。

**最弱的地方**
- 剪影已經不像燈泡或菇，但「圓頭＋細彎頸」仍可能被讀成氣球、棒棒糖或水怪，辨識度還是比有固定四肢的角色弱。48 px 時主要靠剪影和兩個眼點，旋和眼瞼要到 96 px 才看得清楚。
- 前端成本仍是三案中最高，而且集中在和 `DriftingBlobs` 的耦合，事先最難估準。

## 修訂紀錄（第二版，2026-10-27）

這一輪只處理兩位評審的必修項目，以及與必修重疊的弱點。第一版保留為 `character-v1.svg`、`concept-v1.png`、`proposal-v1.md`、`gen-v1.py`。

### 改了什麼

**角色設計評審 1：重畫頭頸比例**
- 頭改成寬大於高的扁圓（300 × 約 224）。
- 頸從第一版最細處約 120 改成約 47，有收腰（下巴底下和水面處較寬），並且彎成半個問號，不再是直柱。
- 頸的顏色改成首頁薰衣草（色相 290、293），拿掉第一版頸中段的玫瑰色。
- 剪影驗證：主姿勢在 48 px 已不像燈泡或菇，探頭姿勢一起檢查（`checks/sizes.png`）。
  - 中途試過「頭在正上方、頸直立」，剪影像棒棒糖或樹，所以改成頭從頸的後下方被托起、頸往前彎。
  - 探頭的頸也從斜直線改成 J 形彎，避免像湯杓或平底鍋柄。
  - 剪影草稿是 `tools/silx.py`。

**角色設計評審 2：池子就是首頁色塊**
- `b-pool` 改成 hero 薰衣草色塊的配方：`var(--color-lavender)`、透明度 0.25、`ShapeGrain` 同配方的顆粒。粉彩只留在頭、頸、手。
- 漣漪和水面線從粉彩改成鉛筆線。
- 合成驗證：`checks/blob-day.png` 把池子隱藏，直接用首頁截圖右下的色塊。
- 白天的打底改成紙色、不透明，壓在 hero 字上也不透字（`checks/over-text.png`）。

**角色設計評審 3：補一支筆**
- 新增中間調鉛筆線，只描頭的上緣（`b-line-head`）、兩眼的外上緣（`b-lid-*`）和嘴（`b-lip`），沒有全身描邊。
- 主線 4.5 單位，在首頁尺寸等於網站主線 1.8 px。
- 頭頂的旋從蠟筆小點改成同一支筆的螺旋，半徑由 20 放大到 30 單位，在首頁尺寸約 12 px 半徑、2 px 線，看得見。

**動態評審 1：夜紙打底內縮**
- 打底改由整隻角色的剪影經 `feMorphology erode` 內縮 7 單位而來（`b-underpaint`）。夜紙上邊緣保持蠟筆斷口，不再是硬邊圓盤。
- 第一版頭左下的灰斑，來自頭的淡出遮罩疊在頸的打底上。這一版頭不再用底部淡出遮罩，頭頸交界只用一點薰衣草和下巴陰影，灰斑消失（`checks/blob-night.png`、`concept.png` 夜紙格）。

**動態評審 2：紙紋從部位抽出**
- 每個部位只留色面和 `b-f-warp` 邊緣。
- 紙紋改成套在 `b-crayon` 上的一個遮罩（`b-m-tooth`），在角色根空間。
- `gen.py` 產生 `checks/neck-stretch.html`：頸 scaleY 1.35 從根部拉長、頭跟著升高。渲染結果（`neck-stretch.png`）顆粒大小和方向不變。

**動態評審 3：池子和色塊的關係定案**
- `b-pool`、`b-ripples` 是兩個獨立群組，可以分別隱藏。
- 頸根和手根淡成透明（遮罩），不是淡成某個顏色，接得上任何底色。
- 夜紙檢查改用首頁夜色塊的實際值（見下一節「數值不一致的處理」）。

**與必修重疊的弱點，一併處理**
- 「臉偏擔心」：
  - 必修 3 要描眼和口，所以順便調了這兩處：眼睛傾斜角從 10°／−6° 改成 6°／−4°，嘴從「喔」改成張開的小笑。
  - 探頭的眉改成往上拱，不再是內側上揚的擔心眉。
- 「48–64 px 時臉幾乎看不見」：頭佔比變大，加上鉛筆線，64 px 仍看得到眼和笑；48 px 只剩兩個眼點。
- 「靜態太依賴動態」：鉛筆眼瞼和唇線提供了靜態可調的表情。

### 兩位評審意見的取捨

**夜紙的明度**
- 動態評審寫「約 L28% 薰衣草」。實際色票是夜間 `--color-lavender` = `oklch(30% 0.045 290)` × 透明度 0.25，在首頁截圖上實測約 L23%。
- 概念圖的夜紙格用實際值（L23%），因為那就是角色真正會遇到的底。
- `checks/night-pools.png` 另外並列 L28%，兩種底上頭、頸、漣漪都讀得出來，兩位評審的目的都滿足。

**打底**
- 角色評審要「白天不透明、與紙同色」，動態評審要「內縮 6–8 px、邊緣保持斷口」。兩者合成同一層：內縮 7 單位，白天填紙色、夜間填暗一階的自身顏色。
- 動態評審原本說的是各部位的 `--b-under-*` 打底。但紙紋移到根空間之後，打底不能再放在部位裡（否則會被紙紋遮罩一起挖洞），所以改成從整隻角色的剪影算出一層。
- 結果一樣：打底跟著部位動，邊緣留 7 單位斷口。CSS 變數也改成一個 `--b-under`。

**實作路線**
- 動態評審不建議 Rive 網格，建議頸和池交給 metaball 引擎。這和紙紋移到螢幕空間是同一件事，所以採用。
- 前端建議和成本估計（12–16 人日）照此更新。

### 沒有改的，和理由

- **手常被讀成尾巴或觸手**：這是弱點，不是必修。這一輪只把手移近臉旁、掌心加大一點，沒有重新設計。
- **動畫成本高**：不是這一輪能解決的，只更新了實作路線和估計。
- **剪影仍可能讀成氣球、棒棒糖或水怪**：已用彎頸、頸根張開、漣漪和手降低風險，但「圓頭＋細頸」這個結構是兩位評審都要求保留的世界觀核心（頭被色塊托起），所以不再往前改。已在自評和避免仿作中寫明。
- **沒有新增變體、新角色或動畫**；`explore.svg/png` 維持第一版的剪影草案。
