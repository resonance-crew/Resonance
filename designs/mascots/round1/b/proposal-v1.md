# B｜蠟筆流體生命：漾漾 Plip

**一句話定位：一滴從自己的池子裡升起來的顏色。它聽故事，聽到心裡去了，顏色就會暈開。**

- 中文名「漾漾」：「漾」是水波一圈一圈盪開，也是顏色在紙上暈開。
- 英文名 Plip：一滴水落進水面時那聲很小的「噗」。

檔案：`character.svg`（角色本體，已拆件）、`concept.svg` / `concept.png`（概念圖）、`explore.svg` / `explore.png`（剪影草案）、`gen.py`（產生上述 SVG 的腳本，筆觸、配色和姿勢都從這裡改）。

---

## 1　角色概念

**核心想法。** 拍一滴水落進水面的高速攝影，會看到水面先凹下去，接著彈起一根水柱，柱頂再托著一顆圓圓的水珠，周圍漾開一圈圈漣漪。漾漾就是那個瞬間活了過來，只是材料換成蠟筆的顏色：圓圓的頭是那顆水珠，脖子是彈起的水柱，身體是它自己的一池顏色，走到哪裡池子和漣漪就跟到哪裡。

**靈感來源。** 一是上面說的水珠回彈物理現象（Worthington jet）。二是共振首頁現在的世界觀：hero 區三團桃、鼠尾草、薰衣草色塊慢慢漂移，兩團相遇時會長出一段頸部、混色、融成一團（metaball）。漾漾的身體結構就是那段頸部：頭和池子之間沙漏形的收腰，正是兩團色塊「快要融合」時的形狀。所以它不是另外放上頁面的吉祥物，比較像本來就住在那些色塊裡的生命。

**和共振理念的關係**（自然呼應，不硬扣象徵）：
- 它的頭和池子是兩種顏色（杏桃和薰衣草），脖子是兩色交疊的地方。它本來就是「兩滴顏色相遇後長成的」，不用解釋，看了就知道。
- 它被打動時，臉頰的顏色會往下流進池子裡（暈開）。兩隻漾漾的池子碰在一起時，漣漪會互相穿過、交疊。故事、共鳴、連結都由它的身體行為表達，而不是畫在身上的符號。
- 每一隻的頭頂都有一個自己的「旋」，就像每個人都不一樣。

**為什麼選這個。** `explore.png` 一開始畫了三個剪影：①雙球頸（兩團融成一個）看起來像雪人或穿毛衣的人；②三道漣漪花紋讀起來像條紋毛衣或手套，花紋搶走了生命感；③拖痕（走過留下一抹）動感最好，但靜態看是一隻蛞蝓。後來取 ① 的「頸」和 ③ 的「痕」，把痕跡改成漣漪，就成了「從池子裡升起的一滴」。它在三個草案裡最像一個有姿態的生命，也最直接接上首頁的色塊世界。

## 2　外型設計

- **輪廓**：圓頭＋沙漏形收腰的脖子＋又寬又低的池子，地上兩三圈斷續的漣漪。另有一隻「手」從池面長出來：一根細莖頂著一片橢圓手掌，揮手時就像水面濺起一束。
- **比例**（主姿勢）：頭寬 1，脖子最細處約 0.45，池子約 1.7。總高約 1.75 個頭高。脖子可以縮到 0（頭直接坐在池子裡），也可以拉到 2 個頭長（探頭）。
- **五官**：
  - 眼睛是水滴形，尖端微微朝內，所以表情顯得認真、真誠，有點怕打擾人。眼裡只有一道蠟筆跳過紙面留下的白，不是貼紙式的閃光。
  - 嘴很小，好奇時是小小的「喔」，開心時是一彎。
  - 臉頰的紅暈用斜排線畫，下面再墊一層暈開的色。
  - 沒有眉毛，只有強烈情緒時才會冒出兩小筆。
- **材質**：油性粉彩（或蠟筆）厚塗在有紋理的紙上。紙面凹處留白，邊緣毛糙，沒有外框線。
- **主要色彩**：

| 用途 | oklch |
| --- | --- |
| 頭（杏桃奶油） | `oklch(86.5% 0.058 64)` |
| 頭的陰影排線 | `oklch(76% 0.085 46)`，更深處 `oklch(68% 0.095 40)` |
| 疊在頭頂受光面的奶油色粉彩 | `oklch(95.5% 0.028 88)` |
| 池子（霧薰衣草） | `oklch(80% 0.042 304)`，陰影 `oklch(68% 0.055 298)`，亮面 `oklch(90% 0.03 310)` |
| 兩色交會的玫瑰色（脖子中段） | `oklch(80% 0.06 18)` |
| 腮紅 | `oklch(74% 0.1 22)` |
| 眼、嘴（暖黑褐） | `oklch(30% 0.035 42)`，口內 `oklch(62% 0.11 25)` |
| 漣漪 | `oklch(70% 0.05 300)`、`oklch(74% 0.06 50)` |
| 紙上的記號（揮手線） | `oklch(66% 0.075 45)`：中間調，奶油紙和夜紙上都看得見 |

  色相全部取自網站既有的卡片色系：55 桃、290 薰衣草、18 玫瑰。

- **最具辨識度的特徵：身上三件不會變的事。**
  1. 水滴形的眼睛
  2. 頭頂一個自己的「旋」
  3. 走到哪都帶著的池子和漣漪

  其餘部分都可以伸長、壓扁、長出手、沉回水裡。變形再大，只要這三樣還在就認得出來。縮到 48px 時，靠的是「圓頭＋細頸＋扁池」的燈泡式剪影，再加上那隻舉起來的手。

## 3　個性與情感

**第一印象**：一個有點害羞、很認真聽你說話的小傢伙。不吵不鬧，你說話時它會把脖子伸過來一點。

| 情緒 | 身體怎麼表現 |
| --- | --- |
| 好奇 | 脖子拉長、彎成一個「？」，頭歪向一邊，眼睛睜大，尖端往上提。可以只伸頭和脖子從畫面邊緣探進來，池子留在畫面外（概念圖「好奇探頭」） |
| 開心 | 頭上下彈，池子的漣漪變密、往外擴。手從池面長出來揮動，臉頰變暖 |
| 害羞 | 往下沉，脖子縮短到頭坐進池子裡，頭頂的旋轉開不讓你看。腮紅的顏色滲進池子 |
| 感動 | 眼睛閉成兩道弧，眼角掛一顆池子色的淚珠。臉頰的顏色順著脖子流進池子（暈開），漣漪染成玫瑰色。手貼在臉頰上（概念圖「被感動」） |
| 陪伴 | 兩隻漾漾的池子靠近、相融成一池（就是首頁色塊融合的動作），兩顆頭互相靠著，手在中間碰一下。兩組漣漪同步漾開 |

## 4　手繪風格

**筆觸與色彩**：
- 沒有外框線，形狀完全靠色面本身。
- 每個部位疊兩到三層：先鋪一層淺底，再用深一號的同色系排線畫陰影（光從左上來），最後在受光面疊奶油色粉彩。
- 脖子是兩支蠟筆互相疊塗：上段杏桃、中段玫瑰、下段薰衣草。
- 和網站「一支筆」的關係：揮手線和漣漪是「一支筆」裡的線條，用單一中間調，粗細在 Landing 尺寸約落在 2–3px，和全站的主線同一個量級。

**SVG 技法**（全部手寫在 `gen.py`，固定種子，可重現）：
1. **`b-f-warp`（手抖與毛邊）**：兩層 `feTurbulence` + `feDisplacementMap`。先用低頻（0.016，位移 13）做手繪的大抖動，再用高頻（0.5，位移 7）做蠟筆邊緣的毛糙。同一部位的每一層都在這個濾鏡裡，所以底色和排線的邊緣保持對齊。
2. **`b-f-tooth1` / `b-f-tooth2`（紙紋空隙）**：
   - 非等向分形雜訊（0.26 × 0.78）當紙面凹凸，加上一層極低頻雜訊（0.03）模擬手的輕重，再用 `SourceAlpha` 高斯模糊讓邊緣附近的顏色比較薄。
   - 三者以 `feComposite arithmetic` 相加，經 `feComponentTransfer` 取門檻後成為 alpha 遮罩（`operator="in"`）。
   - 第二、三層用更高的門檻，只沾到紙紋的峰頂，所以越後面的層，露出的紙越多，跟真的蠟筆一樣。
3. **粉彩筆觸**：每一筆是一個「中間粗、兩頭細、微彎」的填色形狀（不是等寬 stroke），由腳本依光源方向機率性散佈在各部位內，`clipPath` 裁切後再過紙紋濾鏡。
4. **融合**：頭的下緣用漸層 `mask` 淡出，接到同色的脖子上。脖子和手的根部也淡進池子裡，看起來是一整團液體，但每個部位仍然是獨立圖層。
5. **眼、嘴**：用 `b-f-ink`（小位移＋少量紙紋）做出蠟筆壓實的濃色。**腮紅**：先墊一層 `b-f-bleed`（模糊後再上紙紋），再疊斜排線。
6. **夜紙**：每個部位底下都有一層 `style="fill:var(--b-under-head, none)"` 的打底。
   - 淺色模式沒有這層，紙紋空隙露出奶油紙。
   - 深色模式設 `--b-under-head / --b-under-neck / --b-under-pool`（約 L 68–77% 的同色），空隙就露出暗一階的自身顏色，不會變成髒黑點。另外整體 `brightness(0.93)`。
   - 眼、嘴本來就在淺色身體裡，深色時不會消失。漣漪和揮手線是中間調，兩種紙上都看得到。

## 5　Landing Page 的應用想像

**放在哪裡**：不另外開一塊空間。漾漾住在 hero 現有的漂移色塊裡，薰衣草那團（桌機右下、手機底部）就是它的池子。標題、副標、下載區維持原樣，它只在色塊的範圍裡活動，不會蓋到文字。

**出場**（三種，隨機輪替）：
- **落下**：一顆小水滴從頁首 logo 的三道波浪附近落下，掉進色塊時「噗」一下漾開兩圈漣漪，水柱彈起，頭跟著升出來。
- **探頭**：只把頭和脖子從視窗右緣伸進來，彎成「？」，先看標題，再轉過來看訪客。
- **浮出**：色塊表面先冒一個小泡，頭慢慢浮上來。

**停留**：
- 慢慢呼吸（池子 1.02 倍伸縮），每 3–6 秒眨一次眼。
- 頭微微跟著游標歪（±6°），瞳孔偏移 ±3px。
- 游標停在下載按鈕上時，從池面長出手揮一揮。
- 訪客往下捲時，它稍微沉下去一點，好像在目送。

**遇到另一個角色**：首頁本來就會讓兩團色塊相遇、長出頸部、融合。所以互動是現成的：
1. 兩個池子靠近時，兩隻先注意到對方（轉頭、眼睛看過去），脖子往彼此伸長。
2. 額頭輕碰一下，兩組漣漪交疊，交會處的顏色互染一點點。
3. 分開時各自帶走一點對方的顏色，幾秒後才褪掉。

**離場與再出現**：
- 頭沉回池子（脖子縮短、頭融進去），池子變回一團普通的漂移色塊，或縮成一顆水珠滾出畫面。紙上留一圈慢慢淡掉的漣漪痕。
- 過一陣子，它會從另一團色塊裡升出來。它不是固定在某個位置，而是「住在顏色裡」。

**手機與無障礙**：手機上只出現一隻，位置在 hero 下方的色塊。`prefers-reduced-motion` 時顯示靜態主姿勢，只保留眨眼。

## 6　未來系列化的潛力

同一個世界觀是「每個角色都是液體的一個瞬間，用不同的筆畫在同一張紙上」。差異來自下面三個軸，而不是換色或加配件：

1. **液體的「時刻」決定身體結構和個性。**
   - 漾漾是「回彈升起」：好奇、主動探頭。
   - 「垂」是一滴從頁首掛下來、拉得長長的水珠，倒吊著看人，動作慢、愛沉思、話很少。
   - 「泡」是一顆浮著的泡泡，身體是一層薄膜，膽小又輕飄，被碰到就會破了再重組。
   - 「濺」是一攤啪地濺開、身邊散著小水點的角色，熱鬧、停不下來。
   - 「絲」像拉開的蜂蜜絲，身體連著兩個點，負責把大家牽在一起。

   五個剪影完全不同，卻都是同一種物理現象的親戚。
2. **黏稠度決定動態節奏。** 稀的角色（像水）晃動快、脖子能拉很長、容易濺。稠的角色（像膏狀顏料）動作慢、能保持捏出來的尖角、比較固執。同樣是「打招呼」，兩種黏稠度做出來是兩種性格。
3. **筆的種類決定質地。** 漾漾是油性粉彩。其他角色可以是水性色鉛筆（邊緣有水漬暈開）、粉筆（乾、粉粉的、會掉屑）、蠟筆刮畫（底色從刮痕透出來）。紙和「一支筆」的線條重量不變，所以放在一起仍是同一個世界。

## 參考與避免仿作

**實際參考的只有兩樣**：水滴回彈的物理現象，以及共振首頁自己的 metaball 色塊。沒有拿任何既有角色當參考圖。完成後主動比對過下列角色：

| 相近的既有角色 | 像在哪裡 | 刻意避開了什麼 |
| --- | --- | --- |
| 寶可夢「臭泥」（Grimer） | 同樣是「從自己的一灘裡冒出來的生物」，是最接近的一個 | 沒有往下滴的手臂、沒有大嘴、不是暗紫色污泥質感；漾漾有清楚的頭頸結構，只有一隻從池面長出的手 |
| 巴巴爸爸（Barbapapa） | 會變形的軟體生物 | 不用洋梨形單色身體、不用平滑向量；漾漾的基本形是「頭＋頸＋池」，而且兩色 |
| 勇者鬥惡龍史萊姆 | 水滴形加臉 | 頭是圓的，頭頂沒有尖角；水滴形只用在眼睛 |
| 星之卡比 | 圓、粉 | 沒有腳，不是粉紅圓球 |
| 百變怪（Ditto） | 無定形加點點眼 | 不用點點眼和紫色 |
| Molang | 小眼睛分很開＋小嘴 | 臉部測試時試過「小眼分很開」的版本，太像就放棄了 |
| 嚕嚕米的 Hattifattener | 管狀身體、從側面長出手 | 手不是從身體側面長出來的一把手指，是池面濺起的單一手掌 |
| 自來水公司那類「水滴寶寶」吉祥物 | 水滴加臉 | 頭不是尖頂淚滴、顏色不是水藍。漾漾是「一滴顏料」不是「一滴水」，所以用暖色蠟筆 |
| 寶可夢「蚊香蝌蚪」的肚子漩渦 | 漩渦花紋 | 漾漾的「旋」很小、在頭頂、是蠟筆一筆畫出來的，不在肚子上、不是大面積黑白漩渦 |

靜態時偶爾也會被看成燈泡、蘑菇或神燈精靈。池子、漣漪和那隻手是用來打散這些讀法的。

**前端建議**：
- **首選 Rive。** 脖子彎、池子扁、頭融進池子都是「網格變形」，Rive 的 mesh 和 state machine（idle / peek / react / leave）最合適。游標跟隨也能直接接。代價是 runtime（wasm）約一百多 KB，要延遲到 hero 首屏之後才載入。
- **輕量替代：SVG / Canvas 自己做。**
  - 池子和脖子的輪廓直接沿用首頁現有的 `driftingBlobs` metaball（marching squares 畫在 canvas 上，30fps、離開畫面就暫停）。
  - 蠟筆質感預先烤成貼圖（WebP），以 pattern 填進輪廓。
  - 頭、手、五官是預先點陣化的獨立圖層，只動 transform。
  - 這條路和網站現有程式碼最一致。
- **不建議 Lottie。** 不支援 SVG 濾鏡和網格變形，脖子彎曲會很僵；蠟筆質感也只能塞點陣圖。
- **效能風險**：
  - 本稿的 `feTurbulence` / `feDisplacementMap` 濾鏡只適合靜態。若在動畫中逐格重算，每個部位每幀都要重新點陣化，手機和多隻角色同框時會掉幀。動畫版一定要先把質感烤成貼圖，濾鏡只留給靜態圖和縮圖。
  - 多層半透明大圖層也吃 GPU 記憶體，需要限制同時在場的角色數（建議最多 2）。

## 自評

**最強的地方**
- 跟首頁世界觀接得最自然：角色就住在現有的漂移色塊裡，「長出頸部、混色、融合」直接就是它的身體語言和互動方式，不用另外發明一套。
- 變形本身就是表情：伸長是好奇，沉下是害羞，顏色暈開是感動。動態表現力很高，而且蠟筆質感在奶油紙和夜紙上都成立。

**最弱的地方**
- 靜態單張時剪影偏簡單，有被讀成燈泡、蘑菇、神燈精靈的風險。辨識度很依賴動態和那三個不變的標誌，縮到 48px 時旋和眼睛都看不太清楚，只剩剪影。
- 臉仍然是常見的「可愛」配置（小眼、腮紅、小嘴）。另外，要做出好看的液體變形，技術門檻（mesh、metaball 對接、預烤質感）比有固定四肢的角色高。
