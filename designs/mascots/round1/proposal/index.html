共振 Resonance　第一階段　角色方向探索

三個方向，三種被故事打動的樣子

三位子代理各負責一個方向，用 SVG 親手繪製角色，每個角色都已拆成可獨立動的部位。接著由兩位評審（角色設計、動態與前端）交叉點評，每個方向再依必修項目修了一輪。這頁的概念圖是修訂後的第二版，每張都可以切回第一版對照。

沒有使用付費的 AI 生圖，也沒有拿網路上的圖片當素材。請看完後選一個方向，或告訴我想混合哪些優點，我再進入第二階段。

  • A　色鉛筆小生物聽芽 Tingya肩上的蕨芽是它的耳朵，聽見故事就舒展
  • B　蠟筆流體生命漾漾 Plip首頁的薰衣草色塊托起的一滴顏色
  • C　撕紙拼貼紙偶摺摺 Tuck一張色紙，折角底下藏著幾行字

方向 A　色鉛筆小生物

聽芽 Tingya

左肩長出一根往外探的蕨芽，像側過來的一隻耳朵。聽見故事時芽會慢慢舒展，害羞時就捲緊。它不搶話，眼瞼半垂，安安靜靜地在聽。

1角色概念

一隻用「芽」聽故事的小生物。靈感來自蕨類的捲芽、包著新芽的葉鞘、耳蝸的螺旋，以及人想聽清楚時把一隻耳朵轉向聲音的姿勢。它的主要動作是聽；它是被故事養大的，聽得越多，芽長得越開。

2外型設計

頭身一體的球莖形。左肩隆起成一段平滑的「葉鞘肩」，芽從那裡長出、往外下方捲，整隻往右傾 3°，身體天生不對稱。招牌眼型是半垂的厚上眼瞼。主色是杏桃燕麥色排線 oklch(73% 0.085 58)，陰影偏赤陶，芽尖與腮紅是玫瑰色。小手、小腳、一截短尾。

3個性與情感

聚會裡坐在角落、你說話時會把頭偏過來的那個人。情緒主要靠芽和眼睛：

  • 好奇：芽半舒展，探向聲音的方向
  • 開心：捲的部分像彈簧彈兩下
  • 害羞：芽捲緊，收到肩後
  • 感動：芽整根舒展、尖端顫動，眼睛閉成弧
  • 陪伴：兩根芽尖輕碰，呼吸慢慢同步

4手繪風格

色鉛筆短排線（背光處才加交叉排線），紙紋讓顏料只留在紙的凸處，輪廓是兩三道帶壓感、頭尾漸細的重描。小尺寸用同一支筆重畫、線寬固定，呼應網站「一支筆」的原則。夜紙版的輪廓用網站夜裡的粉筆墨色，整隻的亮度低於大標。

5Landing Page 的應用想像

示意：第二版放在首頁截圖上，約 190px 高。

放在畫面右側，讓芽朝主標的方向「聽」。桌機 160–200px，在內容欄外；手機只從右緣探出芽和半個身體。出場永遠是芽先探出來，停兩拍，身體才跟上。停留時呼吸、眨眼，臉朝游標滑動。兩隻相遇時芽尖輕碰，空中留下兩三道淡淡的鉛筆波紋，正好接到 logo 的三道波浪。離場時芽捲緊、躲進色塊後面，過一陣子從另一團色塊冒出來。

6未來系列化的潛力

世界觀是「被故事養大的小生物」，每隻都有自己接收故事的器官。差異來自三條軸：器官長在哪裡（決定剪影）、筆觸語言（排線、點描、長弧線）、身形與移動方式（跳步、滑行、用尾巴彈）。例如一隻低矮寬身、背上長苔絨，感動時會飄出幾顆絨種的慢郎中；或一隻用尾巴尖感覺地面震動、好奇時尾巴彎成問號的話多小傢伙。要防的退化是「同一顆圓身，頭上換一個器官」。

仿作檢查

第一版的芽在頭頂正中，剪影接近天線寶寶 Laa-Laa，第二版已移到肩上。「身上長植物」仍會讓人想到皮克敏；臉屬於「深色眼加腮紅」這一大類。

這一輪修了什麼

芽移到左肩，身體改成不對稱；半垂厚眼瞼定為招牌；日夜配色重做；芽拆成莖與捲兩段，方便動畫；SVG 修成合法 XML。

實作成本（單一角色）

約 10–13 人日

日夜各一組烘焙圖。芽的大幅舒展需要 2–3 張狀態圖或 Rive。第二隻約再 6–8 人日。

方向 B　蠟筆流體生命

漾漾 Plip

首頁那團薰衣草色塊托起的一滴杏桃色。它聽故事，聽到心裡去了，顏色就會暈開。

1角色概念

拍一滴水落進水面的高速攝影，會看到水面彈起一根細水柱，柱頂托著一顆水珠。漾漾就是那一刻活了過來，材料換成蠟筆的顏色。它的池子就是首頁 hero 的薰衣草色塊，不另外帶池子：首頁那些會相遇、長出頸部、融合的色塊，本身就是它的身體語言。

2外型設計

寬大於高的扁圓頭（約 1.35 : 1），一根像半個問號的細彎頸從色塊升起，另有一隻小手從水面濺起。水滴形眼睛、頭頂一個鉛筆畫的「旋」、小小張開的笑。頭是杏桃奶油 oklch(86.5% 0.058 64)，頸和手是首頁薰衣草 oklch(79% 0.05 293)，池子直接用網站的 --color-lavender。

3個性與情感

很認真聽你說話，會把脖子彎過來湊近你。形變本身就是表情：

  • 好奇：頸拉長彎成問號，頭歪向一邊
  • 開心：頭上下彈，漣漪變密
  • 害羞：頸縮短，頭沉下一半
  • 感動：頭沉到水面，臉頰的顏色往下流進池子
  • 陪伴：兩池相融成一池，兩顆頭靠在一起

4手繪風格

油性粉彩厚塗，紙面凹處留白，邊緣毛糙，沒有全身外框；只用網站同一支筆描頭的上緣、眼、口和旋。紙紋改成整隻角色共用的螢幕空間顆粒，脖子伸長時顆粒不會被拉長。

5Landing Page 的應用想像

示意：隱藏角色自帶的池子，頸根直接接進首頁的薰衣草色塊。

只住在色塊裡：桌機在右下的薰衣草色塊或主標右側，手機只從右緣伸頸進來。出場有三種：一顆水滴從 logo 波浪附近落下、彈起、升出；從右緣探頸；從色塊冒泡浮出。遇到另一隻時，做的就是首頁色塊原本會做的事：靠近、長出頸部、融成一池，額頭輕碰、漣漪交疊，分開時各帶走一點對方的顏色。離場時沉回色塊，色塊變回一團普通的漂移色塊。

6未來系列化的潛力

每個角色是「液體的一個瞬間」，從首頁某一團顏色裡長出來：倒吊著看人、愛沉思的長水珠「垂」；身體是一層薄膜、被碰到就破了再重組的「泡」；熱鬧停不下來的「濺」；像拉開的蜂蜜絲、把大家牽在一起的「絲」。黏稠度決定動作節奏，筆的種類決定質地（水性色鉛筆、粉筆、蠟筆刮畫）。

仿作檢查

最接近寶可夢的臭泥（從自己的一灘升起），已避開下垂手臂和大嘴。剪影仍可能被讀成氣球、棒棒糖或尼斯湖水怪。

這一輪修了什麼

頭改扁、頸變細並彎曲（第一版像燈泡或蘑菇）；頸和池改成首頁薰衣草；補上一支筆的線；夜紙打底內縮；紙紋移到螢幕空間。

實作成本（單一角色）

約 12–16 人日

要改首頁的色塊引擎（DriftingBlobs），讓頸和池由它畫出來。三案中最難估、風險最高。

方向 C　撕紙拼貼紙偶

摺摺 Tuck

一張被撕下來的色紙。它一直折著一個角，因為折角底下藏著幾行字；只有信任你的時候，才會掀開給你看。

1角色概念

人在書頁上折一個角，是在標記「這裡我還想再回來看」。摺摺把最在意的東西折起來保護著，願意掀開，代表它信任你。靈感來自一面有色、一面是白的色紙，手帳的撕紙拼貼，以及用雙腳釘固定關節的紙偶。刻意不做成「卡片長了臉」：身體是不規則的撕紙圓形，折角在構圖上更像一隻耳朵。

2外型設計

鼠尾草色紙 oklch(80% 0.044 140) 撕成的圓身，右上一個米白折角，左上一截紙舌，淡玫瑰紙片小手，粉紅風琴摺腿，腳是深一階的鼠尾草紙。眼睛用鉛筆直接畫在紙上，眉毛只在強烈情緒時出現。撕邊的白纖維就是外輪廓。

3個性與情感

有點害羞、很認真，會把重要的東西好好收著。臉很安靜，情緒交給紙的物理：

  • 好奇：折角掀開一半，底下的字露出來
  • 開心：風琴腿彈一下，原地小跳
  • 害羞：折角壓低、貼緊身體
  • 感動：瞇眼，這時眉毛才出現，手按胸口
  • 陪伴：坐下，把折角整個掀開，讓對方一起看

4手繪風格

真實的紙材感：撕邊白纖維、膠水貼上去的一點陰影、稀疏的紙纖維斑點、鉛筆畫的五官和折線。所有紙色都寫成可替換的變數，日後要配合網站的主題色換紙也容易。

5Landing Page 的應用想像

示意：放在下載區左側，約 150px 高。

桌機站在桃色色塊前或下載區左側，120–160px；手機約 80px。最獨特的出場是「紙活過來」：頁面上原本躺著一片紙，折角先掀起，風琴腿一節一節展開把它撐起來，抖一抖再看向訪客。打招呼像脫帽，把折角掀起再放下。離場時腿收起、躺平，變回一片普通的紙，慢慢滑到色塊後面。

6未來系列化的潛力

每個角色是「一張不一樣的紙，被不一樣地撕下、折過、保存下來」。紙材決定身體語言：描圖紙做的半透明、怕生，和別人重疊時會透出兩種顏色；厚水彩紙做的動作慢、很穩。撕法與折法決定剪影：收據撕成的長紙條、從活頁孔偷看的活頁紙。保存方式決定關係：用紙膠帶黏著、碰到誰就貼上去的；被釘書針釘在一起、永遠一起行動的雙人組；夾著乾燥花的老紙。

仿作檢查

「圓身加細腿加簡單的臉」是 Mr. Men 系列的角色模板；紙偶世界接近 Tearaway，但沒有它的信封造型。

這一輪修了什麼

牛皮紙改成鼠尾草色紙（第一版像餅乾或馬鈴薯）；白眼片改成鉛筆眼；像繃帶的描圖紙手改成玫瑰紙片；折角補上正面，字跡移到折角底下；手腳的拆件修正。

實作成本（單一角色）

約 7–10 人日

全是剛體紙片，日夜共用一組圖，第一期不需要任何動畫函式庫。第二隻約再 5–6 人日。

我的點評與推薦

兩位評審各自獨立看過三案，推薦都是 A。以下是我自己的判斷；最後的選擇在你。

A　最好的「角色」

三案中最像一個有個性、能讓人投射情感的生命。它最有價值的是「芽舒展的程度，就是被觸動的程度」這條情緒刻度：首頁動畫和貼圖用的是同一個機制。第二版把芽移到肩上，換來原創的剪影和「側耳在聽」的姿態，代價是少了第一版正面對稱、一眼可愛的感覺。臉還在大類慣例裡，正式定稿時值得請插畫師再重描一次。

B　最好的「世界」

把首頁本來就有的色塊變成生命，是三案中最「只有共振才有」的想法，兩池相融就是共振本身。但作為一個獨立角色（貼圖、App 裡、社群上），它的靜態辨識度最弱，造價也最高。我建議把它降成所有角色共用的舞台機制，而不是讓主角本身是液體。

C　最好的「製作」

材質最原創，離通用 AI 吉祥物最遠；深淺色最穩、成本最低、系列題材最豐富，角色之間的關係也最容易長出來。第二版的鼠尾草色讓它輕了很多。不過它離你優先指定的色鉛筆、蠟筆媒材最遠，情緒也偏手作的可愛，溫度不及 A。

還有一個意外的發現：三位子代理彼此沒看過對方的稿，卻都讓角色以「接收故事」為核心動作。A 在聽，B 被打動、顏色暈開，C 把故事收好、信任時才分享。這三件事剛好是共振發生的三個步驟，可以當成整個角色世界的共同起點。

推薦：以 A 聽芽作為第一個角色

再借 B 的「色塊相融」當舞台、C 的撕紙白邊與紙偶拆件做法來補 A 的弱點（見下方混合一、二）。家族規則則是「每個角色身上都有一個會被故事打開的部位」，讓第二階段的角色在身形和材質上都能完全不同。

如果想混合不同提案的優點

以下可以單選，也可以疊用。

  1. 混合一・推薦

    A 的角色，站在 B 的舞台上

    角色本身維持剛體，便宜又穩。它腳下的影子改成首頁色塊引擎多畫的一小團顏色；兩隻靠近時，兩團影子長出頸部、混色、融合，芽尖相碰的瞬間漾出 logo 的三道波線。B 的「感動時顏色暈開」也移植給 A：腮紅往下暈成一小片淡彩。幾乎不增加成本，「共振」由整個場景演出來。

  2. 混合二・推薦

    A 的造型，畫在 C 的一片紙上

    把聽芽的色鉛筆畫放在一片撕下來的紙上，外緣一圈白纖維撕邊。夜紙上撕邊本身就是輪廓，解決 A 在深色模式偏平的問題，日夜也可以共用一組烘焙圖，成本往 C 靠近；身體多了一層只屬於共振的材質辨識。

  3. 混合三

    三案收斂成同一個世界：住在紙頁上的生命

    鉛筆畫出的一根芽、一滴顏料、書頁的一個折角，都是紙上會留下的痕跡，彼此天然是親戚。A 當第一隻；第二階段把 C 的「一張紙」和 B 的「一滴顏料」重新設計成第二、第三隻。臉和關鍵輪廓一律用 A 的鉛筆語言，材質只表現在身體上；共用「會被故事打開的部位」這條情緒刻度：芽舒展、折角掀開、漣漪漾開。

  4. 混合四

    C 的系列化軸，借給 A

    世界觀維持「被故事養大的小生物」，每一隻換一種「紙加筆」的組合：聽芽是色鉛筆在畫紙上，下一隻可以是蠟筆在牛皮紙上，再一隻是水彩在厚紙上。剪影由器官決定，質感由紙和筆決定，兩條軸疊起來就不會淪為換色。
