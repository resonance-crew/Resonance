# 方向 C｜摺摺 Tuck（撕紙拼貼紙偶）

**一句話定位**：一片被撕下來、還折著一角的紙。它一直留著那個角，因為背面有人寫過字。

- 角色本體：`character.svg`（800×800，透明背景，可拆件）
- 概念圖：`concept.svg` / `concept.png`（1600×1000）
- 剪影草案：`explore.svg` / `explore.png`
- 產生器：`gen/`（`lib.mjs` 撕邊幾何、`tuck.mjs` 角色、`concept.mjs` 概念圖；改參數後重新執行就能重畫）

---

## 1 角色概念

**核心想法**：摺摺是一片被撕下來的牛皮紙。右上角往前折了一個「書角」（dog-ear），折角背面露出另一面的米白紙，上面隱約有幾行別人的鉛筆字。它不知道自己原本是哪張紙，只知道那個角不能攤平，因為那是它最想留著的地方。

**靈感來源**：
- 人在書頁上折一個角，是在標記「這裡我還想再回來看一次」。這個動作很日常，幾乎每個人都做過。
- 手帳、剪貼簿裡的撕紙拼貼：撕紙時露出的白色纖維邊、膠水貼上去後的一點點陰影。
- 用雙腳釘或線固定關節的紙偶，還有小朋友勞作裡的風琴摺紙條。

**和共振理念的關係**（只是呼應，不是硬扣的象徵）：
- 每個角色都是從不同地方撕下來的紙，材質、撕法、折痕都不一樣。這就是「每個人都不一樣」。
- 折角是它最寶貝的地方，背面藏著一段字。它願意把折角掀開給你看，代表它信任你。故事要掀開才看得到，這和「透過故事彼此理解」的方向一致，但畫面上只是一隻紙做的小生物在掀自己的角。
- 我們刻意不讓它成為「一張卡片長了臉」：身體是不規則撕下來的圓形紙片，不是矩形，也沒有卡片框；折角在構圖上的角色更像一隻耳朵。

**為什麼選這個剪影**（`explore.png` 裡有三個草案）：
- A「摺角」：折起的一角加上風琴摺腿。
- B「捲捲」：頂端撕起，捲成浪頭。
- C「流蘇」：撕成一條條的裙襬當腳。

最後選 A。折角是只有紙才做得出來的特徵，縮到很小時仍然是「深色圓身體配一塊淺色三角」，一眼就認得；它還能當成耳朵、帽簷或眉毛來動。B 的捲邊在平面拼貼裡看起來像一頂帽子，需要立體陰影才讀得懂。C 太像水母或幽靈。

**定稿前試過但拿掉的東西**：
- 縫補過的小撕裂：看起來像額頭上的傷口。
- 綠色補丁：在臉下方看起來像一張大嘴。
- 細長的紙鬚：看起來像水果蒂頭。
- 桃色身體：像皮膚。

最後回到牛皮紙，再加一道橫過肚子的舊摺痕，避免它被看成餅乾或馬鈴薯。

## 2 外型設計

**輪廓**：一片略圓、邊緣不規則的撕紙，寬高比約 1 : 1.05。
- 右上角沿 45° 的折線往前折下。
- 左上角後面露出一小塊撕剩的紙片（獨立部件），像一隻小耳朵。
- 下半身有一道舊摺痕：一條亮線，下方稍微暗一點。
- 剪影由三個元素組成：右上被折線切平的斜角、左上的小紙片、兩條鋸齒狀的腿。

**比例**：
- 身體約 310×330，腿長約 110，大約是身體的三分之一。
- 手很短，只有身體寬的 1/5，屬於小短手。
- 臉放在上半部，雙眼大約在身高 45% 的位置。

**五官**：
- 眼睛：兩片撕下來的小白紙，左大右小，有一點不對稱。紙上用鉛筆畫深色瞳孔，留下一大一小兩個沒塗到的紙白當反光。
- 上眼線和眉毛：鉛筆短弧。
- 嘴：一條鉛筆小弧。
- 腮紅：玫瑰色蠟筆。
- 閉眼時白紙片收掉，直接在牛皮紙上畫 ∩ 形弧線。

**材質**：
- 身體：牛皮紙（纖維斑點、輕微紋理）。
- 折角背面：米白書寫紙，上面有鉛筆字跡。這些字跡只是一圈圈的筆畫，不是真的字。
- 手：描圖紙，半透明，帶霧面纖維，能透出後面的身體。
- 腿：玫瑰色色紙，摺成風琴狀，正反兩面深淺交替。
- 關節：用赤陶色線縫兩針固定。

**主要色彩**：

| 部位 | 色值 |
| --- | --- |
| 牛皮紙身體 | `oklch(76% 0.05 64)` |
| 折角背面 | `oklch(94% 0.025 80)`，鉛筆字跡不透明度 0.3 |
| 描圖紙手 | `oklch(91% 0.026 292)`，70–80% 不透明 |
| 風琴腿（亮面／暗面） | `oklch(82% 0.05 22)` / `oklch(71% 0.06 20)` |
| 腳 | `oklch(62% 0.045 58)` |
| 眼白紙片 | `oklch(97.5% 0.008 85)` |
| 鉛筆 | `oklch(29% 0.018 60)` |
| 縫線（接近品牌赤陶色） | `oklch(60% 0.12 38)` |
| 腮紅 | `oklch(70% 0.1 24)` |
| 撕邊白纖維 | `oklch(97.5% 0.012 85)` |

**最具辨識度的特徵**：
- 寫著字的折角：深色圓紙上的一塊淺色三角。
- 兩條風琴摺腿。
- 縮到 48px、甚至 32px 時，這兩點仍然看得出來（見概念圖 a）。

## 3 個性與情感

**第一印象**：有點害羞、很認真，是會把東西好好收著的那種小傢伙。不吵鬧，但會一直在旁邊。

摺摺的情緒不只靠臉，也靠「紙的物理」來表現：折角掀起或放下、腿伸長或壓扁、小紙片晃動。

| 情緒 | 表現 |
| --- | --- |
| 好奇 | 折角整個立起來，像耳朵豎起；小紙片往前翹；身體斜著探出去；瞳孔偏向一側；嘴變成小小的 o。見概念圖「好奇探頭」。 |
| 開心 | 風琴腿彈一下，原地小跳；落地時身體壓扁再回彈；折角跟著拍動；短手舉高揮。 |
| 害羞 | 把折角再往下折，蓋到眉毛；轉身讓寫字的那面朝向自己；腿縮短；腮紅加深。 |
| 感動 | 眼睛瞇成 ∩；兩手按在胸口；腿軟掉一點；眼角掛一滴淚；小紙片垂下來。見概念圖「被感動」。 |
| 陪伴 | 腿完全收起，身體直接坐在地上；把折角輕輕靠在對方身上，或掀開折角讓對方一起看背面的字。 |

## 4 手繪風格

**畫面語言**：
- 撕邊不規則。
- 撕開處露出一圈白色纖維；在夜紙上，這圈白邊也是角色的外輪廓，所以深色模式下仍然清楚。
- 紙片之間有一點點膠水陰影，看起來像輕輕貼上去的。
- 細節都用鉛筆直接畫在紙上，筆觸會在紙的凹凸處斷掉。
- 腮紅是蠟筆質感，有空隙。
- 描圖紙看得到後面的身體。
- 不畫黑色外框，也沒有漸層高光。

**SVG 技法**（所有 id 都加上 `c-` 前綴）：
- `c-paper`：主要的紙材濾鏡。
  - `feTurbulence`（0.11）接 `feDisplacementMap`（3.2），讓邊緣變毛糙。
  - `feMorphology dilate` 加上第二次高頻位移，做出白纖維邊。
  - `feGaussianBlur` 加 `feOffset`，做膠水陰影。
  - 用兩組 `fractalNoise` 經過 `feColorMatrix` 閾值化，再以 `operator="in"` 疊在形狀內，分別做斑點和紋理。
- `c-thin`：描圖紙和眼白用。陰影較淡，加一層霧面纖維。
- `c-graphite`：鉛筆線。先輕微位移，再用反相噪點當遮罩（`feComposite in`），讓線在紙紋凹處斷開。
- `c-crayon`：蠟筆腮紅與地面陰影。位移加上有空隙的遮罩。
- 幾何：用自寫的 seeded 產生器（mulberry32）。
  - 外形：Catmull-Rom 曲線取樣後，沿法線做隨機漫步，偶爾加一個小缺口，就是撕紙的節奏。
  - 鉛筆線：同一條線偏移 0.5–0.6px 重描 2–3 次。
  - 字跡：一圈圈的連筆迴圈，沒有可辨讀的字。
  - 折角：數學上就是把角落那段外形對折線做鏡射，所以「掀開／折回」可以直接做成動畫。

## 5 Landing Page 的應用想像

**位置**：
- 桌機：站在 hero 標題區下方左側的「地面」，大約 120–160px 高，位在桃色漂移色塊的前面。
- 手機：放在下載按鈕下方，約 80px 高，一次只出現一隻。
- 絕不遮住 H1 和 CTA。
- 色塊在它後面慢慢漂，靠近時它會轉頭看。

**出場：紙活過來**
1. 頁面上原本只有一片平躺的撕紙。
2. 折角先掀起來。
3. 風琴腿從底下一節一節展開，把它撐起來。
4. 它抖一抖身體，看向訪客。

這是只有紙才做得到的出場方式。替代版本：從頁面邊緣或色塊後面探頭（見概念圖 c）。

**停留**：
- 呼吸：身體從底部做 1 → 0.985 的 scaleY。
- 每 3–6 秒眨一次眼。
- 瞳孔在 ±5px 內跟著游標，臉部群組跟著位移 4px。
- 小紙片會延遲跟隨身體擺動。
- 游標快速經過時，折角像被風吹到一樣掀一下。

**看向訪客**：游標停住約 1 秒後，它整個身體轉過來，眉毛抬一下。

**遇到另一個角色**：
- 折角先立起來，表示注意到了。
- 用風琴腿一跳一跳地走過去。
- 打招呼時把折角掀起再放下，像在脫帽。
- 陪伴時兩隻一起坐下；摺摺把折角掀開，讓對方湊過來看背面的字。
- 如果另一隻是描圖紙材質，兩者重疊時會透出混色。

**離場與再出現**：
- 離場：跳出畫面；或腿收起、躺平，變回一片普通的紙，慢慢滑到色塊後面。
- 再出現：之後在頁面別處，一片紙又掀起角站起來。

**其他**：
- `prefers-reduced-motion` 時只顯示靜態主姿勢。
- 和既有漂移色塊一樣，離開畫面就暫停（IntersectionObserver）。

## 6 未來系列化的潛力

同一個世界觀：**每個角色都是一張不一樣的紙，也是被不一樣地撕下、折過、保存下來的**。

共同的家族特徵：
- 撕邊的白纖維。
- 眼睛是撕下來的白紙片加鉛筆瞳孔。
- 關節用赤陶色線縫。
- 身上某處藏著一點字跡。

除此之外，外型與個性都可以差很多。以下只是舉例，沒有畫出來：

1. **紙材決定身體語言**
   - 描圖紙做的角色：半透明、怕生。和別人重疊時會「透」出兩種顏色，這本身就是一種互動。
   - 厚水彩紙做的角色：動作慢、很穩，哭了紙會皺，但不會破。
2. **撕法與折法決定剪影**
   - 收據撕成的長紙條：細長，緊張時會捲成螺旋，很愛說話。
   - 被折過太多次的紙：身上都是銳利的摺面，個性有點焦慮，但很會變形。
   - 活頁紙：身上有打洞孔，會從孔裡偷看。
3. **被保存的方式決定個性與關係**
   - 用紙膠帶黏著的角色：很黏人，碰到誰就貼上去。
   - 被釘書針釘在一起的兩片紙：一組雙人角色，永遠一起行動。
   - 夾著乾燥花的紙：年紀比較大，溫柔又安靜。

## 參考與避免仿作

**參考的只是特徵，不是作品**：
- 民間紙偶用雙腳釘或縫線做關節的做法。
- 手帳拼貼的撕紙白邊與膠痕。
- 日常的書頁折角。
- 勞作的風琴摺紙條。

沒有參考任何特定角色的長相。

**可能撞到的既有角色，以及我們避開了什麼**：

| 既有角色 | 可能相像的地方 | 我們的處理 |
| --- | --- | --- |
| Tearaway 的 Iota | 信封頭、三角封口、郵票 | 身體是不規則的圓形撕紙，不是信封矩形；沒有郵票；折角在側上方，不在頂部中央。 |
| Paper Mario | 平面紙片人 | 沒有黑色粗外框，沒有平塗卡通人形，用拼貼材質。 |
| Snipperclips | 幾何紙片互相剪 | 沒有幾何外形。 |
| Yoshi's Crafted World | 紙箱、立體勞作 | 不是立體紙箱造型。 |
| LINE FRIENDS 的 Brown | 棕色、圓臉、簡單五官 | 沒有熊耳、沒有口鼻區塊，眼睛是白紙片，識別重點在折角。 |
| 栗子／橡實吉祥物 | 棕色圓身體、頂端一個尖 | 小紙片放在左上、做成獨立的平頭撕片，不在頂端中央。 |
| Humpty Dumpty | 細腿上的蛋 | 身體不是蛋形，腿是風琴摺紙。 |
| 馬鈴薯／餅乾感 | 棕色圓形加斑點 | 加了舊摺痕和背面字跡，讓它一看就是紙。 |
| 晃動眼（googly eyes） | 白色圓眼加黑瞳 | 眼睛是撕邊紙片，加上鉛筆眼線，瞳孔不會晃。 |

| `c-shadow` | 402,690 | 跳起時 scaleX 0.7、變淡。 |

**正式製作時建議**：
- 把腳從 `c-leg-*` 拆成獨立部件並反向縮放，壓縮腿時腳才不會變形。
- 折角補一個「正面」path。

### 實作成本粗估（插畫 1 人 + 前端 1 人）

| 工作 | 內容 | 人日 |
| --- | --- | --- |
| 插畫完稿 | 主角定稿、折角正反兩面、3 種嘴形、閉眼、4–5 個表情差分、小尺寸簡化版（去掉斑點） | 2–3 |
| 拆件與綁定 | 命名、pivot、雙面折角、分層匯出 | 1 |
| 四段動態 | 出場（躺平→掀角→腿展開）、停留（呼吸、眨眼、看游標、小紙片晃）、互動（掀角打招呼、靠近、坐下陪伴）、離場（跳出或躺平變回紙片） | 3–5 |
| 前端整合 | 深色模式、行動版、reduced-motion、離開畫面暫停、效能調校 | 1.5–2 |
| **合計** | | **約 7.5–11** |

**前端建議**：
- 第一階段：每個部件把紙紋「烤」成 2x 的 WebP/AVIF 圖層（每片約 10–30KB），組成一個絕對定位的 SVG 或 DOM 紙偶。動畫只動 transform 和 opacity，用 CSS 或 WAAPI，不需要額外函式庫，和 Next.js 很好整合。
- 之後如果多角色的互動狀態變多：改用 **Rive**。骨架加 state machine 很適合紙偶；runtime 加檔案大約 100–200KB。
- Lottie 也能做，但放點陣圖的檔案偏大，互動仍要另外寫程式，比較不推薦。

**效能風險**：
- **不要在動畫中保留 `feTurbulence` 和 `feDisplacementMap` 濾鏡**。每一幀、每個元素都會重算，Safari 尤其慢。材質要先烤成圖。
- 折角翻面需要兩個面，scale 過 0 時切換。
- 手機上同時最多一隻角色，離開畫面就停止動畫。

## 自評

**最強的地方**
1. **材質一看就是真的紙**：撕邊白纖維、背面的字跡、透出身體的描圖紙、縫線。離「通用 AI 吉祥物」或光滑 3D 公仔很遠。折角是只有紙才有的特徵，同時是辨識點（48px 仍然看得出來），也是表情裝置（耳朵、帽簷、眉毛）。
2. **天生適合拆件動畫**：紙偶本來就是一片片接起來的。風琴腿免費提供伸縮與彈跳，「躺平的紙站起來」和「變回一片紙」是很獨特的進出場。系列化的差異軸（紙材、撕法、保存方式）也很自然。

**最弱的地方**
1. **臉和整體圓形身體是最普通的部分**。第一眼仍可能被看成「棕色圓餅加卡通眼」，要注意到折角才會想到紙。眼睛的造型還可以再設計得更專屬；短手偶爾會被看成小襪子或繃帶。
2. **「寫著字的折角」很接近業主擔心的「一張紙長了臉」**。我們用不規則撕形和生物化的四肢把它拉回「生物」那一邊，但這條界線見仁見智，需要業主判斷。另外，小尺寸時紙紋斑點會顯得髒，正式製作需要一個簡化版。
