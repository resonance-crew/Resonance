**一句話定位**：一張被撕下來的色紙。它一直折著一個角，因為折角底下藏著幾行字。

## 1 角色概念

**核心想法**：摺摺是一張被撕下來的鼠尾草綠色紙。色紙正面有顏色、背面是白的，所以它右上角往前折下的那個「書角」（dog-ear），露出來的是米白的背面。折角底下、貼著身體的那一塊，有幾行別人用鉛筆寫的字。它不知道自己原本是哪張紙，只知道那個角要一直折著，因為底下的字是它最想留著的東西。只有在信任你的時候，它才會把角掀開給你看。

**靈感來源**：
- 人在書頁上折一個角，是在標記「這裡我還想再回來看一次」。這個動作很日常，幾乎每個人都做過。
- 小時候的色紙：一面有顏色、一面是白的，一折就看得到兩面。
- 手帳、剪貼簿裡的撕紙拼貼：撕紙時露出的白色纖維邊、膠水貼上去後的一點點陰影。
- 用雙腳釘或膠固定關節的紙偶，還有勞作裡的風琴摺紙條。

**和共振理念的關係**（只是呼應，不是硬扣的象徵）：
- 每個角色都是從不同地方撕下來的紙，材質、撕法、折痕都不一樣。這就是「每個人都不一樣」。
- 它把最在意的東西折起來保護著，願意掀開給你看，代表它信任你。故事要掀開才看得到，這和「透過故事彼此理解」的方向一致；但畫面上只是一隻紙做的小生物在掀自己的角。
- 我們刻意不讓它成為「一張卡片長了臉」：身體是不規則撕下來的圓形紙片，不是矩形，也沒有卡片框；折角在構圖上更像一隻耳朵。

**為什麼選這個剪影**（`explore.png` 裡有三個草案）：
- A「摺角」：折起的一角加上風琴摺腿。
- B「捲捲」：頂端撕起，捲成浪頭。
- C「流蘇」：撕成一條條的裙襬當腳。

選 A。折角是只有紙才做得出來的特徵，縮到很小時仍然是「色紙圓身體配一塊淺色三角」，一眼就認得；它還能當耳朵、帽簷或眉毛來動。B 的捲邊在平面拼貼裡像一頂帽子；C 太像水母或幽靈。

**試過但拿掉的東西**：
- 縫補過的小撕裂：像額頭上的傷口。
- 綠色補丁：在臉下方像一張大嘴。
- 細長的紙鬚：像水果蒂頭。
- 桃色身體：像皮膚。
- 牛皮紙身體（第一版）：像餅乾、馬鈴薯、牛皮紙袋，在首頁色塊旁偏重。
- 麥黃身體（本輪比較過，見 `work/colors.png`）：同樣像馬鈴薯或餅乾。
- 直立的小紙片（第一版的形狀）：身體換成綠色後，直立的小紙片像蘋果梗，所以改成往外斜的短紙舌。

## 2 外型設計

**輪廓**：一片略圓、邊緣不規則的撕紙，寬高比約 1 : 1.05。
- 右上角沿 45° 的折線往前折下，折線是一道清楚的折邊。
- 左上角有一小片往外斜出的撕剩紙舌（獨立部件），像一撮翹起來的毛或一隻小耳朵。
- 下半身有一道舊摺痕：一條亮線，下方稍微暗一點。
- 剪影由三個元素組成：右上被折線切平的斜角、左上斜出的小紙舌、兩條鋸齒狀的腿。

**比例**：
- 身體約 310×330，腿長約 110，大約是身體的三分之一。
- 手很短，約身體寬的 1/5。
- 臉放在上半部，雙眼大約在身高 45% 的位置，兩眼間距約身體寬的 0.3，比第一版靠近一點。

**五官**（直接畫在紙上，沒有另外貼的眼睛紙片）：
- 眼睛：鉛筆塗滿的直橢圓，左大右小，有一點不對稱。每隻眼睛左上角留一小點沒塗到的紙白當反光。
- 眉毛：平常沒有。只有強烈情緒（驚訝、被感動、擔心）時才用細鉛筆畫上去。部件一直在，平常透明度是 0。
- 嘴：一條鉛筆小弧，可換成 o 形或軟弧。
- 腮紅：玫瑰色蠟筆。
- 閉眼：橢圓換成一道 ∩ 形鉛筆弧。

**材質**：
- 身體：鼠尾草綠色紙，有淡淡的纖維紋理和少量纖維斑點（斑點密度比第一版低很多）。
- 折角背面：色紙的白色背面，米白，沒有字。
- 折角底下：身體上有幾行鉛筆字跡，折著時被蓋住，掀開才看得到。字跡只是一圈圈的連筆，不是真的字。
- 手：兩小片撕下來的淡玫瑰色紙，形狀像撕下的花瓣，邊緣有白纖維，上面沒有任何線條。直接用膠貼在肩膀上，沒有縫線。
- 腿：玫瑰色色紙摺成風琴狀，正反兩面深淺交替。
- 腳：同一張綠色紙剩下的邊角，顏色深一點。

**主要色彩**（每個紙色都寫成 CSS 自訂屬性，括號內是變數名稱，值是日間預設）：

| 部位 | 色值 |
| --- | --- |
| 鼠尾草色紙身體（`--c-body`） | `oklch(80% 0.044 140)` |
| 折角背面（`--c-flap-back`） | `oklch(94.5% 0.02 86)` |
| 手（`--c-hand`） | `oklch(89% 0.032 32)` |
| 風琴腿亮面／暗面（`--c-leg` / `--c-leg-fold`） | `oklch(82% 0.05 22)` / `oklch(71% 0.06 20)` |
| 腳（`--c-foot`） | `oklch(68% 0.045 142)` |
| 鉛筆（`--c-ink`），字跡不透明度 0.6 | `oklch(29% 0.018 60)` |
| 眼睛反光（`--c-glint`） | `oklch(97% 0.01 85)` |
| 腮紅（`--c-blush`） | `oklch(74% 0.1 16)` |
| 撕邊白纖維（濾鏡內，固定） | `oklch(97.5% 0.012 85)` |

身體的色相 140 就是網站卡片的鼠尾草色系，明度落在 80%，比首頁的鼠尾草色塊深一階。站在桃色色塊前時兩者互補，畫面很輕（見 `work/landing-day.png`）。

**最具辨識度的特徵**：
- 色紙圓身體上的一塊白色三角折角，加上一道折邊。
- 兩條風琴摺腿。
- 縮到 48px、甚至 32px 時，這兩點仍然看得出來（見概念圖 a）。

## 3 個性與情感

**第一印象**：有點害羞、很認真，會把重要的東西好好收著。不吵鬧，但會一直在旁邊。

摺摺的臉很安靜，情緒主要交給「紙的物理」：折角掀起或壓低、腿伸長或壓扁、小紙舌晃動。眉毛只在情緒很強的時候才出現，所以一出現就特別有份量。

| 情緒 | 表現 |
| --- | --- |
| 好奇 | 折角掀開一半，底下的字露出來；小紙舌往前翹；身體斜著探出去；眼睛偏向一側；嘴變成小小的 o。見概念圖「好奇探頭」。 |
| 開心 | 風琴腿彈一下，原地小跳；落地時身體壓扁再回彈；折角跟著拍動；短手舉高揮。 |
| 害羞 | 折角壓得更低、貼緊身體；身體側轉；腿縮短；腮紅加深。 |
| 感動 | 眼睛瞇成 ∩；這時眉毛才出現，眉尾往下；兩手按在胸口；腿軟掉一點；眼角掛一滴淚；小紙舌垂下來。見概念圖「被感動」。 |
| 陪伴 | 腿完全收起，身體直接坐在地上；把折角整個掀開，讓對方一起看底下的字。 |

## 4 手繪風格

**畫面語言**：
- 撕邊不規則。
- 撕開處露出一圈白色纖維；在夜紙上，這圈白邊也是角色的外輪廓，所以深色模式下不用另外調色。
- 紙片之間有一點點膠水陰影，看起來像輕輕貼上去的。
- 五官、字跡、陰影排線都用鉛筆直接畫在紙上，筆觸會在紙的凹凸處斷掉。
- 腮紅是蠟筆質感，有空隙。
- 不畫黑色外框，也沒有漸層高光。唯一的「線」是折角的那道折邊，因為真的折過的紙會有一道折痕。

**SVG 技法**（所有 id 都加上 `c-` 前綴）：
- `c-paper`：主要的紙材濾鏡。
  - `feTurbulence`（0.11）接 `feDisplacementMap`（3.2），讓邊緣變毛糙。
  - `feMorphology dilate` 加上第二次高頻位移，做出白纖維邊。
  - `feGaussianBlur` 加 `feOffset`，做膠水陰影。
  - 兩組 `fractalNoise` 經過 `feColorMatrix` 閾值化，再以 `operator="in"` 疊在形狀內，分別做纖維斑點和紋理。斑點的閾值從第一版的 0.60 提高到約 0.72，數量少很多，小尺寸不再顯髒。
- `c-thin`：手等小紙片用。白纖維邊較窄、陰影較淡、沒有斑點。
- `c-graphite`：鉛筆線。先輕微位移，再用反相噪點當遮罩（`feComposite in`），讓線在紙紋凹處斷開。
- `c-graphite-fill`：鉛筆塗滿的形狀（眼睛、o 形嘴），比線密，邊緣仍有顆粒。
- `c-crayon`：蠟筆腮紅、折角下的陰影和地面陰影。位移加上有空隙的遮罩。
- 幾何：用自寫的 seeded 產生器（mulberry32）。
  - 外形：Catmull-Rom 曲線取樣後，沿法線做隨機漫步，偶爾加一個小缺口，就是撕紙的節奏。
  - 鉛筆線：同一條線偏移 0.5px 左右重描 2–3 次。
  - 字跡：一圈圈的連筆迴圈，沒有可辨讀的字，用折角本身的外形裁切，所以只會出現在折角蓋住的那一塊。
  - 折角：數學上就是把角落那段外形對折線做鏡射，所以「掀開／折回」可以直接做成動畫。
- 顏色：紙色都寫成 `style="fill: var(--c-body, oklch(…))"`。之後要配 sage／lavender／yellow 主題色，或夜間想把紙調暗一點，只要覆寫變數，不必回產生器重出。

## 5 Landing Page 的應用想像

**位置**：
- 桌機：站在 hero 左側桃色漂移色塊的前方或下緣，大約 120–160px 高。鼠尾草綠和桃色互補，角色在色塊旁顯得很輕（見 `work/landing-day.png`）。
- 手機：放在「成為一群最早說故事的人」那一列下方，約 80px 高；或從右緣斜身探頭。一次只出現一隻。
- 絕不遮住 H1 和 CTA。
- 色塊在它後面慢慢漂，靠近時它會轉頭看。

**出場：紙活過來**
1. 頁面上原本只有一片平躺的撕紙。
2. 折角先掀起來。
3. 風琴腿從底下一節一節展開，把它撐起來。
4. 它抖一抖身體，看向訪客。

這是只有紙才做得到的出場方式。替代版本：從頁面邊緣或色塊後面探頭（見概念圖 c）。

**停留**：
- 呼吸：身體從底部做 1 → 0.985 的 scaleY，雙手跟著身體一起動。
- 每 3–6 秒眨一次眼。
- 眼睛在 ±3px 內跟著游標，臉部群組再跟著位移 ±6px。
- 小紙舌延遲跟隨身體擺動。
- 游標快速經過時，折角像被風吹到一樣掀一下，底下的字閃一下又蓋回去。

**看向訪客**：游標停住約 1 秒後，它整個身體轉過來，折角輕輕抬一下（它的「挑眉」）。

**遇到另一個角色**：
- 折角先立起來，表示注意到了。
- 用風琴腿一跳一跳地走過去。
- 打招呼時把折角掀起再放下，像在脫帽。
- 陪伴時兩隻一起坐下；摺摺把折角整個掀開，讓對方湊過來看底下的字。

**離場與再出現**：
- 離場：跳出畫面；或腿收起、躺平，變回一片普通的紙，慢慢滑到色塊後面。
- 再出現：之後在頁面別處，一片紙又掀起角站起來。

**其他**：
- `prefers-reduced-motion` 時只顯示靜態主姿勢。
- 和既有漂移色塊一樣，離開畫面就暫停（IntersectionObserver）。

## 6 未來系列化的潛力

同一個世界觀：**每個角色都是一張不一樣的紙，被不一樣地撕下、折過、保存下來**。

共同的家族特徵（只有這幾樣，其他都可以不同）：
- 撕邊的白纖維。
- 五官用鉛筆直接畫在紙上。
- 身上某處有一道折痕或一個折起來的地方。
- 某個被折起、夾住或捲起來的地方，藏著一點字跡。

以下只是舉例，沒有畫出來：

1. **紙材決定身體語言**
   - 描圖紙做的角色：半透明、怕生。和別人重疊時會「透」出兩種顏色，這本身就是一種互動。（第一版摺摺的描圖紙手移到這裡，給一個真正屬於它的角色。）
   - 厚水彩紙做的角色：動作慢、很穩，哭了紙會皺，但不會破。
2. **撕法與折法決定剪影**
   - 收據撕成的長紙條：細長，緊張時會捲成螺旋，很愛說話。
   - 被折過太多次的紙：身上都是銳利的摺面，個性有點焦慮，但很會變形。
   - 活頁紙：身上有打洞孔，會從孔裡偷看。
3. **被保存的方式決定個性與關係**
   - 用紙膠帶黏著的角色：很黏人，碰到誰就貼上去。
   - 被釘書針釘在一起的兩片紙：一組雙人角色，永遠一起行動。
   - 夾著乾燥花的紙：年紀比較大，溫柔又安靜。

## 參考與避免仿作

**參考的只是特徵，不是作品**：
- 民間紙偶用雙腳釘或膠做關節的做法。
- 手帳拼貼的撕紙白邊與膠痕。
- 一面有色、一面是白的色紙。
- 日常的書頁折角。
- 勞作的風琴摺紙條。

沒有參考任何特定角色的長相。

**可能撞到的既有角色，以及我們避開了什麼**：

| 既有角色 | 可能相像的地方 | 我們的處理 |
| --- | --- | --- |
| Mr. Men 先生小姐系列 | 單一圓形身體、細長腿、小腳、簡單五官 | 拿掉白紙片眼和常駐粗眉，臉只剩畫在紙上的小鉛筆眼；剪影靠折角斜切、斜出的小紙舌和風琴腿，不是光滑的圓。圓身配細腿的結構沒有改（理由見修訂紀錄），這是殘留的相似處。 |
| Mr. Bump（繃帶先生） | 白色、纏著線的手 | 手改成淡玫瑰色撕紙片，沒有任何橫線或縫線。 |
| Tearaway 的 Iota | 信封頭、三角封口、郵票 | 身體是不規則的圓形撕紙，不是信封矩形；沒有郵票；折角在側上方，不在頂部中央。 |
| Paper Mario | 平面紙片人 | 沒有黑色粗外框，沒有平塗卡通人形，用拼貼材質。 |
| Snipperclips | 幾何紙片互相剪 | 沒有幾何外形。 |
| Yoshi's Crafted World | 紙箱、立體勞作 | 不是立體紙箱造型。 |
| LINE FRIENDS 的 Brown | 棕色、圓臉、簡單五官 | 已不是棕色；沒有熊耳、沒有口鼻區塊。 |
| 栗子／橡實、蘋果 | 圓身體、頂端一根梗 | 小紙片改成從左上邊緣斜出的短紙舌，寬、短、不直立，讀起來不像梗。 |
| 青豆、萊姆、仙人掌 | 綠色圓形 | 主色選低彩度的灰綠，紋理是紙的纖維而不是果皮；白色折角和風琴腿是水果和植物都沒有的。小紙片試過有缺口的版本，像仙人掌的小掌，已改掉。 |
| 晃動眼（googly eyes） | 白色圓眼加黑瞳 | 已沒有白眼片，眼睛直接畫在紙上。 |
| Humpty Dumpty | 細腿上的蛋 | 身體不是蛋形，腿是風琴摺紙。 |

## 動態拆件表

所有 pivot 都寫在 `character.svg` 的註解裡，座標是 `c-tuck` 群組內的本地座標。整體縮放寫在 `c-tuck` 的 transform。

**階層**（腿和腳在身體外面；手、折角、臉都在身體裡面）：


### 實作成本粗估（插畫 1 人 + 前端 1 人）

| 工作 | 內容 | 人日 |

| 前端整合 | 深色模式、行動版、reduced-motion、離開畫面暫停、效能調校 | 1–2 |
| **合計** | | **約 7–10** |

第二隻角色因為拆件和互動邏輯可以共用，大約再 5–6 天。

**前端建議**：
- 第一階段：每個部件把紙紋「烤」成 2x 的 WebP（含白纖維邊與膠水陰影），組成絕對定位的 DOM 或 SVG 紙偶，日夜共用同一組圖；全隻約 60–120KB。動畫只動 transform 和 opacity，用 CSS 或 WAAPI，不需要額外函式庫，和 Next.js 很好整合。折角兩面在 scaleY 過 0 時切換顯示。
- 要跟主題色換色時：SVG 版本直接覆寫 CSS 變數；烤圖版本可以每個主題各烤一組，或把紙紋烤成灰階、用 CSS 混色疊上主色。
- 之後如果多角色的互動狀態變多：改用 **Rive**。骨架加 state machine 很適合紙偶；runtime 加檔案大約 100–200KB。
- Lottie 也能做，但放點陣圖的檔案偏大，互動仍要另外寫程式，比較不推薦。

**效能風險**：
- **不要在動畫中保留 `feTurbulence` 和 `feDisplacementMap` 濾鏡**。評審實測第一版整隻角色的濾鏡一幀約 28ms（無濾鏡約 0.6ms）；動畫中每一幀、每個元素都會重算，Safari 尤其慢。材質一定要先烤成圖。
- 手機上同時最多一隻角色，離開畫面就停止動畫。

## 自評

**最強的地方**
1. **材質一看就是真的紙**：撕邊白纖維、色紙的白色背面、折邊、膠水陰影，離「通用 AI 吉祥物」或光滑 3D 公仔很遠。換成鼠尾草色紙之後，它在首頁色塊旁變輕了，也和網站的卡片色系是同一家人。
2. **天生適合拆件動畫，而且機構和故事一致**：紙偶本來就是一片片接起來的；折角掀開才看得到底下的字，動畫做的事和角色想說的事是同一件。風琴腿免費提供伸縮與彈跳，「躺平的紙站起來」和「變回一片紙」是很獨特的進出場。

**最弱的地方**
1. **「圓身體＋細腿」的結構仍接近 Mr. Men 的模板**。臉和手已經改掉，但整體骨架沒變，辨識度還是要靠折角和風琴腿撐。
2. **綠色圓形的第一眼可能被讀成水果或植物**（青豆、萊姆）。折角和撕邊能把它拉回「紙」，但需要看到細節；臉也仍然是三個方向裡最安靜的，溫暖感主要來自色彩與動作，而不是表情。

### 跟著必修一起處理的弱點

- **顏色寫死**（動態評審的弱點，和換色必修重疊）：紙色改成 CSS 自訂屬性（`--c-body`、`--c-flap-back`、`--c-hand`、`--c-leg`、`--c-leg-fold`、`--c-foot`、`--c-ink`、`--c-blush`、`--c-glint`），預設值就是日間色。濾鏡裡的白纖維、膠水陰影和斑點仍是固定值，因為它們在任何主題下都一樣。
- **小尺寸時紙紋斑點顯髒**（第一版自評）：隨換色一起降低了斑點密度。

### 因為換色而必須連帶做的調整（不是新增的設計）

- **小紙片的形狀**：身體變綠之後，直立的小紙片像蘋果梗；試過一個頂端有缺口的寬版，又像仙人掌的小掌。最後改成從左上邊緣斜出、頂端圓鈍的短紙舌，pivot 移到紙舌根部 318,292。
- **折角的折邊**：色紙背面的米白和頁面的奶油紙幾乎同色。在 96px 以下，折角會被讀成身體缺了一角，而不是折起來的三角。所以沿折線加了一道淡鉛筆折邊（不透明度 0.38），折角下的陰影也從 0.15 加到 0.22。這是整隻角色唯一的「線」，代表真實的折痕，不是外框。
- **腳的顏色**：腳從牛皮深褐改成同一張綠紙的深色邊角 `oklch(68% 0.045 142)`，不然整隻只剩腳是褐色。
- **場景小紙片**：主插畫地上的米白寫字紙片，改成一小片綠色邊角。字跡只留在折角底下一個地方。
- **探頭圖的牆**：從牛皮紙改成麥黃色紙 `oklch(87% 0.05 88)`，和綠色角色分得開。

### 沒有做的與理由

- **夜紙不另外調色**：兩位評審都認為第一版在夜紙上不用換色，也沒有給不同的數值，所以這裡沒有衝突。換色後實測，白纖維邊在 21% 夜紙上仍是清楚的外輪廓，五官畫在紙上也不會消失（概念圖 b、`work/landing-night.png`），因此夜間沿用同一組顏色。
  - 鼠尾草身體在夜紙上是畫面裡最亮的色塊之一。若業主覺得太亮，現在只要覆寫 `--c-body`（例如降到 72%）就能調暗，不必改圖。本輪沒有套用，也沒有另外渲染這個版本。
- **「圓身＋細腿」的骨架沒有改**：兩位評審的必修都沒有要求改骨架，風琴腿也是評審列為優點、動畫成本最低的部分。改骨架等於換一個角色，超出這一輪的範圍。殘留的 Mr. Men 相似處已寫進自評與避免仿作表。
- **沒有新增表情、變體或動畫**：概念圖仍是一張主姿勢加兩個情緒縮圖；第二個縮圖從「眉毛常駐」改成示範「眉毛只在強烈情緒時出現」。
- **沒有和 A 的捲芽做混合**：評審提到的混合方向留給業主之後決定。
- **描圖紙材質沒有留在摺摺身上**：它很好看，但正是讓手讀成白手套的原因。改寫進第 6 節，留給一個真正屬於它的描圖紙角色。
